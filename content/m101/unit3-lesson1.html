M101 · Unit 3 · Lesson 1

Matrices acting
on vectors

A matrix records how each input component contributes to an output. We will learn to read those contributions, calculate their combined effect and see the same operation in a diagram.

Allow about 3 hours, including the unit introduction, written attempts and feedback. No coding is required. Pause after Section 3.3 if you prefer two sittings.

3.1 Organising a component rule

Imagine a drawing on a coordinate grid. We want to make it wider without making it taller. One precise instruction is to double every horizontal coordinate and retain every vertical coordinate. A point with coordinates (x,y) is sent to the point (2x,y). Thus (3,2) becomes (6,2), whereas (0,2) stays where it is. The instruction acts on each point; it is not a single displacement added to the whole drawing.

More generally, each new component could depend on both old components. Consider the rule

x′=2x−y,y′=x+3y.

The prime mark distinguishes an output coordinate from its input; here it does not mean differentiation. For input (2,1), the first rule gives x′=4−1=3 and the second gives y′=2+3=5. Both outputs must be calculated from the original pair (2,1). Substituting the newly calculated x′ into the second rule would describe a different operation.

There are four coefficients to keep track of. The first output uses 2 times the first input and −1 times the second. The second output uses 1 times the first and 3 times the second. Place them in a rectangular array:

A=(2−113).

This array is a matrix; its individual numbers are its entries. A row runs horizontally and a column runs vertically. We have placed the coefficients for the first output in row 1, and those for the second output in row 2. Column 1 records the contributions associated with x; column 2 those associated with y. The order carries information, just as the order of components did in Unit 1.

Key idea 3.1 · Shape and entry notation

A matrix with m rows and n columns has size m×n, read “m by n”. The entry aij of a matrix A lies in row i, column j: row first, column second. A matrix with equal numbers of rows and columns is square.

For our matrix, a12=−1 and a21=1. The indices are labels locating entries, not a number to multiply by a. The size 2×2 describes an arrangement; it does not instruct you to multiply the entries or add them up. Two matrices are equal when their sizes match and each corresponding entry is equal.

Example 3.1 · More inputs than outputs

A rule takes three numbers and returns two:

r=3p−q+2s,
t=4q−s.

Write its coefficient matrix in the input order (p,q,s). The first row is (3,−1,2). In the second rule, the coefficient of p is zero; leaving out that entry would shift every later coefficient into the wrong column. Hence

B=(3−1204−1).

This is a 2×3 matrix. Its second column is the two-entry column containing −1 and 4, because those are the contributions of q to the two outputs. The matrix has six entries but describes a rule with three inputs and two outputs. Those are different counts.

A matrix alone records coefficients. To apply them, we must agree how the input is written and how its entries combine with the columns. That is our next step.

3.2 Building an output from columns

We will write input and output vectors vertically, as column vectors. For example, v=(21) has horizontal component 2 and vertical component 1. This is the same vector previously written as 2i+j. Writing its components in a column has not rotated the vector in the plane.

Return to A=(2−113). Read each column as a vector in its own right: the first is (21) and the second is (−13). For input (xy), multiply the first column by x, the second by y, then add:

A(xy)=x(21)+y(−13)=(2x−yx+3y).

The result reproduces both component rules from Section 3.1. A rule that takes an input vector to an output vector is called a transformation; the rule defined by a matrix is a matrix transformation. This operation is called matrix–vector multiplication. We write Av, with the matrix on the left and its input on the right. The multiplication is defined by the weighted sum of columns; it is not entry-by-entry multiplication between arrays of different shapes.

Key idea 3.2 · One weight for each column

To calculate Av, use the first entry of v to scale column 1 of A, the second entry to scale column 2, and so on. Add the resulting vectors. Every input entry therefore has a corresponding matrix column.

Example 3.2 · A negative input weight

For A=(2−113), find the output from v=(3−2).

Keep the weights attached to their columns. The second weight is negative, so its contribution points opposite to column 2:

Av=3(21)−2(−13)=(63)+(2−6)=(8−3).

The output points right and down. The second contribution adds to the horizontal component, because the negative weight multiplies a negative first entry. As a check using the original rules, 2(3)−(−2)=8 and 3+3(−2)=−3. This catches a common error: treating a negative weight as though it changed only one entry in its column.

When we speak of a “weighted sum”, a weight can be negative, zero or fractional. Zero removes a column’s contribution for that particular input; it does not remove the column from the matrix. A later input can use it again.

3.3 Rows, dimensions and checks

The column calculation tells us how vectors combine. There is an equally useful way to organise the arithmetic: calculate one output component at a time. Write a general two-by-two matrix as A=(abcd). The column rule gives

A(xy)=x(ac)+y(bd)=(ax+bycx+dy).

The first output is the sum of products from row 1 and the input; the second uses row 2. You already know this multiply-and-add pattern from the scalar product in Unit 2. Each row supplies one scalar component. Collecting those components gives the output vector. The columns and rows do not define competing methods: they regroup the same products.

Rectangular matrices make the distinction especially clear. A matrix with three columns needs three weights; if it has two rows, every column has two entries and their sum does too. Thus a 2×3 matrix takes three-entry columns to two-entry columns.

Example 3.3 · Checking the size first

Use B=(3−1204−1) on w=(2−13).

First check compatibility. Three matrix columns match three input entries; two rows mean two output entries. Now take each row in turn:

r=3(2)−(−1)+2(3)=6+1+6=13,
t=0(2)+4(−1)−3=0−4−3=−7.

Collecting these two outputs in their original order gives

Bw=(13−7).

To check by columns, combine 2(30), −(−14) and 3(2−1). Their horizontal components give 6+1+6=13; their vertical components give 0−4−3=−7. A three-entry answer would have the wrong size, however convincing its arithmetic appeared.

Key idea 3.3 · Compatible dimensions

An m×n matrix acts on an n-entry column vector and produces an m-entry column vector:

(m×n)(n×1) ⟶ (m×1).

The matching inner numbers express “one input weight for each column”. A mismatch makes this product undefined. Do not repair it by inventing or discarding an input entry.

Here “dimension” refers to the number of entries, rows or columns. Physical units require a separate check. In our plane diagrams the matrix coefficients are dimensionless and both coordinate components use the same unit, so an input in centimetres gives an output in centimetres. In a physical model, coefficients may carry units; every term added into a given output must have compatible units. Knowing the size of an array does not settle that question.

At this point you can perform a small matrix–vector calculation without relying on a diagram. We will now reverse the emphasis and use simple arrows to discover which matrix a geometrical rule needs.

3.4 Finding a matrix from two arrows

In the plane, the coordinate unit vectors are e1=(10) and e2=(01). These are the vectors previously denoted by i and j; the subscripts now emphasise their order. Every vector can be written as (xy)=xe1+ye2.

Apply a matrix to e1. Its weights are 1 and 0, so the output is exactly column 1. Applying it to e2 selects column 2. This gives the columns a geometrical meaning: they are the images of the coordinate unit vectors. Here an image simply means an output under a transformation, not necessarily a photograph.

Ae1=(ac),Ae2=(bd).

For a matrix transformation, knowing these two images determines what happens to every vector: scale the first image by x and the second by y, then add. The output arrows need not remain perpendicular or have length one. We still measure their coordinates using the fixed original axes.

Note 3.1 · Keep the axes fixed. The arrows change; the coordinate frame in which we describe them does not. Changing the coordinate frame is a different question.

Example 3.4 · Reconstructing the rule

A matrix transformation sends e1 to (12) and e2 to (−21). Find its matrix and the image of (−13).

Put the images in columns, in the stated order.

E=(1−221).

Then apply the input weights:

E(−13)=−(12)+3(−21)=(−71).

If we had written the two image vectors as rows, applying the result to e1 would give (1,−2) instead of (1,2). Testing the coordinate vectors is therefore a direct check of whether we have encoded the supplied rule.

3.4.1 What makes two arrows enough?

The column rule respects vector addition and scaling. For example, the image of u+v is obtained by using the sum of their first components on column 1 and the sum of their second components on column 2. Distributing those weights gives the image of u plus the image of v. Similarly, multiplying all input components by a number k multiplies the whole output by k. In symbols,

A(u+v)=Au+Av,
A(kv)=k(Av).

These are the properties called linearity. We have justified them directly from the calculation; no abstract theory is needed here. In particular, every matrix sends the zero vector to the zero vector, because all its column weights are zero.

Be careful about the qualification “a matrix transformation”. Two input–output observations do not determine an arbitrary rule. A rule may behave differently elsewhere. Even leaving the origin fixed is not enough to establish linearity: (x,y)↦(x2,y) fixes the origin but doubling (1,0) produces (4,0), rather than doubling its output to (2,0). A translation by a fixed nonzero vector fails the simpler zero-input test: it moves the origin, so it cannot be represented by a two-by-two matrix acting on these two-component position vectors alone.

A wider view · An algebra of operations

Arthur Cayley developed the algebra of matrices in nineteenth-century work, including expository papers in 1855 and 1858. The historical step was more than arranging numbers neatly: operations on arrays could be studied as mathematical objects in their own right. MacTutor’s biography places that work within his broader interest in algebra and geometry.

We are approaching the same connection through a concrete question: what does an array do to a vector? In the next lesson, following one transformation with another will give us a reason to multiply two matrices. Their operation will be defined by the effect we want to represent.

3.5 Leaving, stretching and collapsing

A transformation need not change anything. To preserve every vector, preserve both coordinate unit vectors. Putting their unchanged coordinates into the columns gives the identity matrix:

I2=(1001),
I2(xy)=(xy).

The subscript specifies size two. In three dimensions, I3 has three diagonal ones and zeros elsewhere. The identity is a matrix; the number 1 is a scalar. They have related roles, but they are different kinds of object.

The zero matrix has every entry zero. A two-by-two zero matrix sends every plane vector to the zero vector. Rectangular zero matrices are also possible: their size still determines which inputs they accept and how many zero entries their outputs contain. Do not confuse a zero matrix with a matrix that happens to contain some zero entries.

Now change the diagonal ones to chosen scale factors. With S=(s00t), the output is (sx,ty). A horizontal component is multiplied by s and a vertical component by t. If s=t=2, every nonzero vector doubles in length and keeps its direction; the zero vector stays zero. If the factors differ, different directions need not experience the same length change.

Example 3.5 · Wider and shorter

Apply S=(20012) to the rectangle with vertices O=(0,0), P=(2,0), Q=(2,2) and R=(0,2).

Use the same rule at each vertex. The images are O′=(0,0), P′=(4,0), Q′=(4,1) and R′=(0,1). The width doubles and the height halves. The diagonal from O to Q originally has length 22+22=8; its image has length 42+12=17. It has not simply doubled or halved. Describe the component changes before making a claim about lengths.

A scale factor of zero has a more drastic effect. The matrix P=(1000) sends (x,y) to (x,0). Every point reaches the horizontal axis, and all inputs with the same first coordinate share an output. The matrix is not the zero matrix: (3,2) goes to (3,0), not the origin. It erases one component. Recovering the missing component from the output alone is impossible without further information.

3.6 Reflecting a figure

To reflect a point across the vertical axis, keep its height and reverse its horizontal coordinate. The point (3,2) becomes (−3,2); points already on the vertical axis remain fixed. In terms of coordinate unit vectors, e1 changes to −e1 while e2 is unchanged. Therefore the columns give

R=(−1001),
R(xy)=(−xy).

The minus sign belongs to the horizontal component, even though the mirror is the vertical axis. Remembering that distinction is safer than memorising which diagonal position gets a minus sign. Reflection across the horizontal axis instead changes y to −y.

Example 3.6 · Reflecting a triangle

Reflect the triangle with vertices P=(1,1), Q=(3,1) and R=(1,2) across the vertical axis.

Transform positions, then compare a displacement. The image vertices are P′=(−1,1), Q′=(−3,1) and R′=(−1,2). The displacement from P to Q is (2,0); from P′ to Q′ it is (−2,0). Its direction reverses but its length remains 2.

The preservation of length is not just a feature of this horizontal edge. Any displacement (u,v) has squared length u2+v2. Its reflected displacement (−u,v) has squared length (−u)2+v2=u2+v2. Since length is the nonnegative square root, the lengths agree for every displacement.

We transformed points by applying the matrix to their position vectors from the fixed origin. A displacement also transforms by the same matrix: if its endpoints have position vectors p and q, the new displacement is Rq−Rp=R(q−p), using linearity. This is why the edge calculation above agrees with reflecting the edge vector directly.

Joining the new vertices with straight segments gives the whole reflected triangle. More generally, matrix transformations carry the points along a straight segment to points along the segment joining its transformed endpoints, possibly collapsed to one point. To see why, write a point on the original edge as p+t(q−p), where 0≤t≤1. Linearity turns it into Ap+t(Aq−Ap), the corresponding point on the image edge. This justifies drawing straight image edges rather than checking infinitely many points.

We also use scalar multiplication of a matrix: multiply every entry by the same number. In particular, −I2=(−100−1). Its effect can be read from its columns just as before.

Discussion of Activity 3.6

Horizontal-axis reflection is (100−1); it sends (−2,3) to (−2,−3). The rule for J is (x,y)↦(y,x). Thus (2,0) and (0,2) exchange places, while (1,1) stays fixed: the mirror line is y=x. Points with x=y stay fixed. For a point off that line, the midpoint between (x,y) and (y,x) lies on y=x, and their non-zero connecting displacement (y−x,x−y) is perpendicular to direction (1,1) because its scalar product with that direction is zero. This checks the reflection interpretation beyond the three examples. Finally, −I2 reverses both coordinates. It sends (0,1) to (0,−1), whereas vertical-axis reflection leaves (0,1) fixed. Reversing both coordinates gives a half-turn about the origin.

3.7 Shearing and explaining the result

A stretch changes a coordinate by multiplying that same coordinate. A different possibility is to add some of the vertical component into the horizontal one while leaving height unchanged:

x′=x+ky,y′=y.

Here k is a fixed, dimensionless number called the shear factor. Every point on a horizontal row has the same height y, so every point on that row shifts horizontally by the same amount ky. Higher and lower rows shift by different amounts. This is a horizontal shear, represented by

Hk=(1k01).

The horizontal axis stays fixed, since y=0 there. For k>0, points above it move right and points below it move left. A negative factor reverses those directions. When k=0, the matrix is the identity. Unlike a translation, a shear does not move every point by the same displacement.

Example 3.7 · From rectangle to parallelogram

Use k=12 on the rectangle O=(0,0), P=(2,0), Q=(2,2) and R=(0,2).

Predict before calculating. The bottom edge has height zero and will stay fixed. The top edge has height two, so every point on it shifts right by 12(2)=1. The images are therefore

O′=(0,0),P′=(2,0),Q′=(3,2),R′=(1,2).

The image is a parallelogram with base 2 and perpendicular height 2. Its area is still 4 square units. Its left side, however, is now the vector (1,2) of length 5, rather than length 2. Equal area does not mean unchanged shape or unchanged lengths. We will connect such area comparisons with determinants in Lesson 5.

For an arbitrary fixed k, the images of e1 and e2 are (1,0) and (k,1). The slanted second image is the second column of Hk. Adding those two image arrows locates the image of (1,1) at (1+k,1). This joins the column interpretation to the changing grid.

Discussion of Activity 3.7

The bottom vertices remain (0,0) and (2,0). For k=−1, the top vertices are (0,2) and (−2,2), in the order Q′,R′. For k=0 they are (2,2) and (0,2); for k=1 they are (4,2) and (2,2). A shear is controlled by height, not by a fixed distance moved by every point.

You can now use several complementary checks. Inspect dimensions before doing arithmetic. Compare rows with weighted columns. Apply a proposed matrix to the coordinate unit vectors to test how its columns were placed. Where a geometrical description is given, check a feature that the transformation should preserve: the height in a horizontal shear, for example, or a displacement length in a reflection. Agreement is useful only when the check could have exposed the relevant mistake.

Discussion of Activity 3.8

The written matrix gives K(11)=(1−1). It changes y using x, a vertical shear. The desired rule needs (1−201): it sends e1 to (1,0) and e2 to (−2,1), exactly the required columns. Looking ahead

A matrix has become more than a table of coefficients. Its columns tell us what happens to coordinate directions; its rows organise the component arithmetic. The same calculation can describe an unchanged vector, a stretched figure, a reflection, a shear or a loss of information. In Lesson 2 we will apply two such rules successively and ask how one matrix can represent the combined effect. Keeping input, intermediate output and final output distinct will be the central task.
