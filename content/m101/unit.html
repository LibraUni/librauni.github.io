Introduction

If you arrange to meet someone “two kilometres from the station”, you have given useful information, but not enough to locate the meeting place. There are many possible destinations at that distance. A direction, or some other way of identifying a position, is still needed.

The same difficulty appears in physics. To describe where an object is, we need a reference and a way of distinguishing one direction from another. To describe a change in position, we must compare a starting point with a finishing point. These requirements are familiar from maps and everyday directions. In this unit we will turn them into mathematical descriptions that can be drawn, calculated and checked.

The street pattern in Figure 1.1 offers a useful starting point. Two directions can organise a description of place without either direction having to point towards the top of the page. A mathematical coordinate system makes the reference point, directions and measurement scale explicit.

We begin with coordinates. A coordinate system supplies a reference point and a set of directions, allowing a position to be described by numbers. At first we will work along a line and then in a plane, such as a map or a plan of a room. A third coordinate will allow us to extend the same reasoning to space.

A pair of coordinates describes a point’s position relative to the chosen system. But we will also want to describe a directed change from one point to another. This leads to a vector. Vectors allow us to keep track of direction as well as size, so that a movement to the left is distinguished from a movement of the same size to the right. The arrows used in our diagrams will make this distinction visible.

Once these descriptions are established, we will learn to combine vectors, find their lengths and express them in terms of perpendicular components. Trigonometry will connect a description using length and angle with a description using components. You will meet several representations of the same vector; an important part of the unit is learning to choose between them and recognise what each makes easier to see.

Many of the early calculations are short. Their purpose is to help you make precise distinctions: a point and a vector, a position and a displacement, a signed component and a length. These distinctions become useful when several quantities appear in the same problem. They will also prepare you to resolve quantities into components in P101.

As you work, keep the diagrams close to the algebra. If a component is negative, be ready to point to the direction it represents. If two answers look different, consider whether they use different reference points or describe different quantities. We will begin with the simplest setting, where a single number is enough to locate a point.

The route through Unit 1

The five lessons are Coordinates, position and displacement; Adding and scaling vectors; Magnitude and unit vectors; Resolving and reconstructing components; and Vector fluency and unit review. The final lesson brings the whole unit together through its exercise set, feedback and reference resources. You will need paper and a pencil throughout; no programming is required in this unit.

Allow about 18 hours for the complete unit, including reading, activities, exercises and checking your work. This is a planning estimate, not a reading deadline. Lesson 1 occupies about three hours of that total, including this introduction, and can be spread over several sittings.
