Rectangle and midpoint quadrature

An integral can be meaningful even when we cannot conveniently write down an antiderivative. The small-contribution reasoning from Unit 10 still applies. In this lesson we turn it into a calculation with a specified, finite set of sample values.

11.1 Choosing what each sample represents

Suppose a supplied model gives a liquid inflow rate q(t)=1+t2 litres per minute, with t in minutes, during 0≤t≤2. The incoming volume is the integral of this rate. We can evaluate that integral exactly, which makes the model useful for testing an approximation. First imagine that we only evaluate the rate at selected times.

Divide the two-minute interval into four equal pieces. Each piece lasts half a minute. If we hold the rate constant on a piece, the estimated volume entering during it is that rate multiplied by half a minute. This multiplication is essential: a sum of rates alone still has units of litres per minute. The interval width turns each rate into a contribution measured in litres.

There is a choice to make. We could use the rate at the beginning of each piece, at its end, or halfway through it. Each choice defines a different rule. The name quadrature means numerical approximation of a definite integral; it does not specify which rule we use.

For a general interval [a,b] with a<b, let n be a positive integer counting the panels, or subintervals. Their common width is h=(b−a)/n. Label the endpoints xi=a+ih, with i=0,1,…,n. Panel i, counted from zero, runs from xi to xi+1.

There are n panels but n+1 endpoints. Draw two panels to check the count before writing a loop.

A wider view · optional context

Turning a curve into a total

Area can be obtained from a drawing without first finding a convenient equation for its boundary. Planimeters are one physical approach to that task; the Science Museum Group documents their use for measuring areas inside closed curves. Our quadrature rules instead work from selected function values. In either setting, the representation determines the information available for the calculation.

For a rate graph, the horizontal and vertical scales carry different units. Their product gives the accumulated quantity: minutes times litres per minute gives litres. Reading a geometric area from a drawing is therefore only part of interpreting the result. Museum context.

Example 11.1 · Build the samples before the sum

For the inflow model, list the four panels and the sample times for a left-endpoint estimate.

The panels are [0,0.5], [0.5,1], [1,1.5] and [1.5,2] minutes. Their left endpoints are 0, 0.5, 1 and 1.5. The final endpoint 2 is not a left endpoint of any panel in this interval. The corresponding rates are 1, 1.25, 2 and 3.25 L/min. Thus the estimate is

L4=0.5(1+1.25+2+3.25)=3.75 L.

The answer describes the incoming volume over the whole interval. It does not give the liquid already in the vessel at time zero; an initial amount would be added separately.

Discussion of Activity 11.1

The sample times are 0.5, 1, 1.5 and 2, giving rates 1.25, 2, 3.25 and 5. Hence R4=0.5(1.25+2+3.25+5)=5.75 L. The rate increases throughout the interval. On each panel its right-endpoint value is the largest rate, so holding that rate constant overestimates the panel contribution. The left rule similarly underestimates it.

11.2 A bracket justified by monotonicity

The preceding comparison used more than the five numbers in a table: it used knowledge that the rate increases between them. For any nondecreasing function, the left endpoint is a lower bound on every value within its panel and the right endpoint is an upper bound. Multiply these inequalities by the positive panel width and add them. This gives a genuine bracket for the integral I.

Key idea 11.1 · Endpoint sums

Ln=h∑i=0n−1f(a+ih),Rn=h∑i=1nf(a+ih).

For nondecreasing f on [a,b], Ln≤I≤Rn. For nonincreasing f, the inequalities reverse. These statements require the monotonicity of the function over each panel, not merely increasing or decreasing sampled values.

Subtract the two sums. Every interior term occurs once in each, so it cancels. Only the final and initial function values remain:

Rn−Ln=h(f(b)−f(a)).

For a monotone function, the width of the bracket is therefore h|f(b)−f(a)|. Doubling n halves this width. Either endpoint estimate is within the bracket width of the exact integral. The centre of the bracket is within half that width. We have obtained a bound from an explicit mathematical property, without knowing the exact integral.

Example 11.2 · Compare a bound with an actual error

For the inflow model, q′(t)=2t≥0 on [0,2], so 3.75≤I≤5.75 L. The bracket centre is 4.75 L and its half-width is 1 L. Now use an antiderivative to determine the actual error:

I=[t+t33]02=143 L.

The centre overestimates by 4.75−14/3=1/12 L, much less than 1 L. A bound is allowed to be conservative. Its value is that it guarantees containment under the stated assumptions; it need not equal the observed error.

Activity 11.2 · Choose a sufficient resolution

For this same rate, find a number of panels that guarantees a left-rule error no greater than 0.1 L using only the monotonicity bracket. Is this necessarily the smallest possible number?

Discussion of Activity 11.2

The bracket width is (2/n)(5−1)=8/n L. Requiring 8/n≤0.1 gives n≥80. This is sufficient, not necessarily minimal: the bound covers the whole bracket, whereas the actual error can occupy only part of it. We chose a justified guarantee rather than guessed agreement of decimal digits.

11.3 Sampling at the midpoint

A left rectangle tends to miss some of an increasing contribution; a right rectangle includes too much. We can instead sample halfway through each panel. The midpoint of panel i is a+(i+1/2)h, so the midpoint rule is

Mn=h∑i=0n−1f(a+(i+12)h).

The sample position is halfway between the endpoints. Its function value is not generally halfway between their function values. For f(x)=x2 on [0,1], the midpoint height is f(1/2)=1/4, whereas the average of the endpoint heights is (0+1)/2=1/2. In Lesson 2 the second construction will produce a different rule.

Why can the midpoint choice help? On a straight line, the excess area on one side of a midpoint rectangle exactly cancels the deficit on the other. Therefore midpoint quadrature integrates a linear function exactly. A curved graph does not have exactly this balance, but over a short panel it can be close to a line. Curvature, rather than increase or decrease alone, now controls the leading discrepancy.

Example 11.3 · Midpoint estimate of an inflow

The four sample times are 0.25, 0.75, 1.25 and 1.75 minutes. Their rates are 1.0625, 1.5625, 2.5625 and 4.0625 L/min. Hence

M4=0.5×9.25=4.625 L.

The exact value is 14/3 L, so the underestimate is 14/3−4.625=1/24 L. This is a much smaller error than either endpoint estimate with the same panel count. We established that comparison by an exact benchmark; it is not a promise for every function sampled four times.

Signed contributions work in the same way. If a net flow is negative on a panel, its sampled contribution is negative. Taking an absolute value would change the question from net change to accumulated magnitude, as in Unit 10. Reversed bounds also need care: a negative width represents reversed integration orientation. For midpoint quadrature, reversing the bounds visits the same set of midpoints in reverse order and changes the result's sign.

Activity 11.3 · A signed benchmark

Use two midpoint panels to estimate int−13(x−1)dx. Show the individual contributions. What happens if the bounds are reversed? Explain why a test using only the final zero is weak.

Discussion of Activity 11.3

The forward width is 2, the midpoints are 0 and 2, and the contributions are −2 and +2, summing to zero. Reversal gives zero again, although both contributions reverse orientation. Because zero equals its own negative, this test cannot expose a program that always takes the absolute value of a result. A nonzero signed test is needed as well.

11.4 Turn the rule into readable code

A numerical routine should make the mathematics recognisable. Begin with the panel count, then the width, then the sample position inside a loop. Accumulate the sampled heights and multiply by the common width once. The following scalar implementation accepts finite numerical bounds and a positive Python integer panel count; the supplied function must return finite numbers at its sample points.

from math import isfinite

def midpoint(f, a, b, n):
    if type(n) is not int or n < 1:
        raise ValueError("n must be a positive integer")
    if not (isfinite(a) and isfinite(b)):
        raise ValueError("bounds must be finite")
    if a == b:
        return 0.0
    h = (b - a)/n
    total = 0.0
    for i in range(n):
        x = a + (i + 0.5)*h
        y = f(x)
        if not isfinite(y):
            raise ValueError("non-finite sampled value")
        total += y
    return h*total

def q(t):
    return 1 + t*t

print(midpoint(q, 0, 2, 4))  # 4.625

rangen gives the indices 0 through n−1, precisely one per panel. The addition of 0.5 places the sample in the centre. isfinite, from Python's standard math module, rejects infinity and the special undefined numerical value NaN. A zero-length interval returns zero before evaluating the function. This convention is useful for a degenerate interval; it does not establish anything about an integral over a neighbourhood where the function is undefined.

Notice what these guards cannot test. A function may be finite at every sampled point and singular elsewhere, or it may have a narrow feature between the samples. Inspecting the mathematical domain remains part of using the routine. If arithmetic overflows for the quantities you choose, stop and rescale or investigate the model; do not interpret the resulting number as an approximation.

Discussion and checks for Activity 11.4

The left sample is a + i*h; it gives 3.75 for the four-panel inflow. For f(x)=3 on [2,5], both rules give 9 for any positive panel count. Midpoint reversal on [5,2] gives −9. For the inflow, the midpoint values are 4.625, 4.65625 and 4.6640625, approaching 14/3. An invalid count should raise a clear error. The constant test checks width and panel counting, the hand sum checks sample positions, and reversal checks orientation. Left-rule reversal uses the original right endpoints, so generally Ln(b,a)=−Rn(a,b), not −Ln(a,b). Preserve that distinction in your tests.
