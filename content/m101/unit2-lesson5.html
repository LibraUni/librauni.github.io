2.28 Check a property, not just a number

A check is strongest when it examines something that your original calculation did not explicitly enforce. Suppose you calculated a projected vector by multiplying a number by b. The result must lie on the line of b, whatever that number was. Confirming parallelism is useful for catching a copying error, but it cannot establish that you chose the right multiplier.

The remaining part provides a different question. For a projection p of a onto a nonzero direction b, the remainder q=a−p must be perpendicular to b. Together, the two conditions say that we have separated a into a part on the chosen line and a part across it. Reconstruction by itself is weaker: if we define a remainder by subtraction, adding it back will recover a even when the proposed projection is wrong.

Example 2.30 · Give the program an independently known answer

For dimensionless vectors a=⟨4,1,0⟩ and b=⟨1,1,0⟩, find the projection and its perpendicular remainder. Establish a check before writing code.

Solution

The reference line is y=x in the xy-plane. A vector along it has the form p=⟨t,t,0⟩. Its remainder is ⟨4−t,1−t,0⟩. Perpendicularity to b requires

(4−t)+(1−t)=0,t=52.

Thus

p=⟨52,52,0⟩,
q=⟨32,−32,0⟩.

This derivation used the two geometric requirements directly. The projection formula agrees: a·b=5 and b·b=2, so the multiplier is 5/2. The component sum reconstructs ⟨4,1,0⟩, and q·b=3/2−3/2=0. Figure 2.26 shows what these calculations say.

There is a general reason for trusting the perpendicularity check. Write any proposed vector on the reference line as p=cb. Then

(a−cb)·b=a·b−c(b·b).

For nonzero b, the positive number b·b makes exactly one value of c set this expression to zero. Solving gives the projection multiplier. This reasoning explains the formula for every allowed input; checking a few numerical cases does not replace it.

Key result 2.17 · What identifies a projection?

For b≠0, a proposed projection is correct if it lies on the line of b and its remainder is perpendicular to b. Check the output type and units too. Reconstruction alone does not establish that the two parts have the required directions.

2.29 Translate the calculation into a function

Programming readiness. Before attempting this section's code independently, use your P101 Unit 1 work to demonstrate that you can open and run your existing notebook, read an entry such as a[1] from a list, evaluate a scalar expression, use an if condition, and define and call a function that returns a value. P101 Lesson 5, Functions and checks you can explain, is the relevant returning-function preparation. If any part is unfamiliar, continue with the hand reasoning and unit exercises, and return to the reserved coding hour after that preparation. Reading the supplied program does not demonstrate independent coding readiness.

We will represent a three-dimensional vector by a list of three numbers in x,y,z order. All inputs in this coding activity are dimensionless, modest-sized numbers. The function assumes that the caller supplies lists of length three containing numbers. It is a small teaching calculation, not a general vector library: we will check the zero reference explicitly, but we will not add a course in input validation, numerical extremes or software installation.

The formula has three stages: form b·b, form a·b, then multiply each entry of b by their quotient. Explicit component arithmetic keeps every operation visible. The following code uses only the lists, scalar arithmetic, condition and returning function already required from P101.

def projection(a, b):
    bb = b[0]*b[0] + b[1]*b[1] + b[2]*b[2]
    if bb == 0:
        return None
    ab = a[0]*b[0] + a[1]*b[1] + a[2]*b[2]
    scale = ab / bb
    return [scale*b[0], scale*b[1], scale*b[2]]

The condition belongs before the division. For our inputs, bb == 0 identifies a zero reference vector. Returning None marks the absence of a defined projection; it must not be replaced by [0, 0, 0]. A zero projected vector is a valid answer when the input is perpendicular to a nonzero reference. An undefined projection is a different situation.

The multiplier scale is a scalar. The returned list is the projected vector. Python's list multiplication does not implement scalar multiplication of a vector: [1, 2] * 2 repeats a list rather than doubling its entries. Writing each product explicitly avoids that mismatch and makes the correspondence with the mathematics visible.

Example 2.31 · Read the output as a vector

a = [4, 1, 0]
b = [1, 1, 0]
p = projection(a, b)
print(p)

Once the definition cell has run, this call displays [2.5, 2.5, 0.0], the same vector as Example 2.30. The decimal format does not make it a different answer. Since this call has a nonzero reference, we can form its remainder:

q = [a[0] - p[0], a[1] - p[1], a[2] - p[2]]
print(q)
print(q[0]*b[0] + q[1]*b[1] + q[2]*b[2])

The outputs are [1.5, -1.5, 0.0] and 0.0. These lines check the remainder rather than simply recomputing the projection formula. Do not index the returned value after a zero-reference call: that result is None, not a list.

2.30 Choose cases that can expose an error

One successful run tells us about one case. To learn more, choose inputs that force qualitatively different answers: a usual slanting projection, a perpendicular input, a parallel input, and a reference with no direction. Predict them before running the function. Otherwise a plausible display can become the answer you unconsciously expect.

A particularly useful test changes the representation without changing the geometric question. Replacing b by −b reverses the signed scalar component, but it leaves the line unchanged. The vector projection must therefore stay the same. Scaling the reference by any nonzero factor has the same invariance, as established in Lesson 2.

Now imagine an erroneous program that always reverses the projected vector. On perpendicular inputs it still returns zero, so those tests pass. It also still returns a vector on the correct line. For Example 2.30, however, the wrong output ⟨−2.5,−2.5,0⟩ leaves remainder ⟨6.5,3.5,0⟩, whose dot product with b is 10, not zero. The failed check tells us which geometric property was lost.

Discussion of Activity 2.29

The correct outputs, in table order, are [2.5, 2.5, 0.0], [0.0, 0.0, 0.0], [-3.0, -3.0, 0.0], [2.5, 2.5, 0.0], [0.0, 0.0, 0.0], and None. A displayed -0.0 in an erroneous or alternative calculation is numerically zero.

The wrong-sign version fails the ordinary, opposite-parallel and reversed-reference predictions. It passes the perpendicular and zero-input cases because negating zero has no effect; it also correctly rejects the zero reference because that return occurs before the faulty line. Its ordinary-case remainder has dot product 10 with b, exposing the failure to separate perpendicular parts.

Notice a limitation: the wrong version is itself unchanged when the reference is reversed. Invariance alone therefore does not reveal this particular bug. An independent expected vector or the perpendicular-remainder check does. After editing a notebook function, rerun its definition cell before rerunning calls; otherwise you may still be calling the old version.

The zero reference provides no line, so a list of zeros would make a false claim about a defined result. Finally, a finite collection of matching outputs supports the implementation only on those cases. Section 2.28 supplies the general mathematical argument; the code must also faithfully implement its steps.

For other decimal inputs, a quantity that is exactly zero in the mathematics may display as a very small nonzero number. Many fractions have only approximate binary representations in a computer, and arithmetic can expose the rounding. This is different from a wrong sign or a missing denominator. Compare with the scale and hand calculation before diagnosing an error; do not fix an unexplained discrepancy by rounding everything until it disappears. Our chosen cases use integers and halves so that the main checks remain easy to interpret. Handling extreme magnitudes, arbitrary tolerances and general numerical stability lies beyond this small function.

Exercise 2.1 · An angle from components

About 4 minutes for an attempt.

Let a=⟨2,−1,2⟩ and b=⟨1,2,−2⟩. Find their dot product and angle. Predict whether the angle is acute or obtuse before using inverse cosine. Explain why using the absolute value of the dot product would change the answer.

Hint for Exercise 2.1

Calculate both squared magnitudes and preserve the sign of the numerator in the cosine formula.

Worked solution to Exercise 2.1

The paired products give a·b=2−2−4=−4. Both squared magnitudes are 9, so both magnitudes are 3. The negative dot product predicts an obtuse angle.

cosθ=−49,θ≈116.4∘.

Replacing −4 by 4 gives the supplementary acute angle, about 63.6∘. That discards the directional information we were asked to find.

Exercise 2.2 · The same comparison in geometric form

About 5 minutes for an attempt.

Two vectors have magnitudes 5 and 4, with tail-to-tail angle 120∘. Find their dot product. Reverse only the second vector: find the new angle and dot product without choosing coordinates. Finally, replace the second vector by zero. State which of the dot product and angle remains defined, and why.

Hint for Exercise 2.2

Reversing one nonzero vector replaces its angle by the supplement. A zero vector has no direction.

Worked solution to Exercise 2.2

The dot product is (5)(4)cos120∘=−10. Reversal changes the angle to 60∘, so the product becomes +10, also following from linearity in the second input. With a zero second input the component rule still gives zero. The angle is undefined, since there is no second direction and its magnitude would make the cosine formula's denominator zero.

Exercise 2.3 · Signed component, vector and distance

About 7 minutes for an attempt.

A displacement is a=⟨−1,−3,0⟩m, and the dimensionless vector b=⟨2,1,0⟩ specifies a reference direction. Find the signed component, the vector projection p and the perpendicular remainder q. Find the perpendicular distance from the tip of a to the line through the origin along b. Check the reconstruction and perpendicularity. Explain why the distance cannot equal the signed component here.

Hint for Exercise 2.3

The distance is the magnitude of the remainder, not a signed component or one of its coordinates.

Worked solution to Exercise 2.3

Here a·b=−5m and |b|=5. The signed component is s=−5m. The multiplier for the projected vector is −5/5=−1 in metres, giving

p=⟨−2,−1,0⟩m.
q=⟨1,−2,0⟩m.

Their sum is the original displacement. The remainder has dot product (2−2)m=0 with the reference, and its magnitude is 5m, the requested distance. The signed component is negative because the projected arrow points against the reference; a distance is nonnegative. Their absolute values happen to agree in this example, but they describe different lengths in the right triangle.

Exercise 2.4 · A perpendicular vector with the wrong orientation

About 5 minutes for an attempt.

For a=⟨1,2,0⟩ and b=⟨0,1,2⟩, a report gives a×b=⟨−4,2,−1⟩ and supports it with two zero dot products. Check those products, compute the correct ordered cross product, and explain what the report's checks could not establish.

Hint for Exercise 2.4

Inspect an ordered component of the cross product, not only its perpendicularity.

Worked solution to Exercise 2.4

The reported vector has dot products −4+4=0 with a and 2−2=0 with b. Both checks pass. But the ordered component formula gives

a×b=⟨4,−2,1⟩.

For example, its first component is 2(2)−0(1)=4, fixing a sign that the perpendicularity checks cannot distinguish. The report has calculated the reverse orientation, b×a. Both normal directions are perpendicular to the plane; the requested order selects one.

Exercise 2.5 · A triangular panel

About 7 minutes for an attempt.

The corners of an ideal flat triangular panel are P=(1,0,1), Q=(3,1,1) and R=(1,2,3), all in metres. Find its area and the unit normal selected by the order PQ→×PR→. Explain what changes if Q and R are interchanged.

Hint for Exercise 2.5

Form edge vectors from one common vertex before taking the cross product. A triangle occupies half the corresponding parallelogram.

Worked solution to Exercise 2.5

The edges are PQ→=⟨2,1,0⟩m and PR→=⟨0,2,2⟩m. Their ordered product is ⟨2,−4,4⟩m2, whose magnitude is 4+16+16m2=6m2. Hence

A=3m2.
n^=⟨13,−23,23⟩.

The unit normal is dimensionless: dividing by the product magnitude removes its area units and scale. Swapping the edges reverses the normal but leaves the area unchanged. The squared component sum of the unit normal is 1/9+4/9+4/9=1.

Exercise 2.6 · Repair claims about zero

About 5 minutes for an attempt.

For each claim, give a corrected statement and a counterexample to the original.

  1. “A zero cross product means that the two vectors point the same way.”
  2. “A zero dot product always defines a right angle.”
  3. “If two nonzero vectors have zero dot product, their cross product must also vanish.”
Hint for Exercise 2.6

Separate zero inputs, opposite parallel inputs and perpendicular nonzero inputs.

Worked solution to Exercise 2.6

For the first claim, nonzero inputs with zero cross product are parallel, possibly opposite: ⟨1,0,0⟩ and ⟨−2,0,0⟩ give a counterexample. A zero input is another possibility and has no direction. For the second, a zero dot product implies a right angle only when both inputs are nonzero; 0 and ⟨1,0,0⟩ have zero product but no defined angle. For the third, take i and j: their dot product is zero and their cross product is k. For nonzero perpendicular inputs, the cross-product magnitude is the positive product of their magnitudes.

Exercise 2.7 · Identify the displacement before the product

About 7 minutes for an attempt.

A specified constant force is F=⟨−4,1,0⟩N. Its point of application moves from P=(1,−1,0) to Q=(3,2,0), with coordinates in metres. Using W=F·d, find the work done by this force. A report uses the position of Q as d and obtains −10J. Diagnose the error. What work would the same unchanged force do for the reverse journey?

Hint for Exercise 2.7

Work uses final position minus initial position. Negative work must retain its sign.

Worked solution to Exercise 2.7

The displacement is d=⟨2,3,0⟩m. Thus

W=(−8+3)Nm=−5J.

The negative contribution along x exceeds the positive contribution along y. The report calculated work for a different displacement, from the origin to Q; (−12+2)J=−10J is consistent arithmetic with the wrong input. The reverse journey has displacement −d, giving +5J for the same force. No claim about the total work of other forces or the resulting motion follows.

Exercise 2.8 · A reference point changes a torque

About 8 minutes for an attempt.

A force F=⟨0,−12,0⟩N acts at P=(0.50,0.25,0) metres. Find its torque about O=(0,0,0), and about C=(0.20,0,0) metres. For each, state magnitude and direction and check with a perpendicular lever arm. View the xy-plane from positive z. If the application point is held stationary, what work does this force do during that interval, and does this require its torque to vanish?

Hint for Exercise 2.8

For each torque form the vector from that reference point to P. The force's line of action is vertical.

Worked solution to Exercise 2.8

About O, rO=⟨0.50,0.25,0⟩m. Its cross product with the force is ⟨0,0,−6.0⟩Nm. About C, use rC=⟨0.30,0.25,0⟩m, giving ⟨0,0,−3.6⟩Nm. Both point along negative z, a clockwise turning effect in the stated view.

The force line is x=0.50m. Its perpendicular distances from the two references are 0.50m and 0.30m, so the magnitudes are 12(0.50)=6.0 and 12(0.30)=3.6 in newton metres. While the application point is held stationary its displacement is zero, hence its work is zero. This does not remove its torque: a supporting arrangement can prevent motion while this specified force still has a turning effect.

Exercise 2.9 · A check that passes for the wrong reason

About 6 minutes for an attempt.

A proposed projection of a=⟨3,1,0⟩ onto b=⟨1,1,0⟩ is p=⟨1,1,0⟩. Its author sets q=a−p and reports that p+q=a, so the answer must be right. Explain why that check is insufficient, show that the answer is wrong, and find the correct two parts. Predict the vector projection and signed scalar component when the reference is replaced by −2b.

Hint for Exercise 2.9

Subtraction guarantees reconstruction. Test the direction of the remainder separately.

Worked solution to Exercise 2.9

The proposed remainder is ⟨2,0,0⟩, so its dot product with b is 2, not zero. Reconstruction holds for any proposed p if q is defined by subtraction. The correct multiplier is (3+1)/(1+1)=2, so the correct parts are ⟨2,2,0⟩ and ⟨1,−1,0⟩.

For reference −2b, the line is unchanged and so is the vector projection. The original signed component is 4/2=22; the reversed direction changes it to −22. The extra factor of two in the reference length cancels when forming a unit direction.

Exercise 2.10 · What the reported answers leave undetermined

About 6 minutes for an attempt.

A dimensionless vector a has vector projection ⟨2,0,0⟩ onto i=⟨1,0,0⟩, and |a×i|=3. Construct two different possible vectors a. Check both reports for each, and explain why the reports do not determine the direction of the perpendicular remainder in three dimensions.

Hint for Exercise 2.10

The first report fixes the x-component. The second fixes a length across the x-axis, not a unique direction in the yz-plane.

Worked solution to Exercise 2.10

Two possibilities are ⟨2,3,0⟩ and ⟨2,0,3⟩. Each has dot product 2 with i and therefore projection 2i. Their cross products with i are respectively ⟨0,0,−3⟩ and ⟨0,3,0⟩, both of magnitude 3.

2.33 Conclusion: comparisons with a purpose

We opened Unit 2 by asking how a calculation can distinguish arrows that follow, cross or oppose a direction. The scalar product answers through a signed parallel comparison. After accounting for magnitudes, it reveals an angle; after choosing a unit direction, it gives a signed component. Restoring that direction turns the component into a projected vector, leaving a perpendicular remainder.

The cross product answers another question. Two nonparallel vectors in three dimensions define a plane, an area scale and two possible normal directions. Their ordered product selects one normal by the right-hand rule. Swapping the order reverses that choice while preserving the area. These connections explain why the formulas differ, and why taking a magnitude too early can discard information that the problem needs.

Work and torque made the choice of inputs just as important as the choice of product. A displacement describes a change; a position vector for torque points from a stated reference to an application point. Equal units cannot make those roles interchangeable. Checking the result therefore starts with the question and its assumptions, then examines the geometry and arithmetic.

A short program can repeat that arithmetic reliably when its instructions and inputs are appropriate. It cannot supply a missing interpretation. Keep the hand prediction, the exceptional case and the explanation of a repaired error together: they show what you have established and what you have not. If the P101 coding preparation is still pending, keep this unit's coding task pending too while retaining your completed mathematical work.

Unit 3, Matrices, transformations and simultaneous equations, will organise component relationships into a new notation and use them to describe transformations and coupled equations. The habits developed here will remain useful: preserve order, state conditions, distinguish kinds of output, and choose a check that can actually detect the suspected mistake.
