Continuity and numerical evidence

A continuous rule connects what happens nearby with what happens at the point itself. A numerical calculation must be checked against both.

In the preceding lessons we deliberately separated three questions: where a function is defined, what its values approach, and what value it has at the target input. Continuity brings these questions together. It is the property that allows nearby behaviour to agree with the assigned value. We will use it to join rules, compose functions and decide when substitution is justified. Then a short Python investigation will expose a different difficulty: two mathematically equal expressions need not give equally reliable rounded calculations.

4.17 Matching the value and the limit

A graph with an isolated misplaced point can have a perfectly clear limit there. Yet evaluating the function at that point gives a different answer. Continuity rules out this mismatch. It also rules out a missing value or a failure of the nearby values to settle.

Key idea 4.9 · Continuity at an interior point

A function f is continuous at an interior input a when all three conditions hold: f(a) is defined; the finite two-sided limit limx→af(x) exists; and that limit equals f(a). We summarise the conditions as

limx→af(x)=f(a).

Check existence before equality. At an included endpoint of an interval, use the one-sided limit from within the interval. A function is continuous on an interval when it is continuous at every interior point and at any included endpoints in this sense.

The intuitive picture of drawing a graph without lifting a pencil can be helpful, but it is not a test: the scale of a drawing can hide a gap, and some domains consist of separate intervals. Use the conditions instead. Continuity is local, concerning an input and its available neighbours; a function need not be defined at every real number to be continuous throughout its domain.

Example 4.16 · Repairing one point

For x≠3, let f(x)=(x2−9)/(x−3). Can we assign a value at 3 to make an extended function continuous there?

Working. Away from 3 the rule equals x+3, so the limit at 3 is 6. The original function has no value there and thus is not continuous at 3. Defining a new function F by the same rule away from 3 and F(3)=6 satisfies all three conditions. Any other assigned value leaves the limit unchanged but fails the equality condition.

This is a removable discontinuity in the usual description of the missing point. The repair changes the domain and adds a value; cancellation alone did neither. If the original model prohibited that input for a physical reason, the algebraic extension would not automatically authorise using the model there.

A jump has a different obstruction: the one-sided limits disagree. Moving one filled point cannot change either approach, so no choice of its value can repair the jump. Similarly, assigning a finite value at zero cannot make 1/x2 continuous there, because its nearby outputs are unbounded. The failure determines whether a repair is possible.

Activity 4.21 · Identify the failed condition

At x=2, compare (a) f(x)=x+1 for x≠2, with f(2)=7; (b) g(x)=1 for x<2 and g(x)=3 for x≥2; (c) r(x)=x−2 on [2,∞). Which can be made continuous by changing only the value at 2? Which is already continuous at its endpoint?

Discussion of Activity 4.21

For (a) the limit is 3 while the value is 7; replacing 7 by 3 repairs the mismatch. In (b) the left limit is 1 and the right limit is 3, so the two-sided limit fails; no single point value repairs it. In (c) the right-hand limit is 0, equal to r(2), so the endpoint is already continuous. A left-hand approach is unavailable in its real domain and is not required for endpoint continuity.

4.18 Joining rules and checking endpoints

Many useful models use different rules in different ranges. Each branch can be continuous on its own while the combined rule has a discontinuity where the branch changes. To examine a join, first take the left and right approaches using their respective formulas. Then evaluate the actual point using the branch whose inequality includes it.

Example 4.17 · Choosing a continuous join

Choose c so that the piecewise rule

p(x)={x2+1,x<2,cx+1,x≥2

is continuous at 2.

Working. The left limit is 22+1=5. The right limit is 2c+1, and the point value is also p(2)=2c+1. Continuity therefore requires 2c+1=5, giving c=2. With this choice both limits and the value equal 5. Both branches are polynomials, so they are continuous away from the join too; the resulting function is continuous on the real line.

Matching one output does not make the two formulas identical. For example, at 3 the second branch gives 7, whereas the unused quadratic formula would give 10. We have joined the branches at their boundary, not replaced one rule with the other.

Closed intervals require special attention only at their ends. The function s(x)=4−x on [0,4] has ordinary two-sided continuity at interior inputs. At 0 its right-hand limit is 2, equal to s(0). At 4 its left-hand limit is 0, equal to s(4). It is therefore continuous on the entire closed interval. The domain restriction at 0 was a modelling choice; the square root itself would allow smaller inputs. In either case the continuity test uses the stated domain.

Do not describe a rational function as discontinuous at every input merely because its domain has an exclusion. For example, 1/(x−2) is continuous on each of (−∞,2) and (2,∞), and hence at every point of its domain. It has no continuous extension across 2. Saying exactly which interval or point is under discussion removes this apparent conflict.

A wider view · Continuity is a property of the model

A finite collection of calibration readings cannot establish continuity at every unmeasured input. Continuity is a mathematical assumption or a consequence of the model’s rule; agreement with readings provides evidence about the model’s suitability. Conversely, a rounded display can change in visible steps even when the chosen model of the underlying quantity varies continuously. Keep the physical quantity, the measuring procedure and the mathematical function distinct.

The left limit is 3. The right limit is a+2, so a=1 makes the approaches agree. We still need b=3 to match the point value. For t, the denominator is nonzero throughout [0,2]. The quotient law gives continuity at interior points; the right limit at 0 is 1 and the left limit at 2 is 1/3, equal to their respective endpoint values.

4.19 Continuity through a chain of functions

Composition uses one function’s output as another’s input. If the first output approaches a value where the second function is continuous, the second function preserves the approach. This is the reason that substituting a limit into a familiar outer function often works. The location at which the outer function must be continuous is the inner limit, not necessarily the original input.

Key idea 4.10 · Passing a limit through a continuous function

If g(x)→L as x→a and f is continuous at L, then, provided the nearby outputs of g lie in the domain of f,

limx→af(g(x))=f(L).

In particular, if g is continuous at a and f is continuous at g(a), their composition is continuous at a, wherever the composition is defined on the relevant nearby domain.

The arithmetic laws already establish continuity of polynomials, and of rational functions where their denominators are nonzero. We also use the established elementary continuity properties of absolute value, square root on its nonnegative domain, sine and cosine, exponential functions and logarithms on positive arguments. The square-root case was justified in Lesson 3; proofs for all the other families are beyond this unit. These facts license substitution within the stated domains. They do not remove input restrictions: a real logarithm of a nonpositive number is still undefined.

Example 4.18 · Follow the input through the composition

Find the limit at x=0 of F(x)=ln(2+1+x) and determine whether F is continuous there.

Working. The square root requires x≥−1. Its output is nonnegative, so the logarithm’s argument is at least 2 and is positive throughout that domain. As x→0, 1+x→1, the square root approaches 1, and 2+1+x→3. The logarithm is continuous at 3, giving

limx→0ln(2+1+x)=ln3.

Direct evaluation gives F(0)=ln3, so the function is continuous at 0. We checked both domains before passing through the composition. The conclusion is an exact value, not a rounded decimal.

Without outer continuity, the conclusion may fail. Let g(x)=x2, and let H(u)=1 when u>0 but H(0)=0. Then g(x)→0, yet H(g(x))=1 for every nonzero x. The limit of the composition is 1, not H(0)=0. The inner approach is well behaved; the mismatch occurs at the outer function’s assigned value.

Find the domain of A(x)=3−x2 and decide whether it is continuous at 0 and at the right endpoint of its domain. Find limx→0exp(3−x2). State which continuity property lets you take the last step.

Discussion of Activity 4.23

The radicand condition is x2≤3, giving [−3,3]. At 0, the polynomial radicand and square root give two-sided continuity and value 3. At the right endpoint the left limit is 0, equal to the value, so endpoint continuity holds. The exponential is continuous at 3, so the requested limit is exp(3).

4.20 A numerical investigation: equal rules, unequal calculations

Exact algebra and computer arithmetic answer related but different questions. A mathematical identity holds for every input in its stated domain. A computer stores and operates on finite approximations to numbers. When two almost equal approximations are subtracted, their small difference can contain very little reliable information.

Return to Example 4.13. For h≥−9, h≠0, the two formulas

D(h)=9+h−3h,R(h)=19+h+3

are exactly equal, and their common limit at zero is 1/6. This makes a controlled comparison: any disagreement between their computed outputs comes from numerical evaluation, not from different mathematical functions. The rearranged form avoids subtracting nearly equal roots.

Activity 4.24 · Predict, run, explain

Before running: predict the limit from algebra. For a small positive h, should the exact value be above or below 1/6? Reverse the sign of h and predict again. Then run this complete starting calculation:

from math import sqrt

def direct(h):
    if h < -9 or h == 0:
        return None
    return (sqrt(9 + h) - 3) / h

def rearranged(h):
    if h < -9 or h == 0:
        return None
    return 1 / (sqrt(9 + h) + 3)

offsets = [0.1, -0.1, 0.01, -0.01, 1e-4, -1e-4,
           1e-8, -1e-8, 1e-12, -1e-12, 1e-16, -1e-16]
print("         h             direct          rearranged")
for h in offsets:
    print(f"{h: .1e}   {direct(h): .12f}   {rearranged(h): .12f}")

Investigate: note where the displayed answers first disagree and where the direct calculation becomes clearly misleading. Test h=0 and h=−10 separately by calling both functions: why do they return None? Add two moderate offsets of your choice and compare the sign of their difference from 1/6 with your prediction. Finally, write three sentences separating (i) the exact limit, (ii) the evidence of the table and (iii) the effect of rounding. Do not claim a universal “safe smallest input” from a single machine.

Hint for Activity 4.24

Use the denominator of R(h) for your sign prediction. To diagnose the smallest offsets, inspect 9 + 1e-16 == 9 and sqrt(9 + 1e-16) == 3. An equality between stored numbers need not be an equality between the intended real numbers.

Discussion of Activity 4.24

For positive h, the denominator of R exceeds 6, so the exact quotient is less than 1/6. For negative h near zero it is greater than 1/6. Both approach the same value. On the checked ordinary binary floating-point run, the two displayed answers first differ in the last displayed digit at h=10−4; at h=10−16 the direct result is zero, while the rearranged result is approximately 0.166666666667. The negative offsets show corresponding loss of reliability. Your last digits or the first visible disagreement can depend on the arithmetic and display precision.

In that run, adding 10−16 to 9 rounds back to 9. The square root is therefore stored as 3, and subtraction produces zero. Dividing this zero by the nonzero offset gives a misleading zero. The rearranged calculation avoids the damaging subtraction and remains close to 1/6. This does not make it exact: its operations are rounded too.

The guards return None at zero because the original quotient is undefined, and below −9 because the root is not real. We deliberately preserve that original domain in both implementations, although the bare rearranged expression also allows zero. If we wanted a continuous extension, we would define and name it explicitly.

A difference from 1/6 at a nonzero offset is not, by itself, numerical error: the exact finite-offset quotient differs from its limit too. The identity establishes the limit; the table illustrates approach and exposes an unstable evaluation. More samples cannot replace the algebraic justification.

Numerical evidence is most useful when it tests a specific prediction and has a known limitation. A disagreement here sends us back to the evaluation procedure, not to the proved identity. In another problem a disagreement might reveal a wrong model, an invalid domain or an algebra error. Keeping these possibilities distinct makes computation a tool for reasoning rather than a vote on what the mathematics should be.

4.21 Drawing the unit together

We began by asking how a function specifies a relationship. Its formula was only part of the answer: the domain, the assignment of one output to each allowed input, and the order of composition also mattered. Limits then let us describe nearby behaviour independently of an isolated value. Algebra made that description exact in cases where a table or graph could only suggest it. Continuity finally connected the approached value with the value of the function itself.

These ideas give a dependable sequence of questions. Which inputs are allowed? Which rule applies nearby? Do the left and right approaches agree? Is a simplification valid on those inputs? Does the resulting limit equal the assigned value? Computer output can support this reasoning, but its sampling and rounding must be accounted for. The next unit will use limits to investigate rates of change. The algebra of small nonzero offsets is already in place; no new derivative rules are required for the work below.

Exercise 4.1 · Rules and allowed inputs (6 minutes)

Find the largest real domain for each rule: (a) 7−2x; (b) (x+1)/(x2−9); (c) ln(x−2). For (a), also state the range. A proposed relation assigns both 2 and −2 to the input 4. Explain why that relation is not a function with a single real output.

Worked solution to Exercise 4.1

(a) Require 7−2x≥0, hence x≤7/2; the endpoint is included because the square root of zero exists. As the input runs downwards without bound, the radicand and root increase without bound, while the smallest output is zero. Thus the range is [0,∞). (b) Require (x−3)(x+3)≠0, so exclude −3 and 3. A zero numerator at −1 is allowed. (c) Require x−2>0, hence x>2; equality is excluded for a real logarithm. A function assigns exactly one output to each allowed input; two outputs at 4 violate this requirement. The rule x↦x chooses the nonnegative root and does define a function on [0,∞). Revisit §4.1–4.2.

Exercise 4.2 · Order matters (7 minutes)

Let f(x)=x and g(x)=3−x. Find formulas and domains for f∘g and g∘f. Evaluate each at 1. Explain why a shared value at one input would not establish that two functions were equal.

Worked solution to Exercise 4.2

(f∘g)(x)=3−x requires x≤3; its value at 1 is 2. (g∘f)(x)=3−x requires x≥0; its value at 1 is 2. In the first composition the output of g must be a valid input to f; in the second the input must first be allowed by f. Equal functions must have the same domain and agree at every input in it. A single shared value would establish neither condition. Revisit §4.4.

Exercise 4.3 · Read the branches (7 minutes)

A graph follows 2x+1 for x<1 and 5−x for x>1, with a separate filled point at (1,8). Sketch the graph near 1, marking open and filled points. State the point value, both one-sided limits and whether a two-sided limit exists. Would moving the filled point to height 3 change the last answer?

Worked solution to Exercise 4.3

The left branch approaches an open point (1,3); the right branch approaches an open point (1,4). Mark the assigned value as a filled point at (1,8). Thus f(1)=8, the left limit is 3 and the right limit is 4. They disagree, so no two-sided limit exists. Moving the filled point changes only f(1), not either branch or its approach, so the two-sided limit still fails. A correct sketch need not use identical axis scales, but it must label the coordinates and distinguish included from excluded points. Revisit §4.8–4.9.

Exercise 4.4 · Make an error requirement precise (7 minutes)

For f(x)=9−4x, establish the limit at 2 by finding an exact expression for |f(x)−1|. How close to 2 must a nonzero input offset be to guarantee an output error less than 0.006? A table samples only offsets of magnitude 0.1, 0.01 and 0.001. Can that table alone prove your guarantee for every closer input?

Worked solution to Exercise 4.4

|f(x)−1|=|8−4x|=4|x−2|. Requiring 0<|x−2|<0.0015 therefore gives an output error less than 0.006. More generally, any positive output tolerance can be met by choosing an input tolerance one quarter as large, which explains the limit 1. The finite table does not cover every input in that interval. The identity supplies the guarantee. A different function could agree at all the sampled inputs yet behave differently between them. Revisit §4.7 and §4.11.

Exercise 4.5 · Select a method (9 minutes)

Find each limit, stating the condition or algebra that justifies your method: (a) limx→2(x2+3)/(x+1); (b) limx→4(x2−5x+4)/(x−4); (c) limh→0((5+h)2−25)/h. Do any of these limit calculations, by themselves, add a missing point to a domain?

Worked solution to Exercise 4.5

(a) The denominator approaches 3, which is nonzero, so the quotient law gives 7/3. (b) Factor the numerator as (x−4)(x−1). For x≠4 the quotient is x−1, hence its limit is 3. (c) Expanding gives 10h+h2=h(10+h); for h≠0 the quotient is 10+h, with limit 10. Neither cancellation assigns the excluded central value. A limit describes nearby outputs; an extension requires a separate definition. Revisit §4.12–4.13.

Exercise 4.6 · A radical and its domain (8 minutes)

Find limh→0(16+2h−4)/h. Give the original real domain, show the conjugate step and explain why the final denominator allows substitution.

Hint for Exercise 4.6

The difference of squares leaves 2h. Retain that factor 2 after cancelling h.

Worked solution to Exercise 4.6

The original domain is h≥−8 with h≠0. The conjugate 16+2h+4 is positive there. Multiplying numerator and denominator by it gives

16+2h−4h=2hh(16+2h+4)=216+2h+4,h≠0.

The denominator approaches 8, a nonzero number, so the limit is 1/4. Both positive and negative small offsets lie in the domain. Revisit §4.14.

Exercise 4.7 · Nested division (8 minutes)

Find limh→0(1/(4+h)−1/4)/h. Keep the restrictions visible. Check the sign of the answer by considering a small negative h without evaluating a decimal.

Worked solution to Exercise 4.7

The domain excludes −4 and 0. Combining the numerator gives −h/[4(4+h)]. Dividing the whole numerator by h, then cancelling for h≠0, gives −1/[4(4+h)]. Its limit is −1/16. For a small negative h, the positive number 4+h is less than 4, so its reciprocal exceeds 1/4: the original numerator is positive. Division by negative h makes the quotient negative, agreeing with the answer. Revisit §4.15.

Exercise 4.8 · Three different outcomes (8 minutes)

As x→0, classify each function as having a finite two-sided limit or not, and justify the decision: (a) x/|x|; (b) x2/|x|; (c) 1/x2. All three exclude zero. Explain why that shared exclusion does not determine their limits.

Worked solution to Exercise 4.8

(a) The left-hand rule is −1 and the right-hand rule is 1, so no two-sided limit exists. (b) The rule is |x|, which approaches 0 from both sides; the finite limit is 0. (c) Outputs grow beyond every fixed positive bound as nonzero x approaches zero, so there is no finite limit. One may express that unbounded behaviour as 1/x2→+∞, but infinity is not a finite function value. A missing centre tells us nothing by itself about settling, jumping or unbounded growth nearby. Revisit §4.10 and §4.16.

Exercise 4.9 · Design a continuous model (9 minutes)

A dimensionless response is q(x)=x2+2 for x<2, q(x)=ax+b for x>2, and q(2)=c. A calibration requirement also specifies q(4)=10. Determine a,b,c so that the function is continuous at 2 and meets the calibration requirement. Show that it is then continuous on the whole real line.

Hint for Exercise 4.9

Continuity supplies the right branch’s approached value at 2. Together with its value at 4, this gives two linear equations.

Worked solution to Exercise 4.9

The left limit is 22+2=6. Thus 2a+b=6 and c=6. The calibration gives 4a+b=10. Subtracting the first equation from the second gives 2a=4, so a=2 and then b=2. At the join both approaches and the point value are 6. Away from it, each branch is a polynomial and therefore continuous; hence the entire function is continuous. This establishes the mathematical join, not the empirical adequacy of the chosen model for real measurements. Revisit §4.18.

Exercise 4.10 · Composition and an endpoint (7 minutes)

Find the real domain of F(x)=ln(1+4−x). Is F continuous at 0? At 4, which approach is relevant, and what are the limit and point value?

Worked solution to Exercise 4.10

The root requires x≤4. On that domain its value is nonnegative, making the logarithm’s argument at least 1 and therefore positive. The domain is (−∞,4]. At 0 all component continuity conditions hold and F(0)=ln3, equal to the two-sided limit. At 4 only the left approach is available in the domain. The root approaches 0, the logarithm’s argument approaches 1, and the logarithm approaches ln1=0. This equals F(4), so endpoint continuity holds. Revisit §4.19.

Exercise 4.11 · Challenge a numerical conclusion (7 minutes)

A report says, “The direct square-root quotient in Activity 4.24 becomes zero for our smallest input, so its limit is zero. The rearranged rule gives a nonzero value, proving the two formulas are not equal.” Identify the mistakes and replace the report with a sound conclusion. Explain why the difference between a computed value at h=0.1 and 1/6 cannot automatically be labelled rounding error.

Worked solution to Exercise 4.11

A finite set of computed outputs does not prove a limit, and stored floating-point values need not reproduce exact real arithmetic. Conjugate algebra establishes equality of the rules on h≥−9, h≠0, and establishes limit 1/6. The observed disagreement concerns the evaluation procedures: subtracting nearly equal rounded numbers can destroy the small difference used by the direct quotient. A sound report states the exact limit, notes that the rearranged calculation is more reliable in this experiment, and describes the observed rounding failure without claiming perfect accuracy. At a nonzero offset such as 0.1, the exact quotient itself is below 1/6. Its distance from the limit combines finite-offset behaviour with any numerical error; it is not a measurement of rounding alone. Revisit §4.20.

Exercise 4.12 · Construct a counterexample (7 minutes)

A table gives output 2 at inputs x=±0.1,±0.01,±0.001. Construct a function on the real line that agrees with every entry but has limit 5 at zero and value 9 at zero. Decide whether it is continuous there and describe the single change that would repair it. Your rule may be piecewise; there is no unique answer.

Worked solution to Exercise 4.12

One possible construction is

F(x)={9,x=0,5,0<|x|<0.0005,2,|x|≥0.0005.

All six sampled inputs lie in the outer region and give 2. Every sufficiently small nonzero input lies in the middle region and gives exactly 5, so the limit is 5. The point value 9 is different, making the function discontinuous at zero. Replace only F(0) by 5 to repair continuity there; this does not repair the separate jumps at ±0.0005, which were not requested. Accept another construction if it defines exactly one output at every input, matches all six samples, has the specified nearby limit and assigns the required centre value. Revisit §4.11 and §4.17.
