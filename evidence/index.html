PRIVATE WORK · PORTABLE EVIDENCE

Learning evidence

Preserve your work. Choose what to share. Verify when it was committed.

Your tutor maintains the academic journal. Here you can freeze a copy of that record and attach original notebooks or written work. Saved snapshots remain private. Ethereum anchoring is optional, costs a network fee and requires your wallet approval each time.

A verified commitment shows that these records match earlier committed data. It does not establish correct answers, independent authorship, assessed mastery or an accredited qualification. Wallet control is not independent verification of your real-world identity.

Sign in to manage private evidence.

1. Preserve a snapshot

Include all academic journal entries currently saved online. Optionally add original files, up to 3 MB total per snapshot. Files are preserved byte for byte; they are never executed here. Earlier snapshots retain earlier attachments.

Nothing is inferred from page visits. Unimported tutorials and files you have not attached are not captured. Snapshot preparation time is separate from the original record dates and any later blockchain time.

No snapshot selected.

The private JSON download is a recovery package containing all selected snapshot data, original file bytes and secret proof salts. Keep it private. Saved snapshots are covered by the existing daily private database backup; downloaded copies provide an additional recovery route. The blockchain cannot recover lost originals.

2. Anchor on Ethereum — optional

First save the snapshot. Check your wallet to sign a message proving control and see a fee estimate; then choose whether to submit the paid transaction. LibraUni never asks for a seed phrase or private key. This version supports an Ethereum wallet extension on mainnet.

Only the salted root is sent to the existing Ethereum Attestation Service contract, alongside public transaction metadata. No personal details, marks or files are put on-chain. A signed message alone is not an on-chain anchor. Repeated anchoring is your choice, not a background charge.

Recover a transaction receipt

If the transaction was broadcast but online saving failed, open the matching snapshot and recover its downloaded receipt. This checks the existing transaction; it does not send another.

3. Choose evidence to share

Choose complete entries or files. Unselected content stays private. Proofs also disclose the snapshot's preparation time, entry/file counts and previous root. Review your selection before sharing, especially tutorial transcripts.

This package uses EAS PrivateData multiproofs. It is not a Blockcerts certificate. Independent verification instructions are available without a LibraUni account.

Verify a shared proof

No account or wallet required. The file is processed in this browser. When an anchor is supplied, only its public root and transaction are queried through an Ethereum node provider. A failed network check is reported as unconfirmed, not verified.

Use the public EAS contract and the independent EAS SDK to check the same evidence without trusting this page. The convenient verification above is operated by LibraUni; it is not an independent academic assessor.
