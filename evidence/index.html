PRIVATE WORK · PORTABLE EVIDENCE

Learning evidence

Preserve your work. Choose what to share. Verify when it was committed.

Your tutor maintains the academic journal. Your tutor also archives original submissions, corrections and assessment records privately. One button gathers everything already saved into an organised, verifiable download. Saved snapshots remain private. Ethereum anchoring is optional, costs a network fee and requires your wallet approval each time.

A verified commitment shows that these records match earlier committed data. It does not establish correct answers, independent authorship, assessed mastery or an accredited qualification. Wallet control is not independent verification of your real-world identity.

Sign in to manage private evidence.

1. Generate your full student records

Your tutor maintains the archive: activities, handwritten scans, notebooks, TMAs, iCMAs, exams, corrections and the academic journal. Recorded skills, milestones, grades and any actually issued certificates are included when present. You do not need to attach them again.

This collects all saved academic entries and all tutor-archived originals, checks every file, saves a private snapshot and downloads an organised ZIP. The ZIP contains readable records, original files and proofs for each category and individual item. It does not create grades, issue certificates or capture work that has not yet been archived.

“Full” means the academic inventory saved at generation time, including correction history. Website administration, profile details and unavailable external conversations are excluded. The current teaching release is included as context; it does not establish which version was used for earlier work. Snapshot time, original record dates and blockchain time remain distinct. Current safeguards allow originals up to 150 MB each and a 250 MB download; an oversized archive stops with an explanation instead of silently dropping records.

No snapshot selected.

Keep the full ZIP private: it includes all record fields, originals and recovery data. Use the sharing selection below to disclose less. Saved records and originals are included in the private database backup; the downloaded ZIP is an additional copy. Blockchain stores a commitment, not your files.

2. Anchor on Ethereum — optional

Generate or open a saved snapshot first. Check your wallet to sign a message proving control and see a fee estimate; then choose whether to submit the paid transaction. LibraUni never asks for a seed phrase or private key. This version supports an Ethereum wallet extension on mainnet.

Only the salted root is sent to the existing Ethereum Attestation Service contract, alongside public transaction metadata. No personal details, marks or files are put on-chain. A signed message alone is not an on-chain anchor. Repeated anchoring is your choice, not a background charge.

Recover a transaction receipt

If the transaction was broadcast but online saving failed, open the matching snapshot and recover its downloaded receipt. This checks the existing transaction; it does not send another.

3. Choose evidence to share

Choose a category, individual field (such as a grade), original file, or any combination. Each selection has a proof against the same snapshot. Unselected fields and files stay private; the snapshot counts and previous-root context are not added to these new selective exports. Review your selection before sharing, especially tutorial transcripts. Older snapshots retain their original, coarser sharing format.

This package uses EAS PrivateData multiproofs. It is not a Blockcerts certificate. Independent verification instructions are available without a LibraUni account.

Verify a shared proof

No account or wallet required. The file is processed in this browser. When an anchor is supplied, only its public root and transaction are queried through an Ethereum node provider. A failed network check is reported as unconfirmed, not verified.

Verifying a separate category or file proof?

If you received a proof JSON rather than a ZIP, select any original files it covers here. A field-only proof needs no extra file: the verified value is displayed from the proof itself.

Use the public EAS contract and the independent EAS SDK to check the same evidence without trusting this page. The convenient verification above is operated by LibraUni; it is not an independent academic assessor.
