Worked example

Read the example one line at a time. Identify the inputs, predict the displayed quantities, then type and run it in your selected notebook kernel. Library calls are explained in this section; preserve your own prediction before execution.

Type, predict, run

import numpy as np
import matplotlib.pyplot as plt
t = np.array([0, 3, 6, 9])
fraction = 2.0 ** (-t / 3)
plt.semilogy(t, fraction, "o-")
plt.xlabel("Time / s")
plt.ylabel("N / N0 (dimensionless)")
plt.show()
print(-3 * np.log(0.1) / np.log(2))

Work, explain and check

Verification should target a possible failure. Check an ordinary input, a boundary or excluded input where relevant, and a result you can obtain independently by hand. Do not execute an unknown proposed program merely because it is described as helpful.

Worked example

N/N₀=2^(−t/3) gives half-life3 time units. At t=6 the fraction is1/4. To reach1/10, t=−3 ln(0.1)/ln2≈9.97. For y/y₀=exp(kt), ln(y/y₀)=kt: a semilog representation is straight. For y/y₀=(x/x₀)^p, a log–log representation has slopep.

Work it through

Show intermediate steps and give units or restrictions where relevant. For code, record a prediction before running.

  1. Solve2^t=16.
  2. Simplify ln(a²/b) for a,b>0.
  3. For y=3x², what is the output factor if x triples? Contrast doubling time in an exponential.
Feedback and worked answers
  1. t=4.
  2. 2ln a−ln b.
  3. Factor9; exponential change is characterised by equal time increments, not generally by multiplying time.
