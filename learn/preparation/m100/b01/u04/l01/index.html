U04-L01-S01 · 84 MINUTES · BLUEPRINT

Equivalent changes preserve solutions

Use balance reasoning for adding/subtracting and multiplying/dividing by known non-zero quantities.

Practice / assignment
Move from one unknown on one side to brackets/fractions and a supplied physical relation; explain every transformation.
Expected evidence
Worked reasoning with any correction retained and explained; no requirement to submit every practice item.
Feedback
Provide two worked examples with fading support, then four graduated prompts and one error-analysis item; explain the first invalid step. Adjust item count after timing review, within this allocation.
Visual support
Balanced operations and an annotated solution chain.
Handover
Carry the explained result and any unresolved difficulty into Solve and substitute back.

Prerequisites: U03-L05. Allocation in minutes (explanation / mathematics / Python / application / review): 36 / 48 / 0 / 0 / 0.
