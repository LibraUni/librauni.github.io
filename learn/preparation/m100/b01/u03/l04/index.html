U03-L04-S01 · 60 MINUTES · BLUEPRINT

A calculation has conditions

Translate a denominator or physical-input restriction into a precise numerical statement; distinguish validity from correctness.

Practice / assignment
Trace a valid and invalid sensor-model input before writing a guard. Repair an indentation or assignment/comparison error.
Expected evidence
Worked reasoning with any correction retained and explained; no requirement to submit every practice item.
Feedback
Provide two worked examples with fading support, then four graduated prompts and one error-analysis item; explain the first invalid step. Adjust item count after timing review, within this allocation.
Visual support
Two-branch decision diagram tied to a denominator restriction.
Handover
Carry the explained result and any unresolved difficulty into Trace the allowed and forbidden cases.

Prerequisites: U03-L03. Allocation in minutes (explanation / mathematics / Python / application / review): 36 / 24 / 0 / 0 / 0.

U03-L04-S03 · 90 MINUTES · BLUEPRINT

Boolean comparisons and if/else

Teach True/False, ==, !=, <, >, <=, >=, colon and indentation; type a single-condition guard and repair comparison/assignment confusion.

Practice / assignment
Introduce Boolean values, ==, !=, <, >, <=, >= and a short if/else with indentation. Begin with one condition; combined Boolean logic is optional backup, not required.
Expected evidence
A saved notebook with predictions, learner-typed code, outputs and a short explanation; rerun from a clean kernel.
Feedback
Use predict–run–explain, then an annotated reference solution; diagnose syntax separately from reasoning.
Visual support
An annotated code/output pair with a plain-text equivalent.
Handover
Carry the explained result and any unresolved difficulty into Guard a sensor calculation.

Prerequisites: U03-L04-S02. Allocation in minutes (explanation / mathematics / Python / application / review): 0 / 0 / 90 / 0 / 0.
