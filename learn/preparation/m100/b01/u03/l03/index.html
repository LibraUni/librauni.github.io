SECTION 1 · ABOUT 84 MINUTES

Factor first, then cancel

Factorisation reverses distribution: identify a factor multiplying every term and put it outside brackets. Cancellation is division of the whole numerator and denominator by a common non-zero factor. It does not remove selected terms from a sum. An excluded input remains excluded after simplification, even if the simplified formula happens to have a value there. Retain that restriction alongside your answer.

Worked example

(6x + 9)/3 = 3(2x + 3)/3 = 2x + 3. In contrast, (x² + 3x)/x = x(x + 3)/x = x + 3 only for x ≠ 0. The original fraction does not acquire a value at zero through cancellation.

Work it through

Show intermediate steps and give units or restrictions where relevant. For code, record a prediction before running.

  1. Factor 8x + 12 and 6a² − 9a.
  2. Simplify (10x + 15)/5.
  3. Simplify (x² − 4x)/x and retain its restriction.
  4. Why is (x + 2)/x not generally 2? Give a permitted counterexample.
Feedback and worked answers
  1. 4(2x + 3) and 3a(2a − 3).
  2. 2x + 3.
  3. x − 4, x ≠ 0.
  4. At x = 2 the original is 2, so that test happens to agree; at x = 1 it is 3, disproving the general claim. Only factors cancel.

SECTION 2 · ABOUT 96 MINUTES

Equivalent expressions with restrictions

To add algebraic fractions, use a common denominator exactly as with numerical fractions. Multiply the numerator as well as the denominator when changing a fraction’s form. State restrictions from the original denominators first. For products, factor before cancelling. A numerator becoming zero is usually allowed; a denominator becoming zero is not. Keep these different cases separate.

Worked example

1/x + 2/(3x) = 3/(3x) + 2/(3x) = 5/(3x), x ≠ 0. Also (2x + 4)/(x + 2) = 2(x + 2)/(x + 2) = 2 for x ≠ −2. The restriction survives even though the final expression looks constant.

Work it through

Show intermediate steps and give units or restrictions where relevant. For code, record a prediction before running.

  1. Simplify 3/x − 1/(2x), giving restrictions.
  2. Simplify (4x + 8)/(2x + 4), giving restrictions.
  3. Simplify (3x/4) × (8/(9x)), giving restrictions.
  4. At which input is (x − 2)/(x + 2) zero, and at which is it undefined?
  5. Explain the error in (a + b)/(a + c) = b/c. Test a = 1, b = 2, c = 3.
Feedback and worked answers
  1. 5/(2x), x ≠ 0.
  2. 2, x ≠ −2.
  3. 2/3, x ≠ 0.
  4. Zero at x = 2; undefined at x = −2.
  5. There is no common factor a to cancel. The values are 3/4 and 2/3.

SECTION 3 · ABOUT 60 MINUTES

Evaluate only permitted inputs

ZeroDivisionError reports an attempted division by zero. It identifies an invalid arithmetic operation, not an instruction to ignore the restriction. First evaluate both forms at permitted inputs. Then deliberately try an excluded value in a separate cell, read the last line of the error, and explain it. Remove or comment out that deliberate error before your final clean run. A comment starts with # and is ignored by Python.

Worked example

For (x² + 3x)/x and x + 3, x = 2 gives 5 in both forms. With x = 0 the original raises ZeroDivisionError, while the simplified expression alone gives 3. That difference is why the domain is part of the equivalence statement.

Type, predict, run

x = 2
original = (x ** 2 + 3 * x) / x
simplified = x + 3
print(original)
print(simplified)

Work it through

Show intermediate steps and give units or restrictions where relevant. For code, record a prediction before running.

  1. Run at x = 2 and −3; predict both outputs.
  2. In a separate cell try x = 0 in the original expression. Identify the denominator responsible.
  3. Explain why replacing the failed result with 3 would change the defined problem.
  4. Restore a permitted input and restart/run the notebook in order.
Feedback and worked answers
  1. 5 and 0 respectively, with agreement at both permitted values.
  2. The divisor x is zero; the calculation is undefined.
  3. The original rule excludes zero. Assigning a value there defines an extension, which has not been requested or justified by cancellation.
  4. A reproducible notebook should run without unintended errors and state x ≠ 0.

SECTION 4 · ABOUT 30 MINUTES

A ratio in a supplied measurement relation

Average speed in a supplied constant-speed model is distance divided by elapsed time. If distance is written vt, then vt/t = v for t ≠ 0. In the physical interval model we normally require t > 0 as well. An algebraic restriction and a physical restriction can differ: negative time intervals may be allowed algebraically but excluded by the meaning of a particular experiment.

Worked example

At v = 4 m/s and t = 3 s, distance is 12 m and distance/time is 4 m/s. At t = 0, the quotient is 0/0 and undefined. The simplified symbol v does not make that quotient defined.

Work it through

Show intermediate steps and give units or restrictions where relevant. For code, record a prediction before running.

  1. Evaluate vt/t for v = 6 m/s and t = 2 s.
  2. State the algebraic and physical restrictions on t.
  3. A fixed delay gives total distance v(t − τ). Simplify v(t − τ)/t without cancelling terms across subtraction.
  4. For v = 6 m/s, t = 4 s, τ = 1 s, evaluate the last expression.
Feedback and worked answers
  1. 6 m/s.
  2. Algebraically t ≠ 0; as a positive elapsed observation interval t > 0.
  3. v − vτ/t, t ≠ 0.
  4. 4.5 m/s; the delay reduces the average over the whole interval.

SECTION 5 · ABOUT 30 MINUTES

Restriction checkpoint

A useful simplification record contains the original expression, the factored form, the final expression and the original restrictions. Use a fresh numerical input to catch errors, then identify the algebraic law that justifies each step. If cancellation is tempting, point to the common factor of the whole numerator and denominator before doing it.

Worked example

(5x − 10)/(x − 2) = 5(x − 2)/(x − 2) = 5, x ≠ 2. A check at x = 3 gives 5, but the written factorisation is the justification.

Work it through

Show intermediate steps and give units or restrictions where relevant. For code, record a prediction before running.

  1. Simplify (7x + 14)/(x + 2) completely, with domain.
  2. Find a counterexample to (x + 5)/x = 5.
  3. Simplify 1/(2x) + 1/(4x), with domain.
  4. Explain in one sentence why a zero numerator and a zero denominator play different roles.
Feedback and worked answers
  1. 7, x ≠ −2.
  2. At x = 1 the left side is 6, not 5.
  3. 3/(4x), x ≠ 0.
  4. Zero divided by a non-zero number is zero; division by zero is undefined.
