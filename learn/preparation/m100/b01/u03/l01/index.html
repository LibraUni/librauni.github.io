U03-L01-S01 · 84 MINUTES · BLUEPRINT

What a symbol stands for

Distinguish variables, constants and parameters; annotate their units and meanings in supplied relations.

Practice / assignment
Compare abstract expressions and a supplied sensor offset/scale model. Evidence: annotated symbol roles and a correct substitution.
Expected evidence
Worked reasoning with any correction retained and explained; no requirement to submit every practice item.
Feedback
Provide two worked examples with fading support, then four graduated prompts and one error-analysis item; explain the first invalid step. Adjust item count after timing review, within this allocation.
Visual support
Expression annotated by roles and units.
Handover
Carry the explained result and any unresolved difficulty into Translate and substitute with structure intact.

Prerequisites: U02-L04. Allocation in minutes (explanation / mathematics / Python / application / review): 36 / 48 / 0 / 0 / 0.
