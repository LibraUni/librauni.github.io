U03-L05-S01 · 60 MINUTES · BLUEPRINT

Three different kinds of claim

Distinguish identity, equation and agreement at a selected input; state the permitted domain.

Practice / assignment
Mixed simplification and fresh counterexamples; written algebra supplies justification when numerical agreement is insufficient.
Expected evidence
Worked reasoning with any correction retained and explained; no requirement to submit every practice item.
Feedback
Provide two worked examples with fading support, then four graduated prompts and one error-analysis item; explain the first invalid step. Adjust item count after timing review, within this allocation.
Visual support
Comparison of claim, permitted domain, example and counterexample.
Handover
Carry the explained result and any unresolved difficulty into Proof and counterexample do different jobs.

Prerequisites: U03-L04. Allocation in minutes (explanation / mathematics / Python / application / review): 36 / 24 / 0 / 0 / 0.

Sampling does not prove an identity

Practice / assignment
Test two expressions at individually assigned inputs, then explain the limit of the test. Do not introduce loops early.
Expected evidence

Feedback
Use predict–run–explain, then an annotated reference solution; diagnose syntax separately from reasoning.
Visual support
