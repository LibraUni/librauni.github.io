U02-L03-S01 · 84 MINUTES · BLUEPRINT

Quantities, units and conversion factors

Distinguish a physical quantity from its numerical value; teach SI prefixes and conversion ratios equal to one.

Practice / assignment
Conversion chains advance from length to area and speed; explain why a length factor must be squared for area.
Expected evidence
Worked reasoning with any correction retained and explained; no requirement to submit every practice item.
Feedback
Provide two worked examples with fading support, then four graduated prompts and one error-analysis item; explain the first invalid step. Adjust item count after timing review, within this allocation.
Visual support
Cancelling-unit chains and matching length/area diagrams.
Handover
Carry the explained result and any unresolved difficulty into Compound and squared units.

Prerequisites: U02-L02. Allocation in minutes (explanation / mathematics / Python / application / review): 36 / 48 / 0 / 0 / 0.

U02-L03-S03 · 30 MINUTES · BLUEPRINT

A conversion that does not hide its units

Type an explicit scalar conversion, compare to hand work and diagnose a mixed-unit result.

Practice / assignment
Write a scalar conversion with units in names and explanation. Inspect a unit-mixing error; ordinary Python numbers carry no automatic units.
Expected evidence
A saved notebook with predictions, learner-typed code, outputs and a short explanation; rerun from a clean kernel.
Feedback
Use predict–run–explain, then an annotated reference solution; diagnose syntax separately from reasoning.
Visual support
An annotated code/output pair with a plain-text equivalent.
Handover
Carry the explained result and any unresolved difficulty into Compare journeys on one consistent scale.
