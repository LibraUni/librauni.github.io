U02-L02-S01 · 60 MINUTES · BLUEPRINT

Write a number as a scale and a coefficient

Normalise positive and negative exponents of ten; include small values and zero without assigning zero an order of magnitude.

Practice / assignment
Progress from abstract scale comparisons to supplied light-travel values. Estimate the power of ten before calculating.
Expected evidence
Worked reasoning with any correction retained and explained; no requirement to submit every practice item.
Feedback
Provide two worked examples with fading support, then four graduated prompts and one error-analysis item; explain the first invalid step. Adjust item count after timing review, within this allocation.
Visual support
Labelled scale ladder; no logarithmic axis assumed.
Handover
Carry the explained result and any unresolved difficulty into Compare scales before calculating.

Prerequisites: U02-L01. Allocation in minutes (explanation / mathematics / Python / application / review): 36 / 24 / 0 / 0 / 0.

U02-L02-S03 · 60 MINUTES · BLUEPRINT

Scientific notation in code

Use e notation and labelled inputs; distinguish a rounded display from a stored numerical value.

Practice / assignment
Use e notation, named quantities and explicit unit labels; compare rounded displays with retained values.
Expected evidence
A saved notebook with predictions, learner-typed code, outputs and a short explanation; rerun from a clean kernel.
Feedback
Use predict–run–explain, then an annotated reference solution; diagnose syntax separately from reasoning.
Visual support
An annotated code/output pair with a plain-text equivalent.
Handover
Carry the explained result and any unresolved difficulty into Light-travel estimates.
