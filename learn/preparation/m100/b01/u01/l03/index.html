U01-L03-S01 · 72 MINUTES · BLUEPRINT

A percentage needs a reference base

Translate percentage to a fraction of a named whole; distinguish percentage change from percentage points.

Practice / assignment
Abstract percentage practice followed by a supplied measurement comparison; diagnose the wrong reference base and report a sensible result.
Expected evidence
Worked reasoning with any correction retained and explained; no requirement to submit every practice item.
Feedback
Provide two worked examples with fading support, then four graduated prompts and one error-analysis item; explain the first invalid step. Adjust item count after timing review, within this allocation.
Visual support
Same percentage applied to different bases; labelled estimate and calculation comparison.
Handover
Carry the explained result and any unresolved difficulty into Estimate first, round last.

Prerequisites: U01-L02. Allocation in minutes (explanation / mathematics / Python / application / review): 36 / 36 / 0 / 0 / 0.

U01-L03-S03 · 60 MINUTES · BLUEPRINT

Change the input, explain the output

Reassign a measurement, predict the new percentage and diagnose a misspelled name from NameError.

Practice / assignment
Reassign a named input, predict changes and read a simple NameError. Explain that a long decimal display does not establish accuracy.
Expected evidence
A saved notebook with predictions, learner-typed code, outputs and a short explanation; rerun from a clean kernel.
Feedback
Use predict–run–explain, then an annotated reference solution; diagnose syntax separately from reasoning.
Visual support
An annotated code/output pair with a plain-text equivalent.
Handover
Carry the explained result and any unresolved difficulty into Reporting a measurement comparison.

Prerequisites: U01-L03-S02. Allocation in minutes (explanation / mathematics / Python / application / review): 0 / 0 / 60 / 0 / 0.
