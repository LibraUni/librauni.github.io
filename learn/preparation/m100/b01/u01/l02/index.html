U01-L02-S01 · 72 MINUTES · BLUEPRINT

Equivalent fractions and a common unit

Use fraction strips to explain equivalence and a common denominator; distinguish numerator from denominator.

Practice / assignment
Worked-to-independent fraction combinations; compare an exact hand result with a decimal display. Use a supplied elapsed-time ratio with units.
Expected evidence
Worked reasoning with any correction retained and explained; no requirement to submit every practice item.
Feedback
Provide two worked examples with fading support, then four graduated prompts and one error-analysis item; explain the first invalid step. Adjust item count after timing review, within this allocation.
Visual support
Fraction strips with accessible labels; exact and approximate representations side by side.
Handover
Carry the explained result and any unresolved difficulty into Combine fractions; retain an exact answer.

Names, assignment and printed values

Type a named calculation, predict reassignment, and distinguish = from equality; compare exact hand work with int/float output.

Practice / assignment
Introduce names, assignment, int/float values and print; explain that assignment stores a value and is not an equation to solve. Use ordinary arithmetic, not a fraction library.

Feedback

Visual support
