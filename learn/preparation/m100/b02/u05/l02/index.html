LEARNING MATERIALS

Arrays, data and labelled plots

NumPy arrays store numerical sequences and apply arithmetic element by element. import introduces a library; as gives it a short name. Matplotlib plots corresponding x/y values; labels and units are part of the result. np.loadtxt reads a simple numeric CSV: delimiter names the separator and skiprows=1 skips its header. A[:, 0] selects all rows of the first column; indexing begins at zero. Use the supplied CSV beside your notebook. Worked example

Read the example one line at a time. Identify the inputs, predict the displayed quantities, then type and run it in your selected notebook kernel. Library calls are explained in this section; preserve your own prediction before execution.

Type, predict, run

import numpy as np
import matplotlib.pyplot as plt
data = np.loadtxt("position.csv", delimiter=",", skiprows=1)
time_s = data[:, 0]
position_m = data[:, 1]
plt.plot(time_s, position_m, "o-")
plt.xlabel("Time / s")
plt.ylabel("Position / m")
plt.show()

Work, explain and check

Worked example

Positions 3, 7 and 11 m at times 0, 2 and 4 s give slope (11 − 3)/4 = 2 m/s and s = 3 + 2t. At 3 s interpolation gives 9 m. Predicting 23 m at 10 s is extrapolation and needs the constant-rate assumption.
