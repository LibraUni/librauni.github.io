U05-L01 · Reading graphs and rates

Coordinates describe quantities, not a picture of the object’s path. Label both axes and units. For a straight line y = mx + c, c is the vertical intercept and m = (y₂ − y₁)/(x₂ − x₁). A horizontal position–time segment is stationary; a negative slope means decreasing position. Average rate over an interval is a secant slope, not an instantaneous derivative. Interpolation estimates between observations; extrapolation assumes the relationship continues beyond them.

U05-L02 · Arrays, data and labelled plots

NumPy arrays store numerical sequences and apply arithmetic element by element. import introduces a library; as gives it a short name. Matplotlib plots corresponding x/y values; labels and units are part of the result. np.loadtxt reads a simple numeric CSV: delimiter names the separator and skiprows=1 skips its header. A[:, 0] selects all rows of the first column; indexing begins at zero. Use the supplied CSV beside your notebook. If libraries are missing, install numpy and matplotlib in the selected notebook environment, then restart the kernel.
