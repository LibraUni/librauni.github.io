U07-L01 · Quadratics and excluded inputs

Factorisation can reveal quadratic roots: x²−5x+6=(x−2)(x−3). A product is zero when at least one factor is zero. Completing the square gives x²−4x+1=(x−2)²−3, identifying vertex (2,−3). For ax²+bx+c=0 with a≠0, roots are (−b±√(b²−4ac))/(2a). The discriminant D=b²−4ac distinguishes two, one repeated, or no real roots. A rational expression remains undefined where its original denominator is zero; plotted lines must not bridge that gap.

U07-L02 · Plotting, debugging and a saved baseline

np.linspace creates evenly spaced points. Plot separate intervals on either side of an excluded input so a connecting line does not invent values there. Debug by stating the expected result, isolating the smallest failing calculation, changing one thing and checking again. Before editing, save a baseline copy. If Git is already available, git init, git add and git commit record a local snapshot; git diff shows changes. Practise only in a disposable folder, never in the website repository. A manual baseline/diff exercise is sufficient for this prototype.
