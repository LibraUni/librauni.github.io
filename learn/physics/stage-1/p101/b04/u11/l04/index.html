P101 · Unit 11 · Lesson 4

Magnetic interactions and a checked field calculation

Different fields require different descriptions of the probe’s response. We first examine what a magnetic field map means, then return to radial gravitational and electric work for a calculation whose exact answer lets us judge a numerical approximation.

Allow four hours: 35 minutes for the explanation, 15 minutes for the magnetic activity, ten minutes for its feedback, and three hours for the Python investigation including its feedback and report. Download the notebook or Python companion.

11.13 Magnetic fields and what a probe reveals

A small freely turning compass placed near a bar magnet changes its orientation from place to place. Its north-seeking end defines the local magnetic-field direction. We denote that field by B; its SI unit is the tesla, symbol T. A compass samples a direction through the turning effect on a magnetic needle. It is not a measurement of electric force per unit charge.

A bar magnet has north and south poles. Like poles repel and unlike poles attract. Outside the bar, the conventional field direction runs away from its north pole and towards its south pole. The lines continue through the magnet to make a continuous pattern. Cutting an ordinary bar magnet produces smaller magnets with both poles, rather than separating a north pole from a south pole.

Moving electric charges also participate in magnetic interactions. A current—a flow of charge—produces a magnetic field, and an external magnetic field can exert a force on a current-carrying wire. This connection will give useful context to circuits, although Unit 12 concentrates on charge and energy balances rather than calculating magnetic fields around wires.

For a classical point charge, the magnetic part of the force depends on its velocity as well as on its charge and the local field. A charge at rest has zero magnetic force. Motion parallel or antiparallel to B also gives zero magnetic force. For other directions, that force is perpendicular to both the velocity and the field; reversing the charge sign reverses the force for the same velocity. We will leave its quantitative vector law to later electromagnetism.

This perpendicularity has an immediate energy consequence using Unit 6: the magnetic force on a moving point charge does no work, because it is perpendicular to the instantaneous displacement. In a purely magnetic field a classical particle can turn while its speed remains constant. An electric field can instead have a component along the motion and change the speed. A magnetic needle can rotate and a magnet can pull another magnet closer; those involve extended magnetic objects and their interaction energy, so the point-charge statement should not be applied to every magnetic system.

Discussion of Activity 11.13

Just beyond the right-hand north pole, the field points away to the right; just beyond the left-hand south pole it points towards the pole, also to the right. The filings reveal orientations and a spatial pattern, but not calibrated field magnitudes. A point charge at rest experiences no magnetic force. A moving charge can be deflected if its velocity is not parallel to the field. Perpendicular force does no work, so this magnetic force alone cannot double its speed.

For the numerical investigation we now return to the radial forces whose work laws we have derived. They provide a clear energy benchmark. The magnetic comparison has helped establish why a field calculation must begin with the correct response law rather than a generic “field times charge” formula.

11.14 A transparent numerical work calculation

Both radial models can be written Fr=C/r2. For gravity C=−GMm; for an electric source and probe C=keQq. In either case C has units Nm2 and can be carried as one supplied parameter. It is a coefficient, not the coulomb unit symbol. Its sign preserves the outward-positive convention.

Divide the radial interval from a to b into n equal pieces. Their signed width is (b−a)/n. We use the midpoint of each piece as the representative radius. With Python indices i=0,…,n−1, the sample radius is a+(i+12)(b−a)/n. Multiplying the force there by the width gives one approximate work contribution. This is the same small-contribution reasoning used in Lesson 2; changing the number of pieces changes its resolution.

The following implementation makes the loop visible. It first checks the chosen model domain. A straight radial interval stays exterior to a source of radius radius if both endpoints do; the minimum endpoint is therefore sufficient for this particular path. A zero point-source radius still requires strictly positive endpoints. These checks are properties of the model, not simply ways to suppress a programming error.

"""P101 Unit 11: radial work. Original LibraUni code, MIT.
All parameters use SI units. C has units N m^2; radius/a/b are in m.
This computes work from a supplied fixed-source model, not observations.
"""
from math import isfinite


def radial_work(C, a, b, n, radius=0.0):
    """Midpoint sum for F_r = C/r**2 on an exterior radial path."""
    if isinstance(n, bool) or not isinstance(n, int) or n <= 0:
        raise ValueError("n must be a positive integer")
    if not all(isfinite(x) for x in (C, a, b, radius)):
        raise ValueError("Use finite model parameters")
    if radius < 0 or min(a, b) <= 0 or min(a, b) < radius:
        raise ValueError("The whole path must be at positive exterior radii")
    width = (b - a) / n
    total = 0.0
    for i in range(n):
        r = a + (i + 0.5) * width
        force = C / r**2
        total += force * width
    return total


def exact_work(C, a, b, radius=0.0):
    """Analytic benchmark with the same physical-domain checks."""
    radial_work(C, a, b, 1, radius)
    return C * (1 / a - 1 / b)

range(n) provides exactly n indices. The half-step places each sample inside its interval. If b < a, the width is negative and the samples run inwards; the same code then gives the reversed work. If the endpoints are equal, every width is zero and the returned work is zero. The helper exact_work uses the analytic result C(1/a−1/b) with the same domain check.

Activity 11.14 · Trace before trusting (60 minutes, including feedback)

Use C=−6.0Nm2, a=2.0m, b=6.0m, source radius 1.0 m and n=2. Write the width, both sample radii, force values and work contributions on paper. Then write your own loop in the notebook’s empty cell and compare it with the supplied function. Explain why doubling the number of sampled points without changing the width would be wrong.

Discussion of Activity 11.14

The width is 2.0 m and the midpoint radii are 3.0 and 5.0 m. The forces are −2/3 N and −0.24 N. Contributions are −4/3 J and −0.48 J, total about −1.813333 J. The exact answer is −2.0 J. Increasing n must reduce the width so that the pieces still cover the same 4.0 m interval once. An acceptable implementation computes each midpoint, evaluates the signed force, multiplies by width and adds to a fresh total. Compare intermediate values if the two implementations disagree.

11.15 Refinement, exact checks and physical limits

The notebook prints estimates for 4, 8, 16 and 32 pieces, alongside the signed difference “estimate minus analytic benchmark”. It also plots absolute error in joules against the number of pieces. The distinction between signed and absolute error is useful: the signed error tells us which side of the benchmark the estimate lies, while its magnitude measures the size of the discrepancy.

In this outward gravitational example the force is negative and curves downwards as a function of radius: d2(−6/r2)/dr2=−36/r4<0. On each interval its midpoint value lies above the interval’s mean value. The midpoint sum is therefore less negative than the exact work. Smaller pieces reduce that curvature effect. You can also establish the tendency by calculating a few cases without using the second derivative.

A decreasing error supports the numerical approximation for this model and interval. An independently derived exact value also tests the implementation. Neither observation establishes that a real source is spherical, fixed or accurately described by the chosen coefficient. To test those physical assumptions requires appropriate observations. Keep those three questions separate in the report: is the equation appropriate, is it implemented correctly, and is the approximation sufficiently accurate?

Activity 11.15 · Make the checks ask different questions (50 minutes, including feedback)

Run the notebook’s refinement table, adding 64 and 128 pieces. Compare the absolute errors for successive doublings. Reverse the endpoints, then double C. Predict the effect before running each case. Record enough values to explain the trend rather than reporting only the final output.

Discussion of Activity 11.15

The 4-piece estimate is about −1.944439 J, with error +0.055561 J. At 8 pieces the estimate is about −1.985279 J. The absolute error falls by roughly a factor of four when the piece count doubles once the intervals are sufficiently small; this is evidence of the midpoint approximation’s behaviour on this smooth interval, not a universal numerical guarantee. Reversing the endpoints reverses the result, apart from roundoff, because the same midpoint contributions have negative widths. Doubling C doubles the work and its signed error. Orientation and scaling checks test different features from refinement.

11.16 A bounded electric investigation

To test whether your reasoning transfers, keep the algorithm but change the physical coefficient. Use a fixed electric source Q=+4.0nC and a probe q=−2.0nC. Let the source model apply outside radius 0.020 m and move radially from 0.10 m to 0.30 m. The force is inward and the displacement outward, so electric work should be negative. This sign prediction is independent of the loop.

Derive the benchmark twice: first integrate keQq/r2, then use the source potential difference and W=−qΔV. Write the units with the hand calculation before entering bare numbers in Python. The program’s variables follow an SI convention; Python does not automatically know that 0.10 is a radius in metres.

Discussion of Activity 11.16

C=−7.192×10−8Nm2. Both hand routes give W≈−4.79467×10−7J. Sixteen pieces meet the stated absolute-error tolerance; a different justified finer choice is acceptable. Reversing q changes the work sign, leaving the source potential unchanged. Equal valid endpoints return zero. The zero radius, interior endpoint and invalid piece counts are rejected. Without the domain guard an interior sample could produce a finite number while using the exterior model in a region where it is unjustified.
