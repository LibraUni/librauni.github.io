P101 · Unit 9

Travelling waves and superposition · Reference

Recall: retrieve fluently. Understand: explain the conditions. Consult: look up a pattern. Printable reference PDF.

UseTopicResult and conditions
RecallSpace and timeλ: spatial repetition / m. T: time repetition / s. f=1/T / Hz. Propagation speed vw=fλ.
RecallPhase scalesk=2π/λ / rad m⁻¹; ω=2πf / rad s⁻¹. kx, ωt, ϕ: rad.
RecallTravelling profiley=Acos(kx−ωt+ϕ): rightward for k,ω>0. Plus time term: leftward. Speed ω/k; local material motion differs.
UnderstandLinear superpositiony=y1+y2, at the same position/time and common zero. Small disturbances in a linear model; add signed deviations.
ConsultEqual-wave phase sumSame direction, frequency, wavelength, amplitude: y=2Acos(δ/2)cos(θ+δ/2), θ=kx−ωt. Amplitude 2A|cos(δ/2)|.
UnderstandPath differenceIn-phase sources, common wavelength: Δr=mλ reinforces; Δr=(m+12)λ opposes. Equal arriving amplitudes needed for zero. Integer m.
RecallStanding waveAsin(kx−ωt)+Asin(kx+ωt)=2Asin(kx)cos(ωt). Equal opposite components; local amplitude 2A|sin(kx)|.
RecallNodes / antinodesFor that sine form: nodes x=nλ/2; antinodes x=(2n+1)λ/4, integer n. A node is zero at all times.
RecallFixed-end modesλn=2L/n; fn=nvw/(2L), n=1,2,…. Uniform string, common speed, fixed ends; n lobes, n−1 interior nodes.
UnderstandBoundary responseTransverse string displacement: fixed end inverts; ideal free end does not. Stationary linear boundary, steady source: frequency unchanged; λ2=v2/f.
UnderstandDiffraction scaleOpening width a: compare a/λ. Large ratio: narrower main spread; comparable/smaller ratio: broader spread. Spread and transmitted power differ.
UnderstandValidationCheck a signed value, crest or node, a nonzero antinode and endpoints. Refine sampling. Model agreement tests implementation; observations test physical suitability.

Consult · Python

Metres, seconds and radians; tolerance below is for these synthetic metre-scale values.

import numpy as np
x = np.linspace(0, 2, 401)       # metres
A, lam, f, t = 0.003, 2.0, 1.0, 0.0
k, omega = 2*np.pi/lam, 2*np.pi*f
phase = k*x - omega*t
y1 = A*np.cos(phase)
y2 = A*np.cos(phase + np.pi)
y = y1 + y2
assert np.allclose(y, 0, rtol=0, atol=1e-12)
# Standing product: equal sine components
standing = 2*A*np.sin(k*x)*np.cos(omega*t)
