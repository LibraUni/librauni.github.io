M101 · Unit 9 · Lesson 6

Mixed practice and unit synthesis

Bring the method, the interval and the checks into one coherent solution.

The earlier lessons developed techniques separately so that their reasoning could be seen clearly. A new problem does not usually announce its method. In this final lesson you will select and, where useful, combine the tools, audit their implementation and review the ideas that connect them.

Four hours: 25 minutes synthesis reading and the short opening activity, 65 minutes closing exercise attempts, 65 minutes exercise feedback, 60 minutes Python and 25 minutes reference revision. The 100 minutes reserved in Lessons 1–5 bring closing attempts to 165 minutes in total.

9.21 Let one method prepare another

A substitution may reveal a simpler integral that still needs parts. At each stage, ask what the new representation has achieved. You should be able to explain both decisions using the same criteria as before.

Example 9.18 · Substitution followed by parts

Evaluate ∫01x(x2+1)ex2+1dx.

The expression x2+1 occurs twice, while its derivative is proportional to the outside x. Set u=x2+1, so xdx=du/2; the endpoints become 1 and 2. Then

∫01x(x2+1)ex2+1dx=12∫12ueudu.

The transformed product is suited to parts. To avoid confusing the integration variable u with a label in the parts formula, use the full product-rule statement: (ueu)′=eu+ueu, where the prime now means differentiation with respect to u. Thus an antiderivative of ueu is (u−1)eu, and

12[(u−1)eu]12=e22.

A useful independent check is to return to the original variable before evaluating. The antiderivative is x2ex2+1/2. Its derivative is xex2+1+x3ex2+1, exactly the original integrand. Its endpoint difference is e2/2.

Activity 9.21 · Explain the sequence Within the 25-minute synthesis allocation

Without calculating again, explain why the first step in Example 9.18 is useful, why the remaining integral suits parts, and why the final answer has no arbitrary constant. What would change if the original limits were reversed?

Discussion of Activity 9.21

The substitution replaces the repeated inner expression and absorbs its derivative factor, leaving a simple product. Differentiating the new variable's linear factor reduces it to 1, while integrating its exponential keeps the same form. Fixed endpoints give a number; any antiderivative constant cancels. Reversed original limits give the negative result, −e2/2.

9.22 Check the formula and its implementation

A correct mathematical derivation and a correct program are two separate achievements. A missing bracket or multiplication can change the function being evaluated even when the handwritten work is sound. Test the implementation against values you obtained independently.

Return to Part B of the notebook or Python companion. It supplies a deliberately incorrect implementation of the intended antiderivative F(x)=(x−1)ex of xex. The error is an object for investigation, clearly labelled in the file.

Activity 9.22 · Part B: audit and repair 60 minutes, including feedback

  1. Use 10 minutes to verify the intended formula by differentiation and predict its values at −1, 0 and 1.
  2. Spend 10 minutes predicting its changes on [0,1], [1,0] and [0.5,0.5]. Keep these predictions separate from the program.
  3. Run the supplied implementation. For 15 minutes, trace the first mismatch to the expression in the return statement, repair it and rerun all cases.
  4. Spend 15 minutes adding two tests of your own, including an interval with negative endpoints. Explain what each test checks.
  5. Use 10 minutes to write a short audit conclusion and restart/run all cells. Compare with the discussion only after making your own diagnosis.
Discussion and sample repair for Activity 9.22

The product rule gives F′(x)=ex+(x−1)ex=xex. The predicted values are −2/e,−1,0. The three changes are 1, −1 and 0. The starter instead computes x−ex; its value at zero happens to agree, so that single test would miss the defect. The repair is:

def candidate(x):
    return (x - 1)*exp(x)

One useful added interval is [−1,0], with change −1+2/e, approximately −0.26424. Another is [1,2], with change e2. Different valid tests are welcome if their predictions are independent and explained. A zero-width difference is zero for any defined function and therefore cannot establish that the function is the right antiderivative. A sound audit distinguishes the derivative identity, the translation into Python, the tested values and the limited reach of finite tests.

9.23 Unit exercises

These exercises cover the whole unit. Allow 165 minutes for attempts, using the reserved time from earlier lessons, then 65 minutes to compare solutions and correct your working. All are core practice. For each calculation, state the method and interval, show enough intermediate reasoning to make the choice clear, and check by differentiation where an antiderivative is used. Hints and full solutions open separately.

Exercise 9.1 · Elementary fluency

Find the indefinite integrals of (a) 5x4−3x−2+2, for x>0, and (b) 4cos(2x)+3e−x.

Hint for Exercise 9.1

Use separate elementary terms; compensate for the inner scale in (b).

Worked solution to Exercise 9.1

(a) Increasing each exponent gives x5+3/x+2x+C. Its derivative is 5x4−3/x2+2. (b) The cosine term gives 2sin(2x), and the exponential gives −3e−x, so the answer is 2sin(2x)−3e−x+C. The chain-rule factors return the coefficients 4 and 3.

Return to Exercise 9.1

Exercise 9.2 · Algebra before technique

Integrate (x+2)2/x, for x>0. Explain your first step.

Hint for Exercise 9.2

Expand the numerator and divide each term by the root.

Worked solution to Exercise 9.2

The integrand is x3/2+4x1/2+4x−1/2. Therefore an antiderivative is 25x5/2+83x3/2+8x+C. Differentiating returns the three expanded terms, which combine to the original quotient. The positive domain keeps the root denominator nonzero.

Return to Exercise 9.2

Exercise 9.3 · A negative inner scale

Evaluate ∫01e2−3xdx, using changed limits. Predict the sign.

Hint for Exercise 9.3

The new variable begins at 2 and ends at −1.

Worked solution to Exercise 9.3

With u=2−3x, dx=−du/3. Thus the integral is −13∫2−1eudu=(e2−e−1)/3. It is positive, consistent with a positive integrand on forward bounds. Differentiating −e2−3x/3 provides a separate check.

Return to Exercise 9.3

Exercise 9.4 · Substitution across several forms

Find (a) ∫x2ex3dx, (b) ∫sinxcos4xdx, and (c) ∫x/9+x2dx.

Hint for Exercise 9.4

Use the exponent, the cosine and the root argument as your respective new variables.

Worked solution to Exercise 9.4

(a) u=x3, so x2dx=du/3: the answer is ex3/3+C. (b) u=cosx, so sinxdx=−du: the answer is −cos5x/5+C. (c) u=9+x2, so xdx=du/2: the answer is 9+x2+C. Chain-rule differentiation returns each integrand. All are valid for real x, using radians in (b).

Return to Exercise 9.4

Exercise 9.5 · A logarithm and a domain

Find ∫(4x+2)/(2x2+2x−4)dx. State all maximal intervals on which your answer applies.

Hint for Exercise 9.5

Compare the numerator with the derivative of the denominator, then factor the denominator.

Worked solution to Exercise 9.5

The numerator is exactly the denominator derivative. The answer is ln|2x2+2x−4|+C. Since the denominator factors as 2(x+2)(x−1), the maximal intervals are (−∞,−2), (−2,1), (1,∞). Each interval can have its own constant. The logarithmic chain rule verifies the answer.

Return to Exercise 9.5

Exercise 9.6 · Rewrite the remaining factor

Find ∫x2x+1dx for x>−1/2.

Hint for Exercise 9.6

After setting u = 2x + 1, express both x and dx using u.

Worked solution to Exercise 9.6

Here x=(u−1)/2 and dx=du/2. The integral becomes 14∫(u3/2−u1/2)du, giving 110(2x+1)5/2−16(2x+1)3/2+C. Its derivative is 12(2x+1)3/2−12(2x+1)1/2=x2x+1.

Return to Exercise 9.6

Exercise 9.7 · Two routes, one interval

Evaluate ∫13x/(x2+4)dx by changed limits and by returning to x. Explain why [lnu/2]13 is not the correct evaluation.

Hint for Exercise 9.7

The corresponding new bounds are 5 and 13.

Worked solution to Exercise 9.7

With u=x2+4, the integral is 12∫513du/u=12ln(13/5). Returning to x gives [ln(x2+4)/2]13, the same result. The proposed expression uses x-endpoints to evaluate a function of u. The denominator stays positive, so the continuity condition holds.

Return to Exercise 9.7

Exercise 9.8 · A substitution that retraces

Evaluate ∫−222xcos(x2)dx. Explain both the endpoint result and cancellation after splitting at zero. Why would the same endpoint map not evaluate ∫−22cos(x2)dx?

Hint for Exercise 9.8

Use u = x² and keep the complete differential factor.

Worked solution to Exercise 9.8

The first integral becomes ∫44cosudu=0. Splitting gives ∫40cosudu+∫04cosudu=−sin4+sin4=0. In the second integral the factor 2x is absent, so the same transformed integrand and differential would not be equal to the original. Equal images of endpoints alone are insufficient.

Return to Exercise 9.8

Exercise 9.9 · First use of parts

Find and check (a) ∫xsin(2x)dx, (b) ∫ln(3x)dx, for x>0.

Hint for Exercise 9.9

In (a), differentiate x. In (b), regard the logarithm as multiplied by 1.

Worked solution to Exercise 9.9

(a) Choose u=x, dv=sin(2x)dx, giving v=−cos(2x)/2. The answer is −xcos(2x)/2+sin(2x)/4+C. Differentiation cancels the extra cosine terms. (b) Choose u=ln(3x), dv=dx, with du=dx/x. The answer is xln(3x)−x+C; its derivative is ln(3x)+1−1.

Return to Exercise 9.9

Exercise 9.10 · Repeated parts and a boundary

Evaluate ∫01x2e2xdx. Show the intermediate integral and the lower-endpoint contribution.

Hint for Exercise 9.10

The first step leaves an integral of x exp(2x), already encountered in Lesson 4.

Worked solution to Exercise 9.10

Parts gives ∫x2e2xdx=x2e2x/2−∫xe2xdx. Thus an antiderivative is e2x(x2/2−x/2+1/4). Its derivative simplifies to x2e2x. The value at 1 is e2/4, and at zero it is 1/4, so the integral is (e2−1)/4, positive as expected.

Return to Exercise 9.10

Exercise 9.11 · Choose before you calculate

For each integral, state a useful first method and evaluate it: (a) ∫xln(x2+1)dx; (b) ∫lnx/xdx, x>0.

Hint for Exercise 9.11

In (a), substitution prepares a logarithm integral. In (b), the differential of the logarithm is already present.

Worked solution to Exercise 9.11

(a) Let u=x2+1, so the integral is 12∫lnudu. Parts then gives 12[(x2+1)ln(x2+1)−(x2+1)]+C. Its derivative is xln(x2+1) after cancellation. (b) Use u=lnx, giving (lnx)2/2+C. The same named function does not imply the same method: the accompanying factor differs.

Return to Exercise 9.11

Exercise 9.12 · Same family?

Two proposed antiderivatives of 2x(x2+3) are F(x)=x4/2+3x2 and G(x)=(x2+3)2/2. Decide whether both are correct. Does their definite endpoint difference agree on every interval?

Hint for Exercise 9.12

Expand G and inspect G − F.

Worked solution to Exercise 9.12

Expanding gives G=F+9/2, so their derivatives agree and both equal 2x(x2+3). A constant cancels in every endpoint difference, so they give the same definite integral on every finite interval. This is stronger than checking one numerical example.

Return to Exercise 9.12

Exercise 9.13 · Find the first invalid step

A proposed evaluation is ∫−112x/(x2)dx=[ln(x2)]−11=0. Explain precisely why it fails. Give a different interval on which the same antiderivative yields a valid evaluation, and evaluate it.

Hint for Exercise 9.13

Inspect the integrand inside the interval before looking at endpoint values.

Worked solution to Exercise 9.13

The integrand 2/x is undefined at zero, so the continuous-integrand evaluation theorem does not apply across [-1,1]. The antiderivative is valid separately on each side. For example, on [1,2] the integral is [ln(x2)]12=ln4. Any stated interval staying on one side with correct endpoint reasoning is an acceptable example.

Return to Exercise 9.13

Exercise 9.14 · A supplied rate model

A supplied delivery rate is q(t)=te−t litres per minute, where t is numerical time in minutes and 0≤t≤2. A vessel contains 4 litres at t = 0. Find the added volume and the final volume. Check the sign and distinguish the two answers.

Hint for Exercise 9.14

Parts gives an antiderivative of the rate; use it for the change before adding the initial amount.

Worked solution to Exercise 9.14

An antiderivative is −(t+1)e−t, verified by differentiation. The addition is [−(t+1)e−t]02=1−3e−2 litres, approximately 0.594 L. The final volume is 5−3e−2 litres, approximately 4.594 L. The rate is nonnegative, consistent with positive addition. The integration is of numerical time in minutes, so rate times time gives litres.

Return to Exercise 9.14

Exercise 9.15 · A false reassurance

Let F(x)=x2 and G(x)=x2+x(2−x). Both give the same change from 0 to 2. A learner concludes that G is also an antiderivative of 2x. Refute the conclusion algebraically and choose a smaller interval whose endpoint check detects the error.

Hint for Exercise 9.15

Compare derivatives first; then use an endpoint where the added term is nonzero.

Worked solution to Exercise 9.15

Here G(x)=2x, so G′=2, whereas F′=2x. They agree only at x = 1. On [0,1], F changes by 1 and G by 2, exposing the error. Both give 4 on [0,2] because the added term vanishes at those endpoints. A single correct accumulated value does not establish the derivative identity.

Return to Exercise 9.15

Exercise 9.16 · An audit you can explain

A program implements an intended antiderivative F(x)=e2x/2 of e2x as return exp(2*x/2). It computes endpoint differences using the correct subtraction order. (a) Explain the coding error. (b) Give a hand-computable interval check that detects it. (c) Explain why a zero-width interval would not detect it.

Hint for Exercise 9.16

Identify what the supplied Python expression simplifies to before testing.

Worked solution to Exercise 9.16

(a) The code computes ex, because division by 2 is inside the exponent; use return exp(2*x)/2. (b) On [0,1], the intended change is (e2−1)/2; the code gives e−1. The intended derivative is e2x, whereas the coded function has derivative ex. (c) Any defined function gives zero when the same endpoint value is subtracted from itself. That tests a property of subtraction, not the correctness of the function.

Return to Exercise 9.16

9.24 Conclusion and reference

We began with a practical gap in the fundamental theorem: knowing that an antiderivative evaluates an integral does not tell us how to find it. The methods developed here resolve many elementary cases by recognising how differentiation builds expressions. Algebra exposes simple terms, substitution reverses a chain rule, and parts rearranges a product rule.

The choice is part of the mathematics. A factor can supply an inner derivative in one problem and be the best quantity to differentiate in another. Endpoints carry their own information: they must move with a substitution, retain orientation and stay within the conditions of the theorem. A final derivative check tests the function you found; an endpoint calculation and a program each need their own checks.

You can now use these tools to support more substantial integral models. Unit 10 will ask what to integrate, over which interval and with what dimensions, in geometric and supplied physical settings. Keep the method decisions and their checks together as you move from evaluating an integral to constructing one.
