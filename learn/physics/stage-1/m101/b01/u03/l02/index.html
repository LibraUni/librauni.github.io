M101 · Unit 3 · Lesson 2

Composing transformations
in order

One matrix changes a vector. A second matrix can act on the result. What single matrix describes the whole process—and what happens if we exchange the two steps?

Allow about 3 hours: 60 minutes of reading and worked examples, 60 minutes of written activities, 30 minutes of Python and 30 minutes of feedback and correction. The notebook is the same coding activity, not additional work.

Use the column-vector convention from Lesson 1 and keep the original axes fixed. The Python section assumes the P101 Unit 1 readiness described below; the mathematical sections do not require programming.

3.8 Keep the intermediate vector

Suppose we reflect a drawing across the vertical axis, then shear the result horizontally. We already know how to carry out each instruction separately. The new feature is the connection between them: the output of the reflection becomes the input of the shear. We must retain that intermediate output rather than apply both instructions to the original drawing.

Throughout the first part of this lesson, let

R=(−1001),H=(1101).

The matrix R changes (x,y) to (−x,y). The matrix H changes (x,y) to (x+y,y): it is the horizontal shear with factor one. These are transformations of the figure on fixed axes. We do not reflect or shear the coordinate frame itself.

Example 3.8 · Two stages, three vectors

Start with v=(21). Reflect with R, then apply H. Find the intermediate and final vectors.

Name the intermediate result. Writing w=Rv prevents the original input from being confused with the input to the second step:

w=(−21).

Now use w, including its changed sign, in the shear:

Hw=(−2+11)=(−11).

The reflection first moved the point to the left of the vertical axis. At height one the shear adds one to its horizontal coordinate, leaving the final point at (−1,1). Applying H to the original (2,1) instead would give (3,1); that would omit the reflection from the path.

Applying one transformation after another is called composition. Our two-stage result can be written H(Rv). Read the brackets from the inside out: first find Rv, then apply H to that vector. In a left-to-right diagram the reflection appears first; in the nested expression it is the matrix closest to the input. The two representations agree, but you read them differently.

This is worth making explicit before introducing any new multiplication rule. If an instruction says “first R, then H”, write the intermediate vector or draw the two arrows. A calculation can have flawless arithmetic and still describe the wrong sequence.

Activity 3.9 · Follow both paths 10 min

Use v=(−12) and the matrices H and R above. First shear, then reflect. Write both intermediate and final vectors, and write the nested expression for this order. Repeat with reflection first. Explain geometrically why the two final horizontal coordinates differ.

Discussion of Activity 3.9

Shearing first gives Hv=(1,2), then reflection gives R(Hv)=(−1,2). Reflecting first gives Rv=(1,2), then shearing gives H(Rv)=(3,2). The intermediate vectors happen to agree for this input, but the second operations differ. In the first path, the shear's rightward shift is subsequently reflected to the left; in the second, the shear adds a rightward shift after the reflection. Keep the operation labels as well as the intermediate coordinates: an intermediate value alone does not identify the whole path.

3.9 One matrix for the whole journey

If we transform hundreds of points, repeating two separate calculations for each may be inconvenient. We would like one matrix that has the same effect as the two-stage process. Lesson 1 gives us a way to find it: work out the images of the two coordinate unit vectors, and put those images into columns.

Why can we use that method here? Each step respects vector addition and scaling. For example, if the first step sends u+v to Ru+Rv, the second sends that sum to H(Ru)+H(Rv). A scalar factor passes through both steps in the same way. Their composition therefore has the linearity needed for the coordinate-vector method. We are using a property of these transformations, not assuming that every two-step rule can be represented by a matrix.

Example 3.9 · Build the columns of the composition

Find a matrix C whose action is “reflect with R, then shear with H”.

Track the first coordinate vector. Reflection sends e1=(1,0) to (−1,0). The shear leaves every vector on the horizontal axis unchanged, so the final image is (−1,0). This is column 1 of C.

The second vector e2=(0,1) is unchanged by reflection. The shear then sends it to (1,1). This is column 2. Hence

C=(−1101).

Test the result on the input from Example 3.8:

C(21)=(−2+11)=(−11).

This agrees with the successive calculation. The coordinate-vector construction explains why the matrix works for every input; the extra numerical test is a useful check for a copying or arithmetic error.

We call C the product of H and R, and write C=HR. The order of the letters preserves the order in the nested calculation:

(HR)v=H(Rv).

The parentheses on the left group two matrices into one matrix. On the right they group a matrix and a vector into an intermediate vector. The equation says that either grouping gives the same final vector. It does not exchange H and R.

Key idea 3.4 · The rightmost transformation acts first

For column vectors, the product AB represents “first B, then A”. Its defining effect is (AB)v=A(Bv). To construct AB, apply A to each column of B and place the resulting columns in the same order.

To see the general column argument, write the two columns of B as b1 and b2. Lesson 1 gives Bv=xb1+yb2 for v=(x,y). Linearity of A gives

A(Bv)=A(xb1+yb2)=x(Ab1)+y(Ab2).

This is precisely the weighted-column rule for a matrix whose columns are Ab1 and Ab2. Matrix multiplication is defined this way because it represents composition. Multiplying entries in matching positions would describe a different operation and would not, in general, reproduce these outputs.

The product is HS. The first path is (1,0)↦(2,0)↦(2,0); the second is (0,1)↦(0,1)↦(1,1). Therefore

On (−1,2) the product gives (0,2). Successive application gives S(−1,2)=(−2,2), then H(−2,2)=(0,2). Putting the final arrows into rows would give the wrong rule: the column positions retain which original coordinate vector produced each image.

Return to Activity 3.10

3.10 Calculating a matrix product

The column construction gives a reason for the multiplication rule. We now turn it into a reliable arithmetic procedure. Write

A=(abcd),B=(pqrs).

Column 1 of the product is A(pr), which has entries ap+br and cp+dr. Column 2 is A(qs), with entries aq+bs and cq+ds. Placing them side by side gives

AB=(ap+braq+bscp+drcq+ds).

Each entry combines a row from the left matrix with a column from the right matrix. For the entry in row 1, column 2, use row 1 of A and column 2 of B: multiply a by q, multiply b by s, then add. The positions in the answer tell you which row and column to select. Work systematically through four positions rather than trying to hold the entire formula in memory.

Example 3.10 · Four entries and a separate check

Calculate AB for

A=(2−113),B=(12−21).

Label the position being filled. Let C=AB. Its four entries are

c11=2(1)+(−1)(−2)=4,c12=2(2)+(−1)(1)=3,c21=1(1)+3(−2)=−5,c22=1(2)+3(1)=5.

Therefore C=(43−55). The two negative signs in the first entry give a positive contribution; they are not a reason to subtract twice.

As a check with a different grouping, choose v=(1,−1). First Bv=(−1,−3), then A(−1,−3)=(1,−10). Directly,

C(1,−1)=(4−3,−5−5)=(1,−10).

Agreement supports our arithmetic, although one vector by itself would not establish that an arbitrary proposed matrix is correct.

Notice how the two views divide the work. Columns explain what the product means and make a useful construction. Rows and columns organise the same calculation entry by entry. Neither method licenses changing the factor order. If you are asked for BA, begin again with rows of B and columns of A.

3.10.1 Check the sizes before the entries

The composition also explains which rectangular products make sense. If B takes a three-entry vector to a two-entry vector, then a two-by-two A can act next. The composite takes three entries in and produces two entries out, so AB is two-by-three. The intermediate sizes must match:

(m×n)(n×p)⟶(m×p).

Here the matrix on the right acts first: it produces n entries, exactly the number the matrix on the left accepts. There is no need to learn a separate compatibility trick unrelated to the transformation. In this lesson we calculate mainly two-by-two products; for other shapes, identify the input, intermediate and output sizes before attempting arithmetic.

(FG)11=1(3)+(−2)(−1)=5,(FG)12=1(1)+(−2)(2)=−3,(FG)21=2(3)+0(−1)=6,(FG)22=2(1)+0(2)=2.

Reading it as “P first, F second” gives a three-entry input, a two-entry intermediate vector and a two-entry output.

3.11 What changes when the order changes?

Return to the shear and reflection. We have found HR, meaning reflection first. To compare the opposite order, we need RH. It is not enough to look at the individual matrices and assume that their product behaves like multiplication of ordinary numbers.

Example 3.11 · The two composite rules

Compare HR and RH, first by their entries and then by their action on (x,y).

Multiplication gives

HR=(−1101),RH=(−1−101).

The different upper-right entry has a direct interpretation. Reflecting first gives (−x,y); shearing then adds y, giving (−x+y,y). Shearing first gives (x+y,y); reflecting then reverses the whole horizontal coordinate, giving (−x−y,y). In symbols,

HR(xy)=(−x+yy),
RH(xy)=(−x−yy).

For (2,1) the results are (−1,1) and (−3,1). The matrices describe different transformations. But for (2,0) both give (−2,0): the shear has no effect at height zero. Different transformations can agree on some inputs.

Read each row of Figure 3.12 from left to right (top to bottom when the panels stack on a small screen). The starting shape and axes are the same. The middle panel matters: it shows the figure to which the second instruction is actually applied. Comparing only the final silhouettes could hide a mistake, especially with a highly symmetric starting shape. The labelled vertices preserve correspondence between original points and their images.

Key idea 3.5 · A counterexample and its limits

A single input with ABv≠BAv establishes AB≠BA. Agreement on one input does not establish equality. For known plane matrix transformations, checking both coordinate unit vectors checks both columns and therefore the entire matrix.

There is another distinction to keep clear. In (AB)v=A(Bv) we change the grouping while retaining the factor order. With three compatible matrices, grouping also gives (AB)C=A(BC): both describe C first, B second and A last. This property is called associativity. It does not imply AB=BA, which exchanges the steps and is called commutativity. You can check the distinction without calculating every intermediate entry: write the sequence of actions on a vector.

Both matrices send e1 to (−1,0), so that test cannot detect this reversal. On e2, HR gives (1,1) while RH gives (−1,1). The second test exposes the wrong column. On (−2,3), the correct HR gives (5,3) and the proposed RH gives (−1,3), confirming the difference away from the coordinate directions.

For each grouped three-matrix expression the order is S, then R, then H. Grouping packages consecutive steps without exchanging them.

3.12 When the order does not matter

The shear–reflection example disproves a general rule that matrix factors may always be exchanged. It does not prove the opposite claim that exchanging them always changes the result. Two matrices commute when AB=BA. This is a statement about that particular pair.

The identity matrix provides an immediate case. Applying I2 before or after a plane transformation changes nothing, so AI2=I2A=A. The same conclusion follows from columns: AI2 has columns Ae1 and Ae2, exactly the columns of A. Identity tests are useful when checking a multiplication procedure, but they are poor tests for detecting a reversed factor order, since both orders are supposed to agree.

Example 3.12 · Two reflections that commute

Let X=(100−1) reflect across the horizontal axis, and retain R for reflection across the vertical axis. Find both products.

One operation reverses the vertical component; the other reverses the horizontal component. Either order therefore sends (x,y) to (−x,−y). Multiplication confirms

XR=RX=(−100−1)=−I2.

The combined transformation is a half-turn about the origin, not a reflection across either one axis. Each nonzero position vector reverses direction and keeps its length. For example, (2,1) becomes (−2,−1) through either intermediate point (−2,1) or (2,−1). The intermediate points differ even though the final rule agrees.

Two diagonal matrices also commute. If D scales the two coordinates by s,t, and E scales them by u,v, either order gives (sux,tvy). The equality follows from ordinary scalar multiplication within each component. We have supplied a reason valid for every input rather than relying on a few successful trials. Other pairs may commute too; this is a useful family, not a complete classification.

A wider view · Reflections that return light

The two component reversals in Example 3.12 give a small mathematical glimpse of a useful idea: several reflections can have a simple combined effect. A corner-cube retroreflector is a three-dimensional optical device that returns incoming light toward its source. The Apollo 11 array contains one hundred such prisms; laser ranging uses the travel time of pulses sent from Earth and returned by the array.

Our calculation concerns plane vectors and two perpendicular coordinate reflections. It does not model the prism's three-dimensional ray path, refraction or measurement precision. The connection is the strategy of understanding a sequence through its combined action. NASA/JPL's account describes the instrument and its scientific purpose. This context is optional; no optics is needed for the activities.

Activity 3.13 · Agreement for a reason 10 min

Use D=(30012) and E=(−1004). Find DE and ED, and interpret their common action on (x,y). Compare their action on (2,−2) as a check. Then explain why none of the following alone can test whether a program reverses the order of arbitrary matrix factors: multiplying by I2, using only diagonal matrices, or using only the zero input vector.

Discussion of Activity 3.13

Both products are (−3002): the horizontal component is multiplied by −3 and the vertical by 2. The common output from (2,−2) is (−6,−4). The negative horizontal factor combines a reversal with a stretch; it is not a negative length.

Identity commutes with every compatible square matrix; diagonal matrices commute with one another; and all matrix transformations send zero to zero. A reversed procedure can therefore pass all three kinds of test. A noncommuting pair such as H,R, together with an input off the horizontal axis, is needed to expose that particular error.

3.13 A transparent computational check

We will now reuse a short Python function to compare a successive calculation with a hand-computed product. The purpose is to see exactly which arithmetic the computer performs. We will not use a matrix library or write a general matrix-multiplication algorithm. Keeping the example small makes it possible to trace every operation on paper.

Readiness. Before running this activity, you should be able to run notebook cells in order, index a list, evaluate scalar arithmetic, and define and call a function that returns a value, as taught in P101 Unit 1. If that foundation is pending, keep this coding activity pending and return after it is established. The preceding mathematics remains usable on its own.

Download the composition notebook · Plain Python companion. The notebook leaves space for your predictions and discussion; the companion contains the same supplied function and checks.

To avoid introducing nested lists, store a two-by-two matrix as a list of four numbers in row order: (abcd) becomes [a, b, c, d]. A vector (x,y) becomes [x, y]. Python starts indexing at zero. Thus m[2] is c, the first entry of the second row; v[1] is y.

def apply2(m, v):
    first = m[0] * v[0] + m[1] * v[1]
    second = m[2] * v[0] + m[3] * v[1]
    return [first, second]

The first assignment evaluates the top row on the original input. The second evaluates the bottom row on that same input. Only then are the two numbers collected into a new list and returned. We have not changed v[0] between calculating the two outputs. That matters: overwriting part of the input too early could make the second calculation use an already transformed coordinate.

This supplied function assumes exactly four numerical matrix entries and two numerical vector entries in the stated order. It is a small teaching calculation, not a general validator. Also, multiplying Python lists with * is not matrix multiplication; our function implements the required scalar products explicitly.

Example 3.13 · Read the call from its input

For R = [-1, 0, 0, 1] and v = [2, 1], the function's first result is -1 * 2 + 0 * 1, or -2. Its second is 0 * 2 + 1 * 1, or 1. It returns [-2, 1]. Calling the function again with H = [1, 1, 0, 1] and that returned list gives [-1, 1].

The nested call apply2(H, apply2(R, v)) does the same thing: Python evaluates the inner call to obtain the vector supplied to the outer call. This order agrees with H(Rv) and therefore with (HR)v.

H = [1, 1, 0, 1]
R = [-1, 0, 0, 1]
HR = [-1, 1, 0, 1]
RH = [-1, -1, 0, 1]
v = [2, 1]

intermediate = apply2(R, v)
successive = apply2(H, intermediate)
print("R then H:", successive)
print("HR product:", apply2(HR, v))

reverse = apply2(R, apply2(H, v))
print("H then R:", reverse)
print("RH product:", apply2(RH, v))

The lists named HR and RH are the products we calculated by hand, entered in row order. They are not computed by attaching two lists or multiplying list entries. Keep that distinction visible: the program checks a candidate product against successive applications.

Discussion of Activity 3.14

For [2, 1], the first two outputs are both [-1, 1]; the last two are both [-3, 1]. Each pair compares a successive calculation with its correctly ordered product. The different pairs represent different transformations.

Expected outputs: each is shared by the successive and correctly ordered product calculation
InputR then H / HRH then R / RH
[1, 0][-1, 0][-1, 0]
[0, 1][1, 1][-1, 1]
[-2, 3][5, 3][-1, 3]

The first coordinate vector hides this error; the second exposes it. Using RH as the reflection-first candidate gives the wrong result on [0, 1] and [-2, 3]. Zero is sent to zero in either order, so it cannot distinguish them.

A clean run checks that the result does not depend on an old value left in the notebook. It does not make the model or code automatically correct. For known matrix transformations, correct agreement on both coordinate vectors identifies the columns and is sufficient mathematically; a few successful runs of an arbitrary program do not establish that it implements a linear rule for every input. Here we can also inspect the function: each output is exactly the stated row–vector scalar product. Our integer examples avoid rounding ambiguity; these printed equalities are not a general method for comparing rounded floating-point calculations.

A useful final note might say: “Reflection first means HR. I used (0,1) to reveal the sign difference in column 2, checked (−2,3) separately and reran from a clean kernel. The derivation explains the general product rule; the runs check this implementation and these candidates.”

Return to Activity 3.14

We began with two instructions and an intermediate vector. The product matrix compresses the same journey into one operation; its columns are the final images of the original coordinate directions. The rightmost factor acts first, row–column sums calculate the entries, and exchanging factors must be justified for the particular pair. A well-chosen check has to be capable of exposing the mistake we are worried about.

Lesson 3 reverses the direction of the question. Instead of supplying an input and calculating an output, we will be given the output and asked which input could have produced it. Writing the component relations as simultaneous equations will let us investigate that question systematically.
