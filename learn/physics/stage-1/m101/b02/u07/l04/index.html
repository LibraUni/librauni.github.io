M 101 · Unit 7 · Lesson 4

Block synthesis and formative checkpoint

A trustworthy answer includes the conditions under which its method answers the question.

Across Block 2 we have moved from the domain of a function to its limits, derivatives, shape and local approximations. Those ideas are now tools to choose between. A question about a nearby value may need a tangent; a question about an extreme value needs candidates and comparisons; a table of computed slopes needs both a formula check and a judgement about what the numbers establish.

Four hours: 35 minutes synthesis, 60 minutes mixed Block 2 problems, 45 minutes correction across the practice, 60 minutes iCMA 02 including feedback, 25 minutes conclusion/reference and 15 minutes handover. The separate 80-minute attempt period for the Unit 7 exercises was reserved in Lessons 1–3. Together these allocations keep Unit 7 at 14 hours and 3 Python hours. No new required coding task is added here.

7.16 Start with the claim

Before calculating, write what you want to know. “What is the value?”, “What is the rate?” and “Where is the maximum?” ask different questions even when the same formula appears. Then record the domain. Algebra may simplify an expression while leaving a restriction that still matters. A numerical routine can return a number at a point where the original question has no allowed value.

Example 7.8 · One formula, several questions

Let r(x)=(x2−1)/(x−1) on its natural real domain. For x≠1, factorisation gives r(x)=x+1. Hence the limit as x approaches 1 is 2, but r(1) is undefined. The derivative is 1 at every allowed input; there is no derivative of this original function at 1 because the value itself is missing.

If we explicitly define a new function by filling the gap with 2, the new function is x+1 on all real inputs. It has derivative 1 at 1 and its tangent is an exact model everywhere. That is a change of function, not a discovery that the original restriction never mattered. A central difference around 1 would return 1 even for the original formula at nonzero sample steps. It would not repair the missing value.

Now consider what kind of evidence is available. An exact derivative calculation can establish a sign throughout an interval after its factors and domain are analysed. A finite graph can suggest that sign, but may miss a small region where it changes. A numerical derivative can support an analytical calculation at selected inputs, but may share an error if both implementations use the same mistaken expression. Independence means using a check that can fail differently.

Use this sequence in the practice below. Attempt the questions before opening feedback. When a result differs, find the earliest disagreement in the reasoning, repair it and explain why the repair works. A final number copied from a solution gives little evidence that you can make the same decision in a new problem.

7.17 Unit 7 exercises

These twelve core exercises cover all three preceding lessons. Use the 80 minutes reserved across those lessons for attempts, then use the correction allocation in this lesson. Hints and worked solutions are separate. Write conditions and units where relevant; a calculator may support a check after your reasoning. No additional exercise booklet is required.

Exercise 7.1 · A value, a change and a tolerance (7 minutes)

For f(x)=2x2+1, construct the tangent model at a=2. Estimate f(2.03) and the change from f(2). Find an exact symmetric range about 2 in which absolute output error is at most 0.002.

Hint for Exercise 7.1

Expand f(2+h) and compare it with its constant and linear terms.

Worked solution to Exercise 7.1

f(2+h)=9+8h+2h2, so L(2+h)=9+8h. At h=0.03, the estimated final value is 9.24 and the estimated change 0.24; the exact values are 9.2418 and 0.2418. The remainder is 2h2. Requiring 2h2≤0.002 gives |h|≤0.001. This is an algebraic bound for every input in that range, not merely a sampled observation.

Return to Exercise 7.1

Exercise 7.2 · A root without losing the sign (6 minutes)

Estimate 24.8 from a convenient tangent. Explain the sign of the error and use a difference of squares to express the error exactly.

Hint for Exercise 7.2

Use the base input 25 and distinguish the difference of squares from the difference of roots.

Worked solution to Exercise 7.2

At 25 the value is 5 and the derivative is 1/10. The signed input change is −0.2, giving 4.98. Concavity down makes the tangent high. Since 4.982=24.8004, the exact positive error is 4.98−24.8=0.0004/(4.98+24.8), approximately 0.00004016. The numerator 0.0004 alone is not the root error.

Return to Exercise 7.2

Exercise 7.3 · Local logarithm (5 minutes)

Use a tangent at 1 to estimate ln(0.97). Is the estimate high or low? Explain why the same tangent cannot give a reliable estimate of ln(0.1) merely because both inputs are positive.

Hint for Exercise 7.3

The derivative of the logarithm is 1/x; its derivative decreases on positive inputs.

Worked solution to Exercise 7.3

The tangent is L(x)=x−1, so the estimate is −0.03. Since the logarithm is concave down, the tangent lies above it: this estimate is less negative than the true value. The base point is 1 and 0.1 is far from it; positivity checks the domain but does not control approximation error. Indeed L(0.1)=−0.9, whereas ln(0.1)≈−2.3026.

Return to Exercise 7.3

Exercise 7.4 · A calibrated response (6 minutes)

At 20°C an illustrative response R is 8Ω and its local slope is 0.12Ω/°C. Estimate the response at 19.5°C. Distinguish an estimated change, an estimated final value and a claim of exact linearity.

Hint for Exercise 7.4

Multiply the slope by the signed temperature difference before adding the initial response.

Worked solution to Exercise 7.4

The change is −0.5°C, so the predicted response change is −0.06Ω and the predicted final response is 7.94Ω. These follow from the local tangent. The supplied value and slope do not establish that R is exactly linear over the interval or bound the error at 19.5°C. Using a temperature difference of −0.5K would be equivalent; using the absolute Kelvin temperature as the change would not.

Return to Exercise 7.4

Exercise 7.5 · Compare two formulas (8 minutes)

For f(x)=x3−2x at 1, derive forward and central estimates in terms of positive h. Evaluate them at 0.1 and 0.05 and compare their errors against the analytical derivative.

Hint for Exercise 7.5

The linear term is differentiated exactly by either difference rule. Retain the cubic remainder.

Worked solution to Exercise 7.5

The derivative at 1 is 1. Expanding gives D+=1+3h+h2 and D0=1+h2. At 0.1 the estimates are 1.31 and 1.01; at 0.05 they are 1.1525 and 1.0025. Forward errors 0.31 and 0.1525 nearly halve; central errors 0.01 and 0.0025 quarter exactly in real arithmetic. Do not claim this exact ratio for an arbitrary function or arbitrarily small computer step.

Return to Exercise 7.5

Exercise 7.6 · Domain before stencil (6 minutes)

A model is supplied only for 0≤x≤2. You need a slope estimate at 1.98 using h=0.05. Which of the forward, backward and central rules stays within the domain? What changes at the endpoint 2?

Hint for Exercise 7.6

Write every sampled input before evaluating any function.

Worked solution to Exercise 7.6

Forward requests 2.03, central requests 1.93 and 2.03, so both leave the domain. Backward uses 1.93 and 1.98 and is allowed. At 2, backward uses 1.95 and 2 and can estimate a left-hand endpoint rate if the model supports one. It does not establish an ordinary two-sided derivative using only the restricted domain. An interior central estimate could instead use a sufficiently small positive step, at most 0.02 at 1.98, but accuracy still needs checking.

Return to Exercise 7.6

Exercise 7.7 · A false stationary point (6 minutes)

For f(x)=4+2|x−1|, compute the forward, backward and central differences at 1. Classify the point using mathematical reasoning, and critique the claim that a zero central estimate proves stationarity.

Hint for Exercise 7.7

The constant cancels; determine the slopes on the two sides separately.

Worked solution to Exercise 7.7

For any positive step the forward result is 2, backward −2 and central 0. The one-sided derivatives disagree, so the ordinary derivative does not exist. The point is an interior critical point and an absolute minimum with value 4, but it is not stationary under our definition. Symmetric cancellation cannot replace the derivative-existence test.

Return to Exercise 7.7

Exercise 7.8 · Read an error table (7 minutes)

A central calculation gives absolute errors 0.0009,0.000225 and 0.00005625 at steps 0.06,0.03 and 0.015. At 0.0075 the error rises to 0.00008. Describe the observed pattern and two checks you would make before interpreting the rise.

Hint for Exercise 7.8

Compare successive ratios, then separate an implementation problem from an arithmetic or data effect.

Worked solution to Exercise 7.8

The first two refinements quarter the error when the step halves, consistent with a quadratic-in-step truncation pattern. The last refinement breaks it. Check that function, base input, formula and reference derivative were held fixed and that the denominator is 2h. Then inspect rounding of inputs/outputs and reproduce from a clean run; for measured data, inspect their precision too. These four observations do not prove a universal order or identify the cause of the rise uniquely.

Return to Exercise 7.8

Exercise 7.9 · An error contribution with units (7 minutes)

Two position values each have absolute error at most 0.003m. Find the worst-case contribution to a central velocity estimate when h=0.15s and when h=0.015s. Would identical endpoint errors attain either bound? Does either bound include truncation?

Hint for Exercise 7.9

The full time separation is 2h, and the difference of two bounded errors has magnitude at most twice their individual bound.

Worked solution to Exercise 7.9

The bound is δ/h, giving 0.02m/s and 0.2m/s. Identical endpoint errors cancel, giving zero contribution, so they do not attain these positive bounds. The bounds concern the stated position errors only. They omit truncation and additional timing/arithmetic errors; they are not total-error estimates or confidence intervals.

Return to Exercise 7.9

Exercise 7.10 · Repair the reasoning as well as the code (8 minutes)

A program uses (f(a+h)-f(a-h))/h, then rounds each function value to three decimals before subtracting. It reports increasing agreement between successive outputs as proof that the derivative exists. Identify three separate problems and propose a test that would reveal each.

Hint for Exercise 7.10

Inspect separation, preservation of small differences, and the corner counterexample.

Worked solution to Exercise 7.10

The denominator must be 2h: a linear test such as f(x)=3x+2 returns 6 with the incorrect rule instead of 3. Rounding before subtraction can erase a small output difference: compare rounded and unrounded cube results over several steps, retaining full stored values for arithmetic. Agreement of a finite sequence does not prove differentiability: |x| at zero gives stable central zeros despite unequal one-sided derivatives. Repairing the denominator and rounding policy still leaves the need to justify the mathematical interpretation.

Return to Exercise 7.10

Exercise 7.11 · Shift the outputs, keep the derivative (6 minutes)

Explain why f(x)=x3 and g(x)=108+x3 have identical exact forward and central estimates at the same input and step, yet can give different floating-point results. Does a computed zero for g prove the derivative is zero?

Hint for Exercise 7.11

Cancel the constant symbolically, then ask whether the stored outputs preserve the small difference.

Worked solution to Exercise 7.11

The same constant appears in both numerator terms and cancels exactly, so both difference formulas and both derivatives agree in real arithmetic. Stored outputs near 108 may round away increments that remain visible near 1. Their computed difference can be zero even when the inputs are distinct. Such a zero is not proof of a zero derivative; at 1 the analytical derivative is 3.

Return to Exercise 7.11

Exercise 7.12 · What three observations support (8 minutes)

At times 1.9,2.0 and 2.1s, recorded positions are 7.8,8.0 and 8.3m. Find the three available difference slopes about 2s. Write a short conclusion separating a direct calculation, a possible instantaneous-velocity estimate and an unresolved limitation.

Hint for Exercise 7.12

Use each actual time separation; central is the average of the two one-sided slopes for these equally spaced times.

Worked solution to Exercise 7.12

The backward slope is 2m/s, forward 3m/s, and central 2.5m/s. These are rates across finite intervals calculated from the observations. The central rate may estimate velocity at 2s if a suitably smooth motion model and adequate measurement precision support that use. Three readings do not prove differentiability, identify a rigorous error bound or establish the exact midpoint velocity. The one-sided disagreement can motivate finer or better-characterised measurements but alone does not prove a corner.

Return to Exercise 7.12

7.18 Bringing Block 2 together

Allow 15 minutes for each mixed activity. These problems retrieve Units 4–6 alongside Unit 7, so a single method will not answer every part. They are formative practice, not TMA 02 questions. Keep the conclusions precise enough that another reader can distinguish what you proved from what you estimated.

Activity 7.16 · A gap, a limit and a derivative

For f(x)=(x2−4)/(x−2), state the domain, the limit at 2 and the derivative at every allowed input. A numerical calculation uses central differences around 2 and obtains 1. Explain what it computed. Define a continuous extension at 2 and give its tangent there. Which claims concern the original function and which concern the extension?

Hint for Activity 7.16

Factor the numerator, but preserve the original denominator restriction.

Discussion of Activity 7.16

The domain excludes 2. On it f(x)=x+2, so the limit is 4 and the derivative is 1. The original function has no value or derivative at 2. The central calculation compares allowed samples 2−h and 2+h and returns 1; it has not supplied the missing middle value. The extension F(x)=x+2 on all real inputs is continuous and differentiable, with F(2)=4 and tangent L(x)=4+(x−2). Only the extension has that tangent at 2. A sound answer keeps both function names and their domains visible.

Activity 7.17 · Shape and local prediction

For p(x)=x3−3x on [−2,2], determine intervals of increase/decrease, classify interior stationary points, and find the absolute extrema. Then construct the tangent at zero, estimate p(0.1) and find its exact error. Do the stationary points coincide with the inflection point?

Hint for Activity 7.17

Factor p′(x) and check both endpoints. For the tangent error, compare the cubic with its linear term.

Discussion of Activity 7.17

p′=3(x−1)(x+1), positive outside [−1,1] and negative inside. The function increases on [−2,−1] and [1,2], and decreases on [−1,1]. It has a local maximum at −1 and local minimum at 1. Candidate values are p(−2)=−2, p(−1)=2, p(1)=−2, p(2)=2: absolute maximum 2 occurs at −1 and 2; minimum −2 at −2 and 1.

At zero, p(0)=0 and p′(0)=−3, giving L(x)=−3x. The estimate at 0.1 is −0.3, while the exact value is −0.299. Signed estimate-minus-target error is −0.001; absolute error 0.001. Since p″=6x changes sign at zero, it is an inflection input, but its tangent is not horizontal. The stationary inputs ±1 are different. This distinguishes zero first derivative from a change of concavity.

Activity 7.18 · A supplied cooling model

A temperature model is T(t)=20+60e−t/10, with t measured in minutes and T in °C, for t≥0. Find the initial temperature and rate, construct a tangent prediction at t=0.2, and determine whether the prediction is high or low. Find the mean rate from 0 to 10 minutes and explain what the mean value theorem guarantees. Does the model predict an attained minimum temperature?

Hint for Activity 7.18

The exponential needs the chain-rule factor. Check the sign of the second derivative and distinguish a limiting value from a value reached.

Discussion of Activity 7.18

T(0)=80°C and T′(t)=−6e−t/10°C/min, so the initial rate is −6°C/min. The tangent predicts 80−6(0.2)=78.8°C. Since T″(t)=0.6e−t/10>0, the curve is concave up and the tangent is low. Direct evaluation gives about 78.8119°C, consistent with that direction.

The mean rate on [0,10] is 6(e−1−1)°C/min, approximately −3.7927°C/min. Continuity on that interval and differentiability inside guarantee at least one interior time with this instantaneous rate. Solving gives c=−10ln(1−e−1)≈4.587 minutes, not necessarily the midpoint. The model decreases towards 20°C but remains above it at every finite time, so it has no attained minimum on [0,∞). The physical model is supplied for this exercise; these mathematical conclusions do not validate it for a real object.

Activity 7.19 · Audit a numerical report

A report on g(x)=108+x3 at 1 says: “At very small steps both difference estimates are zero. They agree, so the derivative is zero and the function has a local extremum.” Rewrite it as an evidence-based report. Include an analytical derivative, a plausible numerical mechanism, two useful checks and the conclusion about extrema. You may consult the earlier table; no new code run is required.

Discussion of Activity 7.19

The analytical derivative is g′(x)=3x2, so g′(1)=3, and it is positive in a neighbourhood of 1. Thus the function is increasing there and has no local extremum at 1. Tiny-step outputs near 108 can round to equal stored values, yielding zero differences. Both methods share this output-loss mechanism, so agreement is not independent confirmation.

Useful checks include removing the constant before computing, comparing moderate steps against the exact cube formulas, inspecting the two stored outputs, and verifying that sampled inputs differ. A repaired report names the function, input, method and steps and describes the observed zeros as numerical failure, not a mathematical derivative. It distinguishes a proposed mechanism from a confirmed inspection of the actual stored values.

For correction, sort difficulties by cause: domain or limit, differentiation rule, sign/endpoint reasoning, local-model interpretation, code implementation, or an overclaim from numerical evidence. Revisit the relevant worked example, then write a corrected explanation without looking at the solution. This is part of the 45-minute correction allocation, not an added set.

7.19 iCMA 02 · Formative checkpoint

Allow 40 minutes to choose answers and 20 minutes for feedback and correction. Work independently first, then compare your reasoning with the explanations. The check runs locally in the page; it does not submit answers or save a mark. There is no pass threshold or automatic completion. Without JavaScript, select or note your choices and open each worked discussion manually.

iCMA 02 · Question 1

For f(x)=(x2−9)/(x−3), which statement is correct?

Worked discussion for Question 1

Correct choice: A. For x≠3, the expression is x+3. This establishes the limit 6 but retains the excluded input. A limit and a value are distinct.

iCMA 02 · Question 2

What is the derivative of e3x?

Worked discussion for Question 2

Correct choice: B. The outer exponential keeps its value and the inner function 3x contributes its derivative 3 by the chain rule. The power rule is not the rule for an exponential with variable exponent.

iCMA 02 · Question 3

Which claim about f(x)=x3 at zero is correct?

Worked discussion for Question 3

Correct choice: C. The derivative 3x2 vanishes at zero but is positive on both sides; the function continues increasing. The second derivative test is inconclusive there. Zero first derivative alone does not classify an extremum.

iCMA 02 · Question 4

For a continuous function on a closed bounded interval, how should absolute extrema be checked?

Worked discussion for Question 4

Correct choice: A. Continuity ensures that extrema are attained, but candidates can include derivative failures and endpoints as well as stationary inputs. A finite plot can miss a candidate.

iCMA 02 · Question 5

Does the mean value theorem apply to |x| on [−1,1]?

Worked discussion for Question 5

Correct choice: B. The function is continuous, but its left/right slopes at zero differ. The differentiability hypothesis fails. Endpoint agreement does not repair this. Here all existing interior derivatives are ±1, so none equals the zero secant slope.

iCMA 02 · Question 6

A function has f(2)=7 and f′(2)=−3. What is its tangent estimate at 2.04?

Worked discussion for Question 6

Correct choice: C. The input change is 0.04, the estimated output change −0.12, and the estimated final value 7−0.12=6.88. It is an estimate, not an exact value guaranteed by the two local data.

iCMA 02 · Question 7

Which expression is a central estimate of f′(a) with positive half-step h?

Worked discussion for Question 7

Correct choice: A. The numerator is the output difference; the sampled inputs are separated by 2h. A sum of outputs is not a slope, and dividing byh doubles the symmetric secant.

iCMA 02 · Question 8

Every central estimate of |x| at zero is 0. What follows?

Worked discussion for Question 8

Correct choice: B. The right slope is 1 and the left slope −1. Symmetry cancels their disagreement in the central quotient. A stable symmetric result does not imply a two-sided derivative.

iCMA 02 · Question 9

A smaller step worsens a numerical derivative. Which is a defensible explanation to investigate?

Worked discussion for Question 9

Correct choice: C. Finite representation and cancellation can dominate at small steps; inspect inputs and outputs and compare moderate steps. This is a candidate mechanism, not proof of the cause in every case. More printed digits do not change the arithmetic already performed.

iCMA 02 · Question 10

Several computed estimates agree. Which conclusion is justified without further information?

Worked discussion for Question 10

Correct choice: A. A finite comparison supports a limited claim. Shared implementation errors, corners, unsampled behaviour and model assumptions remain possible. State the tested function, inputs, formula and steps, and seek a check that can fail differently.

7.20 Conclusion and reference

The unit opened with a prediction near a known operating point. A tangent makes that prediction by combining a starting value with a derivative times a signed input change. It can be powerful without being globally accurate. Exact remainders, units, domains and tolerances make the limits of the prediction visible.

Numerical differentiation travels in the opposite direction, from nearby outputs towards a rate. We learned why symmetry can improve an approximation, why it can conceal a corner, and why excessive refinement can destroy a useful difference in finite arithmetic. A computed value earns confidence through the reasoning and checks around it.

Block 2 has therefore developed more than a collection of rules. Functions require domains; limits describe approach; derivatives connect local change with shape; theorems have hypotheses; approximations need a scale and evidence. These distinctions will remain useful when Block 3 asks how local contributions accumulate into a total.

def central(f, a, h):
    if h <= 0:
        raise ValueError("Use a positive step.")
    if a + h == a or a - h == a:
        raise ValueError("A sampled input did not change.")
    return (f(a + h) - f(a - h)) / (2 * h)

def cube(x):
    return x ** 3

for h in [0.1, 0.01, 0.001]:
    estimate = central(cube, 1.0, h)
    print(h, estimate, abs(estimate - 3.0))
