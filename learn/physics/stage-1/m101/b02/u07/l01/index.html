M 101 · Unit 7 · Lesson 1

Tangent-line approximations

A tangent matches a curve at one point. Using it nearby requires both a calculation and a judgement.

Suppose a quantity currently has value 12 and is increasing at 3 units per second. Predicting 12.3 after a tenth of a second assumes that the present rate describes the short interval well enough. That assumption may be excellent, or it may fail when the rate changes rapidly. We will make this familiar prediction precise and learn what would justify trusting it.

Three hours, including the unit introduction: 65 minutes reading and examples, 65 minutes activities, 25 minutes feedback and correction, and 25 minutes reserved for the cumulative unit exercises. No Python is required.

7.1 From a slope to a nearby value

Let f be differentiable at a. Write h for the signed change in input, so the new input is a+h. The derivative definition says that the ratio of output change to input change approaches f′(a) as the nonzero change h approaches zero:

f(a+h)−f(a)h⟶f′(a).

For a sufficiently small change, it is therefore reasonable to replace that ratio by the derivative, then multiply by h. This gives an estimated change, f′(a)h. To obtain the estimated final value, add the starting value:

f(a+h)≈f(a)+f′(a)h.

Notice the two roles. The derivative controls the tilt; the initial value anchors the prediction at the correct height. Using only f′(a)h would estimate how much the output changes, not where it finishes. A negative h describes an input to the left of the base point and needs no separate formula.

With x=a+h, the predicting function is L(x)=f(a)+f′(a)(x−a). It is exactly the tangent-line equation from Unit 5. It matches both the value and the slope at a. The equality defines L; the approximation sign belongs between f(x) and L(x). Those two statements should not be confused.

Key idea 7.1 · Value plus predicted change

At a differentiable base point a, the local linear model is L(a+h)=f(a)+f′(a)h. The input change h is signed. The model's equality is exact; using it in place of f(a+h) is an approximation whose suitability needs checking.

Example 7.1 · A prediction with an exact check

For f(x)=x2, construct the tangent model at a=3 and estimate the outputs at 3.1 and 2.9.

Since f(3)=9 and f′(3)=6, the model is L(x)=9+6(x−3). At 3.1 the change is h=0.1, so L(3.1)=9.6. At 2.9 the change is h=−0.1, giving L(2.9)=8.4.

The exact outputs are 9.61 and 8.41. Both estimates lie 0.01 below the curve. Expanding the square explains why:

f(3+h)=(3+h)2=9+6h+h2=L(3+h)+h2.

The omitted term is positive for either sign of nonzero h. Here the error is known exactly; it is not merely suggested by a graph.

Activity 7.1 · Which quantity did you calculate?

For q(x)=x2+2x at a=2, estimate q(2.05) and the change from q(2) to q(2.05). Check both against exact algebra. Explain the error in calling 0.3 the estimated final value.

Discussion of Activity 7.1

q(2)=8 and q′(2)=6. The input change is 0.05, so the estimated output change is 0.3 and the estimated final value is 8.3. Expanding gives q(2+h)=8+6h+h2, so the exact final value is 8.3025 and the exact change 0.3025. The answer 0.3 omits the starting value. Both approximation errors are 0.0025 in absolute size.

7.2 Choosing and constructing a useful tangent

A useful base point is close to the target input and makes the required value and derivative easy to obtain. “Close” cannot be judged independently of the function, but it is sensible to avoid using a distant tangent when a nearby one is available. Write down the base point, starting output, derivative and signed input change before combining them. That short inventory prevents most substitution mistakes.

Example 7.2 · Estimating a reciprocal

Estimate 1/4.08 without dividing by 4.08 directly.

Choose f(x)=1/x and a=4. The target is 0.08 above the base point. From f′(x)=−1/x2,

L(4.08)=14−116(0.08)=0.245.

The decrease makes sense: increasing a positive denominator decreases its reciprocal. We can also check the approximation without a decimal division. For h>−4,

14+h−(14−h16)=h216(4+h).

At h=0.08, the right-hand side is about 0.00009804. Thus our estimate is low, and the exact value is about 0.24509804. The algebraic remainder, not the number of decimal places displayed, establishes the error here.

Square roots, exponentials and trigonometric functions are treated in the same way, using their taught derivatives. Trigonometric inputs must be in radians when using the standard derivative formulas. A calculator can be used later as an independent numerical comparison, but it does not replace the construction of the tangent.

Activity 7.2 · A convenient nearby value

Estimate 15.84 using the tangent to f(x)=x at 16. State the signed change in input. Explain why the estimate lies above the exact value using concavity, and then check by squaring your estimate.

Hint for Activity 7.2

The derivative at 16 is 1/(216)=1/8. A negative input change reduces the predicted output.

Discussion of Activity 7.2

h=−0.16, so the estimate is 4−(0.16)/8=3.98. The square-root graph is concave down on positive inputs, so its tangent lies above the graph. Directly, 3.982=15.8404>15.84; both the estimate and the desired root are positive, so 3.98 is too large. The difference in squares is 0.0004, not the difference in roots: the root error equals 0.0004/(3.98+15.84), about 0.00005025. This final identity is an exact check, not a new approximation rule to memorise.

7.3 Changes have units

If the input is time in seconds and the output is position in metres, the derivative has units of metres per second. Multiplying by a time change gives a displacement in metres, which can be added to the original position. This is a useful check on the calculation. It does not prove that the rate stays nearly constant over the chosen interval.

Example 7.3 · A locally calibrated sensor

An illustrative sensor model gives output voltage V(T) at temperature T. At T=20∘C, the output is 1.20 V and the local slope is 0.015V/∘C. Estimate the output at 22 °C.

The temperature change is +2∘C. Its product with the slope is +0.030V, so the tangent prediction is 1.230 V. The data specify local behaviour only: they do not establish that the sensor stays linear across those two degrees. The result should be reported as a local estimate, with validation over the operating range still needed.

A temperature difference of 2 °C has the same magnitude as 2 K, even though the two temperature scales have different origins. It would be wrong to insert the absolute number 295.15 K as the change. The tangent model depends on the difference from the stated calibration point.

A wider view · A calibration belongs to an instrument

Real calibration work compares sensor outputs with reference measurements and monitors changes. Our tangent calculation isolates one mathematical step: predicting a response near a known operating point. The photograph supplies no slope, tolerance or evidence that a linear response remains valid over any particular range.

You may meet the notation dx for a chosen small input change and dy=f′(a)dx for its linearised output change. The actual output change is Δy=f(a+dx)−f(a). In this use, dy is the tangent prediction and need not equal Δy. We will usually retain h to keep that distinction visible.

Activity 7.3 · A rate is not a position

At time 5 s, a supplied position model has s(5)=12m and s′(5)=−0.4ms−1. Estimate s(5.2) and s(4.8). A report claims that this proves the object travelled at constant velocity between 4.8 and 5.2 s. Explain why that conclusion does not follow.

Discussion of Activity 7.3

The two time changes are +0.2 s and −0.2 s. The predicted displacements are respectively −0.08 m and +0.08 m, giving positions 11.92 m and 12.08 m. These are predictions made by holding the instantaneous rate fixed. Knowing the rate at one time does not establish its values throughout the interval; a curved position model can have exactly the same value and derivative at 5 s.

7.4 What does “nearby” guarantee?

Define the signed remainder by r(h)=f(a+h)−f(a)−f′(a)h. Rearranging the derivative definition gives

r(h)h=f(a+h)−f(a)h−f′(a)⟶0.

This is stronger than saying that the error tends to zero: it says the error becomes small relative to the input change. It is still a limiting statement. It supplies no universal numerical radius, such as “within 0.1”, and no specified error bound at your chosen nonzero step. To obtain one, we need more information about the particular function.

For f(x)=x2 about 3, the exact remainder is h2. An absolute error no larger than 0.01 is guaranteed when |h|≤0.1. But for g(x)=100x2 about 3 the remainder is 100h2: the same tolerance now requires |h|≤0.01. The input distance alone does not determine accuracy. Output scale and the acceptable error matter too.

For an estimate A of an exact value v, the absolute error is |A−v|. When v≠0, the relative error is |A−v|/|v|. Absolute error has the units of the output; relative error is dimensionless. Multiplying relative error by 100 expresses it as a percentage.

At a stationary point the tangent is horizontal. That can give a good prediction of the output value while giving a poor relative prediction of its change. For f(x)=x2 at zero, L(h)=0 while the actual change is h2. The absolute error tends to zero, but the prediction misses the entire nonzero change: its relative error is 1, or 100%. Relative error is undefined when the exact quantity used in the denominator is zero. Always say which quantity and which error measure you mean.

Activity 7.4 · A tolerance is a question

For p(x)=5x2 about a=2, find the exact remainder. Determine a symmetric input range giving absolute output error at most 0.005. Would observing a small error at two sampled inputs prove the same bound throughout that range?

Discussion of Activity 7.4

p(2+h)=20+20h+5h2, so the remainder is 5h2. The condition is h2≤0.001, or |h|≤0.001≈0.03162. Thus 2−0.001≤x≤2+0.001. This interval follows from the exact formula for every input in it. Two numerical checks would only establish what happened at those samples; without additional reasoning they could miss larger errors between them.

7.5 When a tangent is the wrong tool

The method requires a derivative at the base point. The graph of |x| has no single tangent slope at zero: its left and right slopes disagree. Drawing a horizontal line through its corner does not repair that failure. Similarly, x at zero has no finite right-hand slope to use in our formula, and a tangent model cannot be carried across a gap in the domain merely because its line is defined there.

Even where the derivative exists, distant extrapolation can give impossible predictions. The reciprocal tangent from Example 7.2 is zero at x=8 and negative beyond 8, while 1/x remains positive for positive x. The line has faithfully preserved value and slope at 4; it was never a global replacement for the reciprocal.

Activity 7.5 · Decide before calculating

For each request, state whether the usual finite-slope tangent method is available and what further qualification is needed: estimate |0.02| from a tangent at zero; estimate ln(1.03) from a tangent at 1; estimate 1/10 from the reciprocal tangent at 4. For the usable local example, calculate the estimate and decide whether it is high or low.

Discussion of Activity 7.5

The absolute-value derivative at zero does not exist, so the usual method is unavailable there; direct evaluation gives 0.02. The logarithm is differentiable at 1 with value 0 and slope 1, giving ln(1.03)≈0.03. Because its derivative decreases on positive inputs, its graph is concave down and the tangent estimate is high. This sign information alone does not give a numerical error bound. At 10 the reciprocal tangent predicts 1/4−6/16=−1/8, while the exact reciprocal is positive. The tangent exists but the target is too far away for this prediction to be useful.

A defensible local estimate therefore names its base point, computes the change with its sign and units, checks domain and differentiability, and states what supports its accuracy. Sometimes that support is an exact remainder, sometimes an independently checked tolerance, and sometimes only limited numerical evidence.
