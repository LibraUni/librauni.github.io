M101 · Unit 6 · Lesson 5

Reading the shape critically

A plotted line is a claim about what happens between calculated points. This lesson makes that claim visible and tests it.

The earlier lessons gave us ways to establish increasing intervals, classify extrema and relate rates without relying on a picture. We now put pictures under scrutiny. A graph can suggest an excellent question, expose an algebraic mistake or reveal the scale of a phenomenon. It can also hide the very feature we are looking for. The useful habit is to make analytical reasoning and computation challenge one another.

Four hours: 60 minutes reading and examples, a two-hour Python investigation including its feedback, 40 minutes correcting the cumulative exercises and 20 minutes for the conclusion and reference. The exercises' two-hour attempt budget was reserved across Lessons 1–4. You need P101 readiness with arrays and plotting as well as M101 Lessons 1–4. If those Python skills are not yet familiar, return to that preparation before undertaking the investigation; the text and static figures remain readable without running code.

6.19 What a plotting program actually draws

When we ask a plotting library to draw y=f(x), we normally provide a finite array of input values and a corresponding array of calculated outputs. The usual line plot joins successive pairs by straight segments. It does not inspect the formula between the samples, and it does not automatically know that an input is excluded. A smooth-looking line can therefore be a property of our sampling choices rather than of the function.

Consider the dimensionless function

f(x)=x+0.08sin(20πx),0≤x≤1.

The term x supplies a rising trend; the sine term adds oscillations with amplitude 0.08. Because the argument increases by 2π when x increases by 0.1, there are ten complete oscillations across the interval. The amplitude is small compared with the total rise of 1, but a small oscillation in height need not have a small slope. Differentiating before plotting gives

f′(x)=1+1.6πcos(20πx).

At zero this is positive, while at x=0.05 it equals 1−1.6π<0. The function cannot be increasing throughout the interval. In particular, its derivative is continuous and remains negative in a neighbourhood of 0.05, so there is a genuine interval of decrease there. This conclusion does not depend on a screen's resolution.

Example 6.18 · Samples that miss every oscillation

What will a line plot show if it uses 21 equally spaced inputs, including both endpoints?

Working. Twenty gaps fit between 21 inputs, so the spacing is 1/20=0.05. Write each input as xk=k/20, where k=0,1,…,20. Then 20πxk=kπ, and the sine term is exactly zero at every sample:

f(xk)=xk+0.08sin(kπ)=xk.

Every sampled point lies on y=x, and joining them produces a straight rising line. The missing falls are not a failure of differentiation: our samples happen to land precisely where the oscillation crosses its centre line. A computer may return tiny nonzero sine values because it uses finite-precision approximations to π and the inputs. Those tiny residuals do not explain the missing oscillations; the sampling pattern does.

The graphing window creates a different issue. Even well-spaced samples may display a feature too small to distinguish when the vertical range is very large. Enlarging the visible region can make local structure less visible. Conversely, zooming into a small region cannot reveal what happens elsewhere. Always retain the domain and the plotted limits when recording a graphical observation.

A wider view · The instrument has display choices too

The distinction between samples and the displayed line therefore has a laboratory counterpart. Our Python example isolates that one issue using an exact formula; a real measurement adds instrument response, noise and other choices. You do not need oscilloscope theory for the investigation, and its simple plotting rule should not be assumed to describe every instrument mode.

Key idea 6.10 · Three separate objects

Distinguish the mathematical function and its domain, the finite samples evaluated by the program, and the displayed line within a chosen window. Changing the last two changes the evidence you see; it does not change the original function.

6.20 A controlled graph investigation

Keep a short table in your notes with columns for sample count, input interval, visible vertical range, prediction and observation. Change one choice at a time so that you can explain why the picture changes. The starter notebook and Python file contain the code below. Use Python 3 with NumPy and Matplotlib in your established P101 environment. No data file is needed. Run notebook cells from the top after restarting the kernel; in a script, close a displayed figure if execution waits before opening the next.

np.linspace(left, right, n) generates n evenly spaced inputs, including both endpoints by default. Thus the spacing is (right−left)/(n−1), not the interval length divided by n. NumPy evaluates the expression at each array entry. In plt.plot, the format "o-" asks for circular sample markers joined by a line. The markers help us see where the computed evidence actually is. Axis labels include the dimensionless status of this model rather than inventing physical units.

Activity 6.19 · Predict before running (20 minutes)

Predict the first plot from Example 6.18, then run this block. Explain why a graph with many visible points can still be misleading. State an exact derivative value that contradicts the claim “the function is increasing everywhere”.

import numpy as np
import matplotlib.pyplot as plt

# Dimensionless input and output; trigonometric arguments in radians.
left, right = 0.0, 1.0
n = 21
low, high = -0.15, 1.15
x = np.linspace(left, right, n)
y = x + 0.08 * np.sin(20 * np.pi * x)
plt.figure(figsize=(8, 4))
plt.plot(x, y, "o-", label=f"{n} sampled values")
plt.xlim(left, right)
plt.ylim(low, high)
plt.xlabel("x (dimensionless)")
plt.ylabel("f(x) (dimensionless)")
plt.title("A sampled curve: inspect the spacing and window")
plt.grid(True)
plt.legend()
plt.tight_layout()
plt.show()
Discussion of Activity 6.19

The points lie on the rising line to floating-point precision. At x=0.05, however, the exact derivative is 1−1.6π<0, and the derivative remains negative nearby. Twenty-one points have supplied a misleading picture because their spacing is tied to the oscillation. Counting points without considering their positions does not measure reliability. Your explanation should distinguish exact cancellation in the model from very small numerical residuals in the calculation.

Activity 6.20 · Sampling and window experiments (45 minutes)

Predict and run these changes in order. First set n = 41, then n = 401, leaving other values alone. Next keep 401 samples but set low, high = -10.0, 10.0. Finally restore the original vertical range and set right = 0.2. Compare the spacing and visibility of the oscillations. Restore the first block's defaults to reset. For each change, explain whether it changes the sample locations, the displayed scale, or both. Finish with one mathematical conclusion and one remaining uncertainty.

Hint for Activity 6.20

With 41 inputs the spacing is 0.025. Evaluate the sine at x=0.025 and x=0.075. Changing right in the block changes both the inputs passed to the function and the displayed horizontal limits.

Discussion of Activity 6.20

The 41-point graph catches alternating peaks and troughs of the sine contribution and shows falls, though its straight segments are visibly coarse. With 401 inputs the spacing is 0.0025 and the curve looks smoother. Keeping these samples while widening the vertical range compresses the 0.08 amplitude; the mathematics is unchanged. Restricting the input interval to [0,0.2] with 401 samples reduces the spacing to 0.0005 and displays two oscillations. This combines a changed view with denser sampling in that view. If you changed only plt.xlim, the existing sample array would remain unchanged.

The negative derivative near 0.05 proves a decreasing interval, independently of all four plots. The smoother plot supports our interpretation but does not prove that all features have been resolved. A useful remaining uncertainty is whether a chosen finite mesh resolves every feature of a different, unfamiliar function. “It looks smooth” does not settle that question.

A controlled comparison also protects against accidental conclusions caused by automatic axis rescaling. If the plotting library changes both axes after each run, two curves of very different height can fill similar-looking frames. Explicit limits make the comparison reproducible. They can also clip values: a curve disappearing through the frame is not an endpoint of the function. Look at the code and the formula before interpreting that boundary.

6.21 Reconciling analytical and numerical evidence

Now consider g(x)=1/(x−0.5) on [0,1] with x=0.5 excluded. Algebra tells us that g is negative to the left of the excluded input, positive to the right, and never zero. Its derivative is g′(x)=−1/(x−0.5)2<0 on each separate domain component. It decreases within each component, although a comparison across the gap can give a larger output on the right. This is exactly the domain caution from Lesson 1.

A single array spanning both sides may contain no forbidden input at all, yet still draw an incorrect connection. With 20 equally spaced inputs, the two central inputs lie on opposite sides of 0.5. The plotting routine joins their large negative and positive outputs with a steep line that crosses zero. That segment belongs to the drawing, not to the graph of g.

Activity 6.21 · A false zero (35 minutes)

Predict what is wrong with the first plot below, then run it. Compare it with the second block, which plots the domain components separately. Explain why merely deleting a forbidden sample from one array would not necessarily fix the line. Why are 0.49 and 0.51 computational cutoffs rather than endpoints of the mathematical domain?

x = np.linspace(0.0, 1.0, 20)  # no sample equals 0.5
plt.figure(figsize=(8, 4))
plt.plot(x, 1 / (x - 0.5), "o-", label="one connected sample list")
plt.xlim(0, 1)
plt.ylim(-25, 25)
plt.xlabel("x (dimensionless)")
plt.ylabel("g(x) (dimensionless)")
plt.title("Deliberate error: a line drawn across an excluded input")
plt.grid(True)
plt.legend()
plt.tight_layout()
plt.show()

x_left = np.linspace(0.0, 0.49, 200)
x_right = np.linspace(0.51, 1.0, 200)
plt.figure(figsize=(8, 4))
plt.plot(x_left, 1 / (x_left - 0.5), label="left component")
plt.plot(x_right, 1 / (x_right - 0.5), "--", label="right component")
plt.xlim(0, 1)
plt.ylim(-25, 25)
plt.xlabel("x (dimensionless)")
plt.ylabel("g(x) (dimensionless)")
plt.title("Separate lines: no connection across x = 0.5")
plt.grid(True)
plt.legend()
plt.tight_layout()
plt.show()
Discussion of Activity 6.21

The first plot draws a segment through the excluded input and the horizontal axis, suggesting a zero that is impossible because the numerator is 1. Deleting an entry from a connected sample list brings its neighbours together in that list; the routine may still join them. The two separate plotting calls create separate lines, so neither crosses the gap. The cutoffs avoid evaluating too near the pole for this illustration, but the function is defined at inputs between 0.49 and 0.5 and between 0.5 and 0.51. Those portions are simply omitted from these arrays. Clipping at vertical limits ±25 also hides large finite outputs. The missing parts have not become undefined.

When calculation and a picture disagree, neither deserves automatic trust. Recheck the derivative rules and simplification, the intended formula in the code, the domain, and the plotting choices. A wrong sign in a derivative can mislead just as readily as a coarse mesh. Here several independent facts agree: the numerator excludes a zero; the denominator identifies the gap; the derivative gives decrease on each component; and separate plotting respects that domain. Their agreement is much stronger evidence than appearance alone.

Example 6.19 · Write a defensible graph report

A report says, “The 401-point graph is smooth, so there are no other stationary points.” How should the claim be revised?

Working. A finite mesh cannot generally rule out features between its inputs. A defensible observation is: “On the stated interval, the 401 sampled values and this window show the following turning behaviour.” Follow that observation with an analytical classification, if available: factor the derivative, list all allowed zeros and undefined-derivative candidates, then establish signs on the resulting intervals. The derivative argument can justify completeness when the graph cannot. If no such argument is available, report the unresolved possibility rather than turning a visual impression into a theorem.

Sample approach and criteria for Activity 6.22

For the oscillatory function, a suitable report identifies the 21 endpoint-inclusive samples on [0,1] and vertical range [−0.15,1.15], proves that all sample values equal their inputs, and contrasts that picture with the negative derivative at 0.05. It then reports a 401-sample comparison while acknowledging that sample density alone supplies no general proof of completeness. A good report distinguishes observation from proof, supplies enough settings to reproduce the picture, and states a specific limitation. Different wording and plots can meet those criteria.

This investigation has used exact derivatives to test graphical claims. It has not estimated derivatives from sampled data. Unit 7 will take that next step, where the size of a numerical increment and the error in an approximation become central questions.

6.22 Unit exercises

This cumulative set covers the whole unit. Allow about two hours for attempts, using the time reserved in Lessons 1–4, then 40 minutes for feedback and correction. The individual timings are guides, not speed targets. Work in two sittings if helpful. Questions 1–7 consolidate shape and domains; 8–13 connect rates and interval reasoning; 14–15 combine methods and evidence. All are core practice. Exercise 6.1 · Signs describe different things (6 minutes)

At an input a, a twice-differentiable model has f(a)=−4, f′(a)=2 and f″(a)=−3. Explain each statement without confusing height, slope and change of slope. Does this information alone locate a maximum? Give a reason.

Hint for Exercise 6.1

Imagine a graph below the axis whose tangent slopes are positive but becoming smaller.

Worked solution to Exercise 6.1

The output is negative; the instantaneous slope is positive; the instantaneous rate of change of that slope is negative. The graph can rise while below the axis and while its slope decreases. None of these values locates a maximum: in particular f′(a)≠0, so a is not a differentiable interior extremum. Pointwise information alone does not classify the whole domain. For example, −4+2(x−a)−32(x−a)2 fits these data and has its maximum elsewhere; other functions can share these three data and behave differently farther away.

Return to Exercise 6.1

Exercise 6.2 · Build an interval argument (8 minutes)

A differentiable function on the real line has F′(x)=(x+1)(x−2)2. Find its intervals of increase and decrease and classify the stationary inputs. Explain why neither the stationary heights nor the zeros of F can be recovered from this derivative alone.

Hint for Exercise 6.2

The squared factor is positive except at 2. Adding a constant to F leaves F′ unchanged.

Worked solution to Exercise 6.2

For x<−1 the derivative is negative. For x>−1 it is positive except at 2. Thus F decreases up to −1 and increases afterwards; the isolated zero at 2 does not interrupt strict increase. At −1 the sign changes from negative to positive, giving a local minimum. At 2 both neighbouring signs are positive, so the horizontal tangent is not an extremum. Any vertical translate has the same derivative, so the stationary heights and zeros require additional information about F.

Return to Exercise 6.2

Exercise 6.3 · A corner and an endpoint (7 minutes)

Find the absolute extrema of f(x)=|x−1| on [−2,3]. Identify the interior critical input and explain why solving only f′=0 would miss it. State whether the mean value theorem applies on this interval.

Hint for Exercise 6.3

Use the slopes on each side of 1, then compare the corner value with both endpoint values.

Worked solution to Exercise 6.3

The slopes are −1 for x<1 and 1 for x>1, with no derivative at 1. That included interior input is critical and has value 0. The endpoints give f(−2)=3 and f(3)=2. The absolute minimum is 0 at 1; the absolute maximum is 3 at −2. There is no stationary input because no existing derivative is zero. The mean value theorem does not apply: continuity holds, but differentiability fails at the corner.

Return to Exercise 6.3

Exercise 6.4 · Zeros of the second derivative (8 minutes)

For q(x)=x5−5x3, find the intervals of concavity and all inflection points. Is each inflection stationary? Show the sign changes rather than just solving q″=0.

Hint for Exercise 6.4

Factor q″ and retain all three candidate inputs. Evaluate q′ separately.

Worked solution to Exercise 6.4

Differentiation gives

q′=5x4−15x2,q″=20x3−30x=10x(2x2−3).

Put a=32. The signs of q″ on (−∞,−a),(−a,0),(0,a),(a,∞) are respectively −,+,−,+. Hence the function is concave down on the first and third intervals and up on the second and fourth. Concavity changes at all three inputs. Their points are (−a,21a/4), (0,0) and (a,−21a/4). At zero q′=0; at ±a, q′=−45/4≠0. Only the central inflection is stationary. Continuity holds everywhere because q is a polynomial.

Return to Exercise 6.4

Exercise 6.5 · Inconclusive does not mean absent (6 minutes)

At zero, compare f(x)=x4, g(x)=−x4 and h(x)=x5. Apply the second-derivative test as far as it goes, then finish the classification by another method.

Hint for Exercise 6.5

A zero test result is a request for more information. Compare nearby values with the value at zero.

Worked solution to Exercise 6.5

All three first and second derivatives vanish at zero, so the second-derivative test is inconclusive in every case. Yet x4>0 for nonzero inputs and f(0)=0, giving a strict minimum; −x4<0 gives a strict maximum. The fifth power is negative to the left and positive to the right, continuing to increase through zero, so it has neither extremum there. The same inconclusive test result is compatible with all three behaviours.

Return to Exercise 6.5

Exercise 6.6 · All candidates, all ties (8 minutes)

Find the absolute extrema of p(x)=(x2−1)2 on [−2,2]. State every input at which each extremum occurs, and distinguish the interior local maximum from the absolute maximum.

Hint for Exercise 6.6

Factor p′ and make one table containing both endpoints and every interior critical input.

Worked solution to Exercise 6.6

The polynomial is continuous on the closed interval. Its derivative is 4x(x2−1), with candidates −1,0,1 in the interior. At inputs −2,−1,0,1,2 the values are 9,0,1,0,9. Thus the absolute minimum 0 occurs at both −1 and 1, and the absolute maximum 9 occurs at both endpoints −2 and 2. The derivative changes from positive to negative at zero, giving a local maximum of 1, which is smaller than the endpoint values. Stopping at the interior local maximum would give the wrong global conclusion.

Return to Exercise 6.6

Exercise 6.7 · Changing the domain (6 minutes)

For f(x)=e−x, compare absolute extrema on [0,2], (0,2) and [0,∞). Explain why a finite limiting value is not automatically an attained minimum.

Hint for Exercise 6.7

The derivative is always negative; then check which bounding inputs are actually included.

Worked solution to Exercise 6.7

Since f′=−e−x<0, the function decreases. On [0,2] the maximum is 1 at zero and the minimum e−2 at 2. On (0,2) neither endpoint is included, and every value has both larger and smaller values in the domain, so there are no absolute extrema. On [0,∞) the maximum is 1 at zero; there is no minimum, since outputs stay positive and approach zero without reaching it. A lower bound or limiting value need not be an actual output.

Return to Exercise 6.7

Exercise 6.8 · Two changing dimensions (8 minutes)

A rectangular panel has differentiable side lengths a(t) and b(t). At one instant a=2m, b=3m, a˙=0.04ms−1 and b˙=−0.01ms−1. Find its area rate. A student substitutes A=6 before differentiating and obtains zero. Diagnose the error.

Hint for Exercise 6.8

Differentiate the relationship A=ab while both lengths are still functions of time.

Worked solution to Exercise 6.8

The product rule gives A˙=ba˙+ab˙=3(0.04)+2(−0.01)=0.10m2s−1. The area is increasing at that instant even though one side shrinks. The statement A=6m2 is an instantaneous value, not an identity throughout time. Differentiating it as a constant replaces the changing panel with a different model. The two contributions have area-per-time units, as required.

Return to Exercise 6.8

Exercise 6.9 · Rates near a tank boundary (9 minutes)

Use the supplied spherical-tank relation V=πh2(R−h/3), with fixed R=1m and net inflow V˙=0.03m3min−1. Find the depth rates at h=0.5m and h=1m. What happens to the model's depth rate as h approaches 2m from below? Explain why this is a warning about the idealisation rather than a prediction that real water moves infinitely fast.

Hint for Exercise 6.9

The derivative of volume with respect to depth is πh(2R−h); distinguish an interior calculation from an endpoint limit.

Worked solution to Exercise 6.9

Differentiating before substituting gives V˙=πh(2R−h)h˙. At h=0.5, h˙=0.03/(0.75π)=0.04/πmmin−1; at h=1, h˙=0.03/πmmin−1. The smaller surface area away from the middle gives the larger depth rate. As h→2−, the positive denominator tends to zero and this ideal model's rate grows without bound. At fullness the assumed interior geometry and sustained inflow description must be reconsidered, for example because water overflows or inflow changes. The formula does not justify an infinite physical endpoint velocity.

Return to Exercise 6.9

Exercise 6.10 · Separation can be momentarily steady (8 minutes)

Two markers lie on perpendicular tracks at positive distances x=5m, y=12m from their intersection. Their signed distance rates are x˙=2ms−1 and y˙=−1ms−1. Find the separation rate. What value of y˙ would make that rate zero at this instant if the other data stayed the same? Would that prove constant separation over a time interval?

Hint for Exercise 6.10

Differentiate d2=x2+y2 before inserting the 5–12–13 geometry.

Worked solution to Exercise 6.10

At the instant d=13m, and 2dd˙=2xx˙+2yy˙. Hence d˙=(10−12)/13=−2/13ms−1: the markers approach. Zero separation rate requires 10+12y˙=0, or y˙=−5/6ms−1. This is instantaneous cancellation. Constant separation over an interval would require the rate to remain zero throughout it, not merely at the stated configuration.

Return to Exercise 6.10

Exercise 6.11 · A model condition matters (6 minutes)

A fixed amount of gas is modelled at constant temperature by pV=C, where p is absolute pressure. At an instant p=150kPa, V=0.08m3 and V˙=−0.004m3s−1. Find p˙. If the temperature is changing, may the same zero right-hand side be assumed?

Hint for Exercise 6.11

Use the product rule and retain the sign of the volume rate.

Worked solution to Exercise 6.11

Under the given conditions, Vp˙+pV˙=0, so p˙=−150(−0.004)/0.08=7.5kPas−1. Compression corresponds to increasing absolute pressure. A changing temperature invalidates the stated constant-C assumption; the right-hand side cannot simply be set to zero without a justified replacement model. No further gas-law formula is needed to identify that limitation.

Return to Exercise 6.11

Exercise 6.12 · The mean value theorem with a gap (8 minutes)

For f(x)=lnx on [1,e2], check the mean value theorem's hypotheses and find its matching input. Then consider r(x)=1/(x−1) on [0,2] with 1 excluded. Does the theorem apply, and does any allowed interior derivative equal its endpoint secant slope?

Hint for Exercise 6.12

The logarithm is smooth on positive inputs. For the second function, inspect both the missing input and the sign of its derivative.

Worked solution to Exercise 6.12

The logarithm is continuous on the closed positive interval and differentiable inside. Its secant slope is 2/(e2−1). Solving 1/c=2/(e2−1) gives c=(e2−1)/2≈3.19, which lies between 1 and e2≈7.39. For r, the interior gap means the hypotheses fail. The endpoint slope is (1−(−1))/2=1, while r′=−1/(x−1)2<0 at every allowed input. Thus direct calculation also rules out a matching derivative. The failure of a hypothesis alone would not have established that second conclusion.

Return to Exercise 6.12

Exercise 6.13 · What endpoint readings imply (7 minutes)

A differentiable position model is continuous at the endpoints of a 12 s interval, and −0.5≤s′(t)≤1.5 in metres per second throughout its interior. Bound the displacement. A reported displacement is 15 m: is it compatible with the bound, and what velocity must occur somewhere? If two such position models have identical derivatives on this interval, what additional information would show that they are the same model?

Hint for Exercise 6.13

Multiply both derivative bounds by the positive time span; then use the average velocity and the constant-difference result.

Worked solution to Exercise 6.13

The displacement lies in [−6,18]m, so 15 m is compatible with the bound. Its average velocity is 15/12=1.25ms−1, which the theorem guarantees at an interior time. This does not specify that time or a maximum speed. Equal derivatives give a constant difference between the two models on the interval (including endpoints by continuity). Agreement at one time makes that constant zero; derivative agreement alone leaves an unknown position offset.

Return to Exercise 6.13

Exercise 6.14 · A complete shape argument (15 minutes)

For q(x)=x2e−x on [0,5], prepare a concise shape report: intervals of increase and decrease, stationary points, concavity, inflections and absolute extrema. Give coordinates of the inflections in exact form and explain why the endpoint comparison is needed. You may check your sketch with a plot after completing the argument.

Hint for Exercise 6.14

Factor the first derivative. For the second derivative, solve the remaining quadratic; retain only inputs in the chosen domain.

Worked solution to Exercise 6.14

The function is continuous on [0,5] and smooth inside. Differentiating and factoring gives

q′=e−xx(2−x),q″=e−x(x2−4x+2).

Since the exponential is positive, q increases on (0,2) and decreases on (2,5). The interior stationary point at 2 is a local maximum; the endpoint 0 has derivative zero for the extended formula but is handled as an endpoint of this problem.

For concavity, the second derivative vanishes at a=2−2 and b=2+2, both in the interval. It is positive on (0,a), negative on (a,b) and positive on (b,5). Thus the inflection points are (a,a2e−a) and (b,b2e−b). Neither is stationary.

Endpoint/candidate values are 0, 4e−2 and 25e−5. The sign argument shows the middle value is largest and both later values are positive: absolute maximum 4e−2 at 2, absolute minimum 0 at 0. Endpoints must be considered because an interior test alone would not identify the absolute minimum.

Exercise 6.15 · Challenge a computational claim (10 minutes)

A student plots w(x)=x+0.03sin(40πx) on [0,1] at the 41 inputs xk=k/40. The report says, “The curve is increasing because every sampled value increases.” Explain exactly what the samples show, use a derivative to decide the claim, and propose a controlled plotting revision. State what your revision still cannot prove.

Hint for Exercise 6.15

Evaluate the sine at the supplied inputs, then inspect the derivative at x=1/40.

Worked solution to Exercise 6.15

At every stated input, sin(40πxk)=sin(kπ)=0, so the exact samples lie on w=x and increase. But w′=1+1.2πcos(40πx), and at x=1/40 it is 1−1.2π<0. By continuity of the derivative there is a decreasing interval nearby, refuting the claim about the whole function. A sample revision could compare 41 with 801 inputs at fixed horizontal and vertical limits, displaying markers and recording the spacing. This should expose oscillations, but no finite mesh alone proves that every stationary point has been found. A sound answer explains the sampling cancellation, gives the exact counterevidence and distinguishes improved observation from proof. Other controlled revisions can satisfy these criteria.

6.23 Conclusion and reference

The water-tower question at the start of the unit asked how a changing amount becomes a changing level. The answer required more than a derivative rule: we had to choose a model, identify what was held fixed, keep the quantities tied to the same instant and interpret the geometry in the rate equation. The same care runs through the rest of the unit. A zero derivative proposes a candidate; signs and comparisons decide what the candidate means. A theorem turns local information into an interval statement only when its hypotheses hold.

Graphs now have a more precise role in that reasoning. They help us notice structure and test our expectations, but their samples, domain treatment and window must be examined. An exact sign argument can reveal what a picture hides; a surprising picture can send us back to check our algebra. In Unit 7 we move from exact rates to local approximation and numerical estimates. Keep the distinction between an exact result, evidence and approximation: it will be as important there as the formulas themselves.
