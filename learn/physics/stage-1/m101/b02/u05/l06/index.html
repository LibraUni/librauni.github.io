M101 · Unit 5 · Lesson 6

Checking derivative calculations

A plausible answer is a starting point for checking. The most useful check asks a question that the original calculation did not already answer.

The rules now let us differentiate a substantial range of functions. They also create opportunities for small, systematic mistakes: losing an inner derivative, reversing a subtraction or using a simplified formula at an excluded input. This lesson brings calculation and judgement together. We will combine exact reasoning with a deliberately limited numerical investigation, then use the unit exercises to practise choosing methods independently.

Four hours: 25 minutes reading and examples, a two-hour Python investigation, 30 minutes of exercise attempts, 45 minutes of correction and 20 minutes with the conclusion and reference. The other 150 minutes of exercise attempts were reserved across Lessons 1–5, giving three hours for the whole closing set. Use those reserved periods here; the exercises are not an additional layer of study.

5.26 A calculation needs a different check

Suppose two lines of working contain the same forgotten chain factor. Repeating those lines neatly may reproduce the same error. An independent check changes something: the algebraic form, the input, the interpretation or the route to the result. None is a universal test, but together they can reveal mistakes that a single familiar route conceals.

Example 5.22 · Change the algebraic route

Check a derivative of f(x)=(x+1)2 in two ways.

Working. The chain rule gives f′(x)=2(x+1). Expanding first gives f=x2+2x+1 and f′=2x+2. These are identical for every real input, so the comparison checks an algebraic expression rather than just one numerical value. The exact difference quotient at a is 2a+2+h, giving the same derivative in the limit. At a nonzero offset, however, the quotient differs from the derivative by h even before rounding is involved.

Units offer another independent check in a physical model. A first derivative of metres with respect to seconds must have units of metres per second. If an expression has units of metres alone, something is missing. Correct units do not prove the expression correct: a missing dimensionless factor of two would pass that test. A check is useful precisely when we understand what it can and cannot detect.

Key idea 5.11 · Build a case for the answer

Check the original domain, the structure of the rules, an alternative exact route where available, and units when quantities have units. Use numerical values at deliberately varied inputs to look for contradictions. A finite collection of agreeing values supports a calculation but does not prove an identity or a limit.

5.27 A scalar Python investigation

Our numerical quantity is the same secant slope used in Lesson 1:

Q(x,h)=f(x+h)−f(x)h,h≠0.

We will compare it with a proposed derivative at several fixed inputs, using both signs of the offset. The function values and input are dimensionless in this experiment. Positive and negative offsets approach the same target from opposite directions. The task is to judge a proposed symbolic calculation, not to discover a universally best offset; systematic numerical differentiation belongs to Unit 7.

The following program uses only Python's standard library. exp(x) calculates ex and isfinite(x) checks that a number is neither infinite nor a special “not a number” value. The new instruction raise ValueError("message") stops the calculation and reports why the chosen inputs are unsuitable. It is preferable to printing an apparently meaningful slope after an invalid operation. In a notebook, run experiments expected to raise an error in separate cells so the explanation remains next to the experiment.

The argument named function receives a function such as f or abs; function(x) calls it at x. This lets the same secant calculation check different formulas without copying its subtraction and division. The outer loop selects an input, and the indented inner loop runs every listed offset at that input before moving on. The function called proposed deliberately contains the expression under review.

from math import exp, isfinite

def f(x):
    return x**2 * exp(-x)

def proposed(x):
    # A proposed derivative to investigate, not an answer.
    return 2 * x * exp(-x)

def secant(function, x, h):
    if not isfinite(x) or not isfinite(h):
        raise ValueError("Use finite inputs")
    if h == 0 or x + h == x:
        raise ValueError("Choose a nonzero, representable offset")
    first = function(x)
    second = function(x + h)
    if not isfinite(first) or not isfinite(second):
        raise ValueError("Function values must be finite")
    result = (second - first) / h
    if not isfinite(result):
        raise ValueError("Secant result must be finite")
    return result

for x in [0.0, 1.0, 2.0, -1.0]:
    print("input", x, "proposed derivative", proposed(x))
    for h in [0.1, -0.1, 0.01, -0.01, 0.001, -0.001]:
        print("  offset", h, "secant", secant(f, x, h))

The guards have different purposes. A zero offset makes the mathematical quotient undefined. A nonzero offset can nevertheless be too small to change the stored floating-point value of x; x + h == x catches that case. Finite inputs do not guarantee finite outputs, so the function values and result are checked separately. The program does not anticipate every error: log at a nonpositive argument raises its own domain error, and exp at a very large positive input may raise an overflow error before a finite-value check. These failures should be interpreted, not hidden by deleting the guards.

Discussion and a model approach to Activity 5.27

A corrected function is:

def checked(x):
    return exp(-x) * (2*x - x**2)

At 1, the correct derivative is about 0.367879. The secants for offsets 0.01 and −0.01 are about 0.366034 and 0.369713 respectively; they lie on opposite sides of the derivative and disagree slightly because they span finite intervals. Both are far from the proposal, about 0.735759. At 2, secants with those offsets are about −0.001349 and 0.001358, close to the correct zero, while the proposal is about 0.541341. These comparisons reveal a discrepancy worth tracing to the missing product-rule term; the exact derivation settles it.

At zero, both derivative candidates give zero. Small secants can be close to zero too, so that test would not distinguish the formulas. For abs at zero, positive offsets give 1 and negative offsets give −1, consistently with the corner. For example secant(log, 0.1, -0.2) requests a logarithm at −0.1 and fails on the domain. That does not disprove differentiability of lnx at 0.1; it rejects an interval that leaves its domain. Zero and an unrepresentable offset are rejected for their separate stated reasons.

For the transfer problem, q′(x)=(1−x2)/(1+x2)2, all real x. Choosing zero and 2 gives exact derivative values 1 and −3/25. These inputs sample different signs rather than merely repeating near-identical cases. A useful report includes the derivation, chosen inputs and offset signs, the observed pattern, and a clear statement that a finite table is not a proof. Other well-justified input choices are equally acceptable.

5.28 Reading agreement and disagreement

When a secant differs from a derivative candidate, several explanations remain possible. The candidate may be wrong. The finite interval may still have a noticeably different average slope from the instantaneous slope. Floating-point subtraction may lose accuracy when two almost equal function values are subtracted. Or the interval may have left the function's domain. The point of the investigation is to distinguish these possibilities using the mathematics, rather than declaring every discrepancy a computer error.

For a quadratic we know the exact finite-offset term, so we can predict disagreement without running anything. For |x| at zero the persistent opposite signs express a mathematical failure of differentiability. For the exponential product, the exact product-rule derivation explains the missing term. The same general-looking table can therefore carry very different meanings in different problems.

A useful stopping point is a coherent explanation: the exact rule is justified, its domain is retained, the test inputs are capable of exposing a relevant error, and the numerical pattern agrees within the limitations of finite offsets and arithmetic. “The computer agrees” by itself leaves all four questions unanswered.

Exercise 5.1 · A derivative from the definition (8 minutes)

For f(x)=3x2−2x+1, expand and simplify the difference quotient at a general input a. Find f′(2) and the tangent there. State when division by the offset is allowed.

Hint for Exercise 5.1

Keep h≠0 until after cancellation.

Worked solution to Exercise 5.1

f(a+h)−f(a)=6ah+3h2−2h, so the quotient is 6a+3h−2 for h≠0. Its limit is 6a−2. At 2, f(2)=9 and f′(2)=10, giving y−9=10(x−2). Substituting h=0 into the original quotient is invalid; it is the simplified expression whose limit we take.

Exercise 5.2 · A reciprocal and its domain (8 minutes)

Use the definition to find the derivative of r(x)=1/(x+2) at a≠−2. Explain why your answer cannot define the derivative at −2.

Hint for Exercise 5.2

Combine the two fractions before dividing by h.

Worked solution to Exercise 5.2

The quotient is −1/[(a+h+2)(a+2)], for h≠0, a≠−2 and a+h≠−2. Its limit is −1/(a+2)2. A sufficiently small neighbourhood avoids the excluded input when a≠−2. At −2 the original function has no value, so it has no derivative there.

Exercise 5.3 · Continuity and a corner (8 minutes)

For f(x)=|x−2|, calculate the difference quotient at 2 from each side. Is the function continuous there? What does this establish about continuity and differentiability?

Hint for Exercise 5.3

The quotient is |h|/h.

Worked solution to Exercise 5.3

The right quotient is 1 and the left quotient is −1, so no finite two-sided derivative exists. Both one-sided function limits and the value at 2 are zero, so the function is continuous. Differentiability implies continuity, but continuity does not imply differentiability.

Exercise 5.4 · Families, powers and boundaries (12 minutes)

Find derivatives and real domains for (a) 4x3/2−2x−1/2; (b) 5ex−3lnx; (c) 2sinx−cosx; (d) 3x+log2x−tanx. Distinguish the function domain from the derivative domain. Why is the derivative of x not finite at zero?

Hint for Exercise 5.4

In (a), a negative power excludes zero. In (c), angles are in radians.

Worked solution to Exercise 5.4

(a) 6x1/2+x−3/2, function and derivative domain x>0. (b) 5ex−3/x, both domains x>0. (c) 2cosx+sinx, all real inputs, with radian arguments. (d) 3xln3+1/(xln2)−1/cos2x; both domains require x>0 and cosx≠0. The inward quotient for x at zero is h/h=1/h for h>0, which grows without bound; the finite derivative formula applies only for x>0.

Exercise 5.5 · Two changing factors (10 minutes)

Differentiate p(x)=(x2+1)ex. Evaluate at zero. Explain why multiplying the two individual derivatives gives a wrong answer, using either the increment formula or the value at zero.

Hint for Exercise 5.5

Write one term for the change in each factor.

Worked solution to Exercise 5.5

p′(x)=2xex+(x2+1)ex=ex(x2+2x+1), all real inputs. At zero it is 1, whereas (2x)ex would give zero. The increment has the first-factor change times the old second factor and the second-factor change times the old first factor, plus a product of changes; it is not just that last product.

Exercise 5.6 · A quotient with no real exclusions (8 minutes)

Find the derivative of q(x)=(x+1)/(x2+1) and its value at 1. Check the denominator condition explicitly.

Hint for Exercise 5.6

Keep the numerator grouped until its subtraction is complete.

Worked solution to Exercise 5.6

q′=[(x2+1)−2x(x+1)]/(x2+1)2=(1−2x−x2)/(x2+1)2. Since x2+1>0, this holds for every real input. At 1 it is −1/2. Squaring the denominator is part of the quotient rule; it does not remove the need to check the original denominator.

Exercise 5.7 · A hole that survives simplification (8 minutes)

For r(x)=(x2−9)/(x−3), find the derivative wherever it exists. Compare this function with its continuous extension at 3, and state the derivative of that extension at 3.

Hint for Exercise 5.7

Equality with x+3 holds only on the original domain.

Worked solution to Exercise 5.7

For x≠3, r=x+3, so r′=1. The original function has no derivative at 3 because it has no value there. Define r~(x)=x+3 for all real x, including value 6 at 3. This new, extended function has derivative 1 at 3. A limit or a cancelled expression does not silently make this new definition.

Exercise 5.8 · Find the layers (10 minutes)

Differentiate (a) (1+2x2)4; (b) ln(2+x2); (c) sin(e2x). Name the layers in (c) and give real domains.

Hint for Exercise 5.8

Work from the outer operation inward, retaining the input at each layer.

Worked solution to Exercise 5.8

(a) 16x(1+2x2)3. (b) 2x/(2+x2). (c) cos(e2x)e2x2=2e2xcos(e2x). The layers are 2x, then exponential, then sine. All three functions and displayed derivatives are defined for all real x. Radian convention applies to the sine.

Exercise 5.9 · Select more than one rule (12 minutes)

Find derivatives of (a) x2ln(1+x) and (b) e3x/(1+x2). Show where the chain rule enters and state the domains.

Hint for Exercise 5.9

The outermost operation determines the first rule; inspect each component afterwards.

Worked solution to Exercise 5.9

(a) Product differentiation gives 2xln(1+x)+x2/(1+x), with x>−1; the logarithm uses the inner derivative of 1+x, which is 1. (b) Quotient and chain rules give e3x[3(1+x2)−2x]/(1+x2)2, all real x. The exponential contributes the factor 3. These grouped forms make the separate contributions easier to check than unnecessary expansion.

Exercise 5.10 · An angular convention matters (10 minutes)

A supplied displacement is s(t)=0.04sin(5t+π/6) metres for numerical t in seconds. Find velocity and acceleration at zero, including units. Why would a formula written using degree-valued angles need an extra conversion factor?

Hint for Exercise 5.10

Each time derivative contributes the inner factor 5. For degrees, θ corresponds to πθ/180 radians.

Worked solution to Exercise 5.10

v(t)=0.20cos(5t+π/6) m s−1 and a(t)=−1.00sin(5t+π/6) m s−2. At zero, v=3/10≈0.1732 m s−1 and a=−0.5 m s−2. Here 5 carries inverse-second units so the phase is dimensionless. Differentiating sin(πθ/180) with respect to the numerical degree value adds π/180 by the chain rule.

Exercise 5.11 · A tangent to a relation (10 minutes)

For x2+xy+y2=13, verify that (1,3) lies on the curve and find the tangent there. Explain why xy contributes two derivative terms.

Hint for Exercise 5.11

Treat y as a function of x on the chosen branch.

Worked solution to Exercise 5.11

1+3+9=13. Differentiation gives 2x+y+xy′+2yy′=0, hence y′=−(2x+y)/(x+2y) where x+2y≠0. At (1,3) the slope is −5/7, so y−3=−57(x−1). Both x and y(x) change, and the product rule gives y+xy′.

Exercise 5.12 · One more derivative (10 minutes)

On the upper branch of x2+y2=25, find y′ and y′′ at (3,4). Check the second result by differentiating the explicit branch. Describe the issue at (5,0).

Hint for Exercise 5.12

Differentiate 2x+2yy′=0 once more before substituting values.

Worked solution to Exercise 5.12

y′=−x/y=−3/4 at the point. Another differentiation gives 2+2(y′)2+2yy′′=0, so y′′=−[1+(y′)2]/y=−25/64. Explicitly y=25−x2 gives y′′=−25/(25−x2)3/2 for −5<x<5, agreeing at 3. At (5,0) the tangent is vertical and there is no finite y′; the derivative formula cannot be used by dividing by zero.

Exercise 5.13 · Position is not acceleration (10 minutes)

For s(t)=2t3−9t2+12t metres, with numerical time in seconds, find s, v and a at t=1. Does zero velocity there imply zero acceleration? Compare s′′(1) with [s′(1)]2.

Hint for Exercise 5.13

Find functions for both rates before substituting.

Worked solution to Exercise 5.13

v=6t2−18t+12 and a=12t−18. At 1, s=5 m, v=0 m s−1, a=−6 m s−2. Zero velocity at one instant does not force zero change of velocity. The second derivative is −6 in the stated units, whereas the squared first derivative is zero and has different units, m2 s−2.

Exercise 5.14 · A first-order join (10 minutes)

Let f(x)=x2+2x for x≤1 and f(x)=ax+b for x>1. Choose a,b for differentiability at 1. Does a second derivative exist there? Justify using one-sided rates.

Hint for Exercise 5.14

Match the values before matching the slopes.

Worked solution to Exercise 5.14

Continuity requires a+b=3. The left derivative is 2x+2, whose value at 1 is 4; the right slope is a. Thus a=4, b=−1. The derivative is 2x+2 below 1 and 4 at and above 1. Its one-sided difference quotients at 1 are 2 and 0, so f′′(1) does not exist.

Exercise 5.15 · Audit three claims (12 minutes)

Explain and correct each claim: (a) “(xsinx)′=cosx”; (b) “(ln(x2))′=1/x2”; (c) “A difference quotient at h=10−6 is the exact derivative because h is small.” Give a domain with (b) and a precise counterexample with (c).

Hint for Exercise 5.15

Identify the operation at which each argument loses information.

Worked solution to Exercise 5.15

(a) The correct product result is sinx+xcosx, all real x. Both factors vary. (b) The chain factor gives 2x/x2=2/x, on x≠0; the domain includes negative inputs because x2>0. (c) For f(x)=x2 the exact quotient at a is 2a+h, whereas the derivative is 2a. Any nonzero h, including 10−6, gives a finite-offset difference in exact arithmetic. Floating-point evaluation introduces a further possible discrepancy.

Exercise 5.16 · Choose a useful numerical check (10 minutes)

Two candidates for the derivative of x2e−x are A(x)=2xe−x and B(x)=e−x(2x−x2). Explain why checking only at zero is weak. Predict their values at 2, decide which is correct by derivation, and say what positive and negative small-offset secants should test.

Hint for Exercise 5.16

The omitted product-rule term vanishes at zero.

Worked solution to Exercise 5.16

Both candidates give zero at zero, so agreement there cannot distinguish them. At 2, A=4e−2≈0.54134 and B=0. The product rule gives B. Secants from both signs at 2 should approach zero; their nonzero finite-offset values need not equal the derivative exactly. Use more than one input and a written derivation; a finite table alone cannot prove the rule.

Exercise 5.17 · Compare two exact routes (12 minutes)

For f(x)=(x2+1)2/x on x≠0, find f′ once using quotient and chain rules, and once by expanding into powers first. Show that the results agree. Find f′′ by the simpler route and retain the domain.

Hint for Exercise 5.17

The expanded function is x3+2x+x−1.

Worked solution to Exercise 5.17

Quotient and chain rules give [4x2(x2+1)−(x2+1)2]/x2=(x2+1)(3x2−1)/x2. Expanding first gives f′=3x2+2−x−2. Expanding the first numerator gives 3x4+2x2−1, establishing equality. Then f′′=6x+2x−3, throughout x≠0. Neither route fills the hole at zero.

Exercise 5.18 · A sensor model with units (12 minutes)

A supplied resistance model is R(T)=100[1+0.004(T−20)+0.00001(T−20)2] ohms, where T is the numerical temperature in °C. The temperature follows T(t)=20+3t, with numerical t in minutes over 0≤t≤5. Find dR/dt and d2R/dt2 at two minutes. Check the first derivative by substituting T(t) first. State the unit conversion implicit in the coefficients and what the model does not establish.

Hint for Exercise 5.18

The bracket is dimensionless. Differentiate with respect to the variable requested.

Worked solution to Exercise 5.18

dR/dT=0.4+0.002(T−20) Ω/°C. Multiply by dT/dt=3 °C/min to obtain dR/dt=1.2+0.018t Ω/min, giving 1.236 Ω/min at two minutes. The second rate is 0.018 Ω/min2. Substitution gives R(t)=100+1.2t+0.009t2 Ω, confirming both derivatives. The coefficients 0.004 and 0.00001 have inverse-degree and inverse-degree-squared units. These are rates of the supplied model over its stated interval, not a calibration or error guarantee for a real sensor.

5.30 Conclusion and reference

The unit opened with a question about a changing quantity: how can an average rate over an interval lead to a rate at a single instant? The derivative answers through a limit of difference quotients. Its definition explains why the value at the target matters, why a corner can be continuous without being differentiable, and why a small nonzero offset remains an average rather than becoming an exact instantaneous rate.

The differentiation rules turn that definition into a practical method. Their order is guided by structure: a sum separates, a product has two changing contributions, a quotient requires a nonzero denominator, and a composition transmits rates through its layers. Implicit differentiation extends the same reasoning to a chosen curve branch. A second derivative then asks how the first rate changes, without turning it into a squared rate or forgetting which input is independent.

There is therefore more to a derivative than a formula. It has a domain, a variable of differentiation and, in physical models, units. It may be supported by an alternative exact route and challenged by numerical evidence. In Unit 6 we will put this information to work: rates, stationary points and curve shape will become ways of answering questions about a model. Unit 7 will return to how a computer estimates derivatives when an exact formula is unavailable.
