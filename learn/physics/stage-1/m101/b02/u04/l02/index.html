M101 · Unit 4 · Lesson 2

Limits

A missing value need not leave us without information. The surrounding values may point to one definite answer—or reveal why no single answer is possible.

In Lesson 1, cancelling a factor simplified a rule without restoring an excluded input. We also saw a display whose formulas approached different heights at a boundary. We now need language that describes those nearby values without confusing them with the value at the boundary itself. That language is the language of limits.

Three and a half hours: allow about 80 minutes for explanation and worked examples, 80 for your own tables, sketches and arguments, and 50 for feedback and correction. The activities are part of that allocation. No programming is needed; a calculator may help check a table, but keep the reasoning visible.

4.6 A value approached

Return to the function q(x)=(x−3)(x+1)/(x−3) from Lesson 1. Its domain excludes 3. At every other input it agrees with x+1, so inputs just below 3 produce outputs just below 4, and inputs just above 3 produce outputs just above 4. There is no output q(3) to calculate. Nevertheless, there is a clear statement about the surrounding outputs:

limx→3q(x)=4.

Read this as “the limit of q(x) as x tends to 3 is 4”. The arrow describes the input approaching 3; the number on the right describes the output approached. These are different numbers with different roles. The notation does not instruct us to put x=3 into the original quotient.

A finite table makes the approach visible. The entries below are exact for the stated decimal inputs because away from 3 the rule is simply x+1.

What makes the conclusion stronger than a guess from these six entries is the relation |q(x)−4|=|x−3| for every allowed input. If we want the output less than one millionth away from 4, it is enough to use any input less than one millionth away from 3, excluding 3 itself. The same reasoning works for any positive target distance, however small. It controls all sufficiently nearby inputs, not only the ones in the table.

Key idea 4.4 · A finite limit

Writing limx→af(x)=L means that outputs can be made as close to the finite number L as we require by taking allowed inputs sufficiently close to a, but different from a. Every sufficiently nearby input must meet the requirement. For the two-sided limits here, the function is defined on an interval on each side of a, possibly with a itself missing.

The value f(a) is not part of this test. It may equal L, differ from L, or be undefined.

The word “finite” matters. We are asking for a real number as the approached output. We shall also encounter outputs that grow without bound, but an unbounded direction is not an extra real number.

Activity 4.9 · Three functions, one approach

Keep q(x)=x+1 for x≠3. Construct one function that is undefined at 3, one that assigns 4 at 3, and one that assigns −2 there, all agreeing with this rule elsewhere. Sketch the three graphs. State the value and limit at 3 for each. Explain why changing just the filled point cannot change this limit.

Discussion of Activity 4.9

The first is q itself; the second is j(x)=x+1 on all real inputs; the third uses x+1 away from 3 and assigns −2 at 3. Each limit is 4, because every nearby input different from 3 gives the same output in all three functions. Their values at 3 are, respectively, undefined, 4 and −2. Draw an open point at (3,4) for the first and third, and a filled point at (3,−2) for the third. For the second, include (3,4). A limit describes the surrounding graph, not the isolated choice at its centre.

4.7 How close is close enough?

The phrase “gets closer” can be misleading if it suggests that each output must move steadily towards its limit. A function can approach from above, from below or alternate between the two. It can even equal its limit at many nearby inputs. What matters is that a small enough input neighbourhood keeps every output within a requested band.

To make that statement tangible, consider f(x)=2x−1 near x=2. Its candidate limiting value is 3. Write x=2+h, where h is the signed offset from the target input. Then

f(2+h)=2(2+h)−1=3+2h,

so the output error relative to 3 is 2h, and its size is 2|h|. This identity tells us how to choose input accuracy to achieve output accuracy.

Example 4.6 · Working backwards from a tolerance

For f(x)=2x−1, ensure that the output differs from 3 by less than 0.02. How close to 2 must the input be?

Working. The required condition is |f(x)−3|<0.02. Since f(x)−3=2(x−2), it becomes 2|x−2|<0.02, or |x−2|<0.01. Thus every input in (1.99,2.01) meets the accuracy requirement. In the limit discussion we exclude the central input 2, even though this particular function happens to be defined there.

The strict inequality matters: at 1.99 or 2.01 the output error is exactly 0.02. If the requested error were less than 0.0002, we would instead use |x−2|<0.0001. There is no smallest permitted positive tolerance; the rule for choosing the input neighbourhood continues to work.

We have used ordinary algebra to explain a limit, without developing a formal theory of quantified definitions. Keep the order of the reasoning: first specify how close the output must be; then find a sufficiently close range of inputs. Checking a single small input offset reverses that emphasis and gives less information.

Activity 4.10 · Choose a sufficient neighbourhood

Let r(x)=7−3x. Near x=2, show that the output approaches 1. Find an input condition that guarantees |r(x)−1|<0.015. Would requiring |x−2|<0.001 also work? Explain whether a sufficient neighbourhood must be the largest possible one.

Hint for Activity 4.10

Subtract the proposed limiting value before taking absolute values. Compare the output error with the input error.

Discussion of Activity 4.10

r(x)−1=−3(x−2), so |r(x)−1|=3|x−2|. The condition |x−2|<0.005 guarantees the requested error. The narrower condition |x−2|<0.001 also works, since it gives an output error less than 0.003. A limit requires a neighbourhood that works, not the widest possible one. The identity also shows that any positive output tolerance can be met by dividing it by 3 to choose an input tolerance.

4.8 Approaching from each side

The display in Example 4.5 followed d(x)=x+2 below 1 and d(x)=5−x at and above 1. The input condition decides which formula governs each approach. From the left, inputs less than 1 give outputs approaching 3. From the right, inputs greater than 1 give outputs approaching 4. We express these two statements separately:

limx→1−d(x)=3,limx→1+d(x)=4.

The superscript minus sign means approach using inputs less than 1; the plus sign means inputs greater than 1. These signs do not describe negative and positive outputs, and they do not mean subtracting or adding a fixed small number to 1. Inputs can approach a negative target from either direction too.

Example 4.7 · Can a boundary value repair a jump?

Replace only d(1) by a chosen real number c, leaving the two formulas unchanged for x<1 and x>1. Can a choice of c give a two-sided limit at 1?

Working. For left inputs, d(1−h)=3−h when h>0, so the approach is to 3. For right inputs, d(1+h)=4−h, so the approach is to 4. Neither expression involves c. No choice of the value at 1 can make the two approaching values equal. The two-sided limit does not exist, whether c is 3, 4, 3.5 or anything else. Averaging the two numbers does not give a limit: nearby outputs on neither side are forced towards that average.

Key idea 4.5 · The two sides must agree

For a function defined on both sides sufficiently near a, the finite two-sided limit exists and equals L exactly when both one-sided limits exist and equal L.

limx→a−f(x)=L=limx→a+f(x).

Unequal finite one-sided limits, or failure of either side to approach a finite value, rule out a finite two-sided limit.

A domain endpoint needs a different question. The real function s(x)=x has no inputs less than zero. Its right-hand limit as x→0+ is 0: to make x less than a positive number e, choose 0<x<e2. There is no left-hand approach within its domain. In this unit we write the right-hand limit explicitly at such endpoints; we do not invent an unavailable branch. Later we will use this same one-sided convention when checking continuity at an endpoint.

Activity 4.11 · Read the signs on the arrow

For p(x)=2−x when x<−1, and p(x)=x+4 when x≥−1, find the two one-sided limits at −1 and p(−1). Does a two-sided limit exist? Then change only p(−1) to 8 and answer again. Finally, state the available endpoint limit for 5−x at 5.

Discussion of Activity 4.11

Both branches approach 3 at −1; the original value is also 3. The two-sided limit is 3. Changing the point value to 8 leaves both approaches and their common limit unchanged. For 5−x, the domain is x≤5, so only x→5− is available; its limit is 0. The side is determined by allowed inputs, not by whether the output is positive.

4.9 Reading a graph at a missing point

When a graph specifies an exact function, follow its branch towards the target input and read the approached height. Do this separately from each side before inspecting any filled point. A graph of measurements is different: joining measured points by a line adds an assumption about what happens between them. Even a computer plot of a formula samples finitely many inputs and can conceal a small gap or a rapid change.

Example 4.8 · A graph description with three answers

An exact graph follows y=2x+1 for x<2 and y=9−2x for x>2. Both branch endpoints at (2,5) are open. The graph has a separate filled point at (2,1). Find the value and one-sided and two-sided limits at 2.

Working. The left branch approaches 2(2)+1=5; the right branch approaches 9−2(2)=5. The approached heights agree, so the two-sided limit is 5. The filled point instead gives f(2)=1. Drawing a vertical segment between the open and filled points would be wrong: it would assign many outputs to the input 2. There is a single exceptional value, not a connecting part of the graph.

A useful annotation on your own sketches is to write “value” beside the filled point and “approach” beside the open endpoint. Once the distinction is comfortable, those words become unnecessary, but initially they help prevent an easy visual mistake.

Activity 4.12 · Design the graph

Sketch two functions defined on all real inputs. Both must have value 2 at zero. For the first, require a two-sided limit of −1 at zero. For the second, require a left-hand limit of −1 and a right-hand limit of 3. Give a piecewise formula for each sketch. Explain why the same point value tells us so little about nearby behaviour.

Discussion of Activity 4.12

One simple first function equals −1 at every nonzero input and equals 2 at zero. A possible second equals −1 for x<0, 3 for x>0, and 2 at zero. Use open points at the ends of the horizontal branches and a filled point at (0,2). The first limit is −1; the second has no two-sided limit because its sides disagree. Many sloping or curved branches would also work. Check each proposed formula against all three requirements rather than expecting a unique sketch.

4.10 When nearby values do not settle

A jump is one reason for failure of a two-sided limit. Another is that outputs do not stay near any finite number, even on one side. For u(x)=1/x2, the inputs 0.1, 0.01 and 0.001 give 100, 10 000 and 1 000 000. Negative inputs of the same magnitudes give the same outputs. More generally, to make 1/x2 exceed any chosen positive threshold M, choose 0<|x|<1/M. The outputs grow beyond every finite threshold as we approach zero.

This is unbounded growth, not approach to a very large real number. It is commonly written limx→01/x2=+∞. Here the infinity symbol describes the growth; it does not supply a finite limit or a value at zero. Likewise, 1/x is negative without bound on the left of zero and positive without bound on the right. In questions asking for a finite limit, explain that none exists and describe the behaviour.

Being bounded is not enough either. To see why, recall that the sine function oscillates between −1 and 1. In radians, consider w(x)=sin(π/x) for x≠0. As positive inputs get small, the angle π/x grows and keeps passing through whole cycles. For positive integers n, the inputs

xn=24n+1,zn=24n+3

both get arbitrarily close to zero. Yet w(xn)=1 because the angle is 2nπ+π/2, while w(zn)=−1 because it is 2nπ+3π/2. Thus arbitrarily close to zero there are outputs separated by 2. They cannot all settle within a small band about one real number. This explains the failure; a densely shaded plot alone would not.

Example 4.9 · A limit may be reached repeatedly

Contrast v(x)=xsin(π/x) with w(x)=sin(π/x) near zero, with both undefined at zero.

Working. Since |sin(π/x)|≤1, we have |v(x)|≤|x|. Any positive output tolerance is therefore met whenever the input magnitude is smaller than that tolerance. Hence limx→0v(x)=0. The output still oscillates, but its amplitude is confined to a shrinking band. At inputs x=1/n it is exactly zero. A limit need not be a value the function “never reaches”. This bounding argument uses only the sine bound and the meaning of closeness; no derivative rule is needed.

Activity 4.13 · Diagnose the failure

For each rule near zero, decide whether it has a finite two-sided limit and justify your decision: (a) −2/x2; (b) |x|/x; (c) x2sin(π/x). All exclude zero. Do not describe all three merely as “undefined at zero”.

Discussion of Activity 4.13

(a) Outputs are negative with arbitrarily large magnitude, so no finite limit exists. (b) For negative inputs the quotient is −1; for positive inputs it is 1. The finite one-sided limits disagree. (c) The magnitude of the output is at most x2, which can be made as small as required by taking |x| small; its limit is 0. Exclusion of zero did not decide any of these conclusions.

4.11 What a table can and cannot establish

The distinction between sampled evidence and an argument about all nearby inputs matters outside pure mathematics too. A telescope detector records a finite collection of readings. A mathematical model may describe behaviour between readings, but that is an additional claim which needs justification.

Suppose a table lists F(x)=0 at x=±0.1, ±0.01 and ±0.001. It is tempting to conclude that the limit at zero must be 0. Compare two possible rules. The first is zero at every input. The second is

F(x)={1,0<|x|<0.0005,0,|x|≥0.0005,0,x=0.

Every listed sample is outside the narrow inner interval, so the table is identical for both functions. But all sufficiently small nonzero inputs for the second rule have output 1: its limit is 1, despite its value at zero being 0. The missing information lies closer to the target than the table reaches.

Adding more rows may reveal this particular hidden change. It cannot turn a finite table into a proof for an unrestricted unknown function: a still narrower interval could escape the new samples. Nor do many decimal places in an output answer a question about all nearby inputs. A table is useful for suggesting a result, finding a sign mistake or testing a conjecture. A formula and an argument can explain why the behaviour continues.

Key idea 4.6 · Match the strength of the claim to the evidence

A finite table or sampled graph supports a conjecture about a limit. A justification must cover every sufficiently nearby allowed input, or exhibit incompatible approaches when the limit fails. Keep “the values suggest” separate from “the rule implies”.

Activity 4.14 · Challenge a convincing table

A report samples a function at nonzero distances 0.2, 0.02 and 0.002 on both sides of zero, obtaining output 5 each time. Construct a piecewise function with exactly those six outputs but with limit 7 at zero. Assign it any value you like at zero. State one extra pair of samples that would expose your construction, and explain why that pair still would not prove a limit for an unknown function.

Discussion of Activity 4.14

For example, assign 7 when 0<|x|<0.001, 5 when |x|≥0.001, and −4 at zero. The six samples give 5 but the limit is 7. Samples at ±0.0005 reveal the inner value. They settle what this particular rule does at those inputs, not what every possible function does at all closer inputs. A successful answer states a positive threshold smaller than 0.002, distinguishes the centre from its neighbourhood, and explains the remaining information gap.

We can now say what a limit claims, separate the two directions of approach, and distinguish several ways a limit can fail. The next lesson turns the algebra retrieved in Lesson 1 into methods for establishing limits. The aim is to replace a suggestive table with a justified calculation while retaining every restriction that makes the calculation valid.
