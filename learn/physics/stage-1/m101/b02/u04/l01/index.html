M101 · Unit 4 · Lesson 1

Functions and their domains

Before asking what happens near an input, we must know what counts as an input. A formula is only part of that information.

In Unit 3 a matrix accepted a vector and returned another vector. We checked that the dimensions matched before calculating. A real function has a related requirement: the input must belong to its domain. This lesson retrieves the language of functions and develops the restrictions that will matter when we approach a point.

Four hours: about 80 minutes for the block and unit openings, explanation and examples; 110 minutes for the activities and revisiting their algebra; and 50 minutes for feedback and correction. Work through graphs with pencil and paper. No programming is needed.

4.1 A rule with an allowed set of inputs

A function assigns exactly one output to each input in its domain. Here the inputs and outputs are real numbers. Writing f(x) means “the output of the function f at input x”; it does not mean f multiplied by x. The function is the whole assignment, while f(3) is one particular output, provided 3 belongs to the domain.

For example, the rule f(x)=x2 assigns the same output to 2 and −2. That is allowed: distinct inputs may share an output. What is forbidden is assigning two different outputs to the same input. The equation y2=x does not, on its own, define a single real output y for each positive x: when x=9, both 3 and −3 satisfy it. Choosing y=x specifies the nonnegative output and gives a function on x≥0.

The set of outputs actually reached is called the range (or image set). For f(x)=x2 on all real inputs, the domain is R and the range is [0,∞). Every output is nonnegative; every nonnegative number is the square of a real number. The same rule restricted to −1≤x≤2 has range [0,4]. A different domain gives a different function even when the formula is unchanged.

Key idea 4.1 · Specify the function

State the rule and domain. In this unit we take the codomain—the containing set in which outputs are declared to lie—to be R unless stated otherwise. The range contains only outputs actually obtained. If an abstract formula has no stated domain, use the largest real domain on which every operation is defined; a physical model may require a smaller one.

Interval notation keeps domains compact. A square bracket includes an endpoint and a round bracket excludes it. Thus [1,5) means 1≤x<5. The symbol ∞ indicates an unbounded direction, not an endpoint that can be included, so (2,∞) means all real numbers greater than 2. A union symbol joins alternatives: (−∞,0)∪(0,∞) is all real numbers except zero.

Example 4.1 · A domain changes the question

A proposed position model is s(t)=(t−2)2 metres, with t the numerical time in seconds during 0≤t≤3. Find its range and say whether s(−1)=9 is a prediction of this model.

Working. The squared quantity is zero at t=2, which is in the interval. Its largest magnitude occurs at t=0, where t−2=−2 and s=4. To check that no output between 0 and 4 is missed, choose such a value y. Then t=2−y lies in [0,2] and gives s(t)=y. The position range is therefore [0,4] metres. Although the algebraic expression gives 9 when −1 is substituted, that input is outside the model's stated domain. It is not a prediction for the stated three-second observation.

The calculation distinguishes a possible extension of a formula from a claim that the model applies there. It also distinguishes position from distance travelled; a position range is not a total path length.

Activity 4.1 · Input, output and restriction

For g(x)=3−x2 on [−2,1], calculate g(−2) and g(1), and determine the range. Is g(2) defined for this function? Explain why equal outputs at different inputs cause no difficulty.

Discussion

The outputs are −1 and 2. The maximum is 3 at x=0, and the minimum is −1 at x=−2, so the range is [−1,3]. The input 2 is excluded even though the formula can be evaluated there. Inputs −1 and 1 both produce 2; each input still has exactly one output.

4.2 Finding restrictions before simplifying

Three familiar operations supply most of our domain restrictions. A denominator must not be zero. The quantity inside a real square root must be nonnegative. A real logarithm requires a strictly positive argument. Apply all restrictions simultaneously: passing one test does not remove the others.

Example 4.2 · Two restrictions at once

Find the largest real domain of

r(x)=x+2x−1.

Working. The square root requires x+2≥0, hence x≥−2. The denominator excludes x=1. Combining these gives [−2,1)∪(1,∞). The endpoint −2 is allowed: the numerator is zero but the denominator is −3. Zero divided by a nonzero number is defined and equals zero.

If the square root were itself in the denominator, as in 1/x+2, the endpoint −2 would be excluded. Its domain would instead be (−2,∞). The location of an operation matters.

Simplification introduces a subtler issue. Suppose

q(x)=(x−3)(x+1)x−3.
For x≠3 we may cancel the nonzero factor and obtain q(x)=x+1. The original function still excludes 3. The expression x+1 on all real inputs describes an extension, with an additional output at 3; it is not the same function on the same domain.

Key idea 4.2 · Keep the original domain

A denominator must be nonzero; a real square-root argument must be nonnegative; a real logarithm argument must be positive. Combine every restriction. Algebraic simplification preserves values where the working is valid; it does not automatically add excluded inputs.

We will use this distinction repeatedly. Cancellation can reveal nearby behaviour without repairing the missing value. Write restrictions beside the working so that an algebraic shortcut does not silently change the question.

Activity 4.2 · Audit the domain

State the largest real domain of each expression: (a) 1/(x2−9); (b) 5−2x; (c) ln(x−2); (d) x/(x−4). Then simplify (x2−16)/(x−4) while preserving its restriction.

Hint

Factor a denominator before excluding its zeros. For the logarithm the inequality is strict. For the last quotient, retain every restriction from the original expression.

Discussion

(a) All real inputs except −3 and 3. (b) x≤5/2. (c) x>2. (d) [0,4)∪(4,∞). The final expression equals x+4 only for x≠4; cancelling does not assign an output to the original quotient at 4.

Activity 4.3 · The same line, with a missing point

Compare q(x)=(x−3)(x+1)/(x−3) with j(x)=x+1, each on its largest real domain. Make a table at x=2, 2.9, 3, 3.1, 4. Sketch both graphs, distinguishing the point where they differ. A classmate says “the formulas simplify to the same thing, so the functions are equal”. Write a two-sentence correction, then give a domain on which the two functions do agree.

Discussion

The shared outputs away from 3 are 3, 3.9, 4.1, 5. At 3, q is undefined while j(3)=4. Draw the line y=x+1 with an open circle at (3,4) for q, and include that point for j. Their rules agree wherever x≠3, but equality of functions also requires the same domain. Restrict j to R⧵{3}—the real numbers with 3 removed—and the functions agree.

4.3 Reading familiar functions and graphs

A graph contains the points (x,f(x)) for allowed inputs. Reading vertically above one input should find one point on the graph. A missing point is often drawn as an open circle; a filled circle marks an included value. Those small marks carry mathematical information, especially when a formula changes or an input is excluded.

The families in Figure 4.3 give a useful store of shapes. A polynomial combines nonnegative integer powers of x with constants; it is defined for every real input. A rational function is a quotient of polynomials, with zeros of its denominator excluded. The square-root function starts at zero and increases without becoming negative. Absolute value measures distance from zero: |x|=x for x≥0 and |x|=−x for x<0.

Exponential and logarithmic functions reverse one another. With e≈2.71828, ex is positive for every real x, and lny is the exponent that produces a positive number y: ln(ex)=x. Thus e0=1 and ln1=0. A logarithm is not defined at zero or at a negative real argument. Sine and cosine accept every real angle and give outputs between −1 and 1. We use radians in calculus; one complete turn is 2π radians. The tangent tanx=sinx/cosx excludes the angles where cosx=0.

These reminders are intended for recognition, not a second course in algebra and trigonometry. When a later expression combines familiar functions, first recognise its parts and then check their domains. For instance, ln(1+x2) is defined for every real x because 1+x2 is always positive. It is not necessary to sketch the whole graph to decide that.

Example 4.3 · A graph shifted by its input

Describe h(x)=x−2+1 using the graph of the square root. State its domain and range.

Working. The square root receives input x−2, so it starts when x−2=0, at x=2. Every feature of the original graph moves two units right. Adding 1 afterwards moves each output one unit up. The start is (2,1), the domain is [2,∞) and the range is [1,∞). The minus sign inside the function moves the graph right because a larger input is needed to give the old argument.

Activity 4.4 · Sketch before calculating

Sketch y=|x−1| for −2≤x≤4, labelling its vertex and endpoints. Sketch y=1/(x−1) separately; label its excluded input and the signs on either side. Explain why the two graphs behave differently near 1. Finally give the domain of ln(4−x2).

Discussion

The absolute-value graph has vertex (1,0) and endpoints (−2,3) and (4,3). It approaches zero from either side of 1. The reciprocal is negative for x<1 and positive for x>1; its magnitude grows without bound near the excluded input. For the logarithm, 4−x2>0, so −2<x<2. The endpoints are excluded because their logarithm argument is zero.

Activity 4.5 · Arguments and outputs

Without a calculator, evaluate e0, ln(e2) and ln1. State whether ln(−1) is a real number. Then explain why “a logarithm cannot be negative” is false by finding the sign and value of ln(e−2). Finally identify the domains of e−x2 and ln(x2); explain why they differ at zero.

Discussion

The first three outputs are 1, 2 and 0. The real logarithm has no value at −1, because an exponential is always positive. But ln(e−2)=−2: a positive argument smaller than 1 gives a negative logarithm. The exponential e−x2 accepts every real x. The logarithm ln(x2) requires x2>0, so it excludes exactly zero. A restriction on the argument is different from a restriction on the output.

4.4 Composition: the output becomes an input

A laboratory calculation often has stages. A sensor converts an input into a voltage, and a calibration converts that voltage into a displayed number. Mathematics describes the combined operation by composition. If f acts first and g acts second, the final output is g(f(x)), written (g∘f)(x). As with a matrix product, the rightmost operation acts first.

A wider view · A formula needs experimental support

A mathematical composition tells us how specified rules fit together. In an instrument, establishing those rules is an experimental task. The photograph shows comparison with a reference temperature: the numerical relation used afterwards is only useful if it describes the instrument over the range where it will be used.

The calibration activity below supplies invented rules and their valid intervals so that you can concentrate on the mathematics. It makes no claim about the photographed thermometer. P101 develops the separate question of how measurements support a calibration or model.

To find the domain, follow the input through every stage. It must enter f, and the resulting value f(x) must enter g. Checking only whether the final formula looks legal can miss restrictions imposed by an earlier stage. Composition is also different from multiplication: g(f(x)) feeds a value into a rule; g(x)f(x) multiplies two outputs at the same input.

Example 4.4 · Order changes the domain

Let f(x)=x2−4 on R, and g(u)=u on [0,∞). Find both compositions and their domains.

Working. Applying f first gives

(g∘f)(x)=x2−4.
We require x2−4≥0, or |x|≥2. The domain is (−∞,−2]∪[2,∞). Applying g first instead gives
(f∘g)(x)=(x)2−4=x−4,x≥0.
Although the simplified expression x−4 would make sense for negative inputs, the first operation g does not. The composition retains x≥0.

The dummy letter u makes the stages visible; changing it to x would not change g. What matters is which value enters each rule.

Key idea 4.3 · Composition has two domain checks

For (g∘f)(x)=g(f(x)), require x in the domain of f and f(x) in the domain of g. The rightmost function acts first. The intermediate output is part of the reasoning even if it disappears during simplification.

Activity 4.6 · Check every stage

Let a(x)=x−1 and b(x)=1/x, with their largest real domains. Find a∘b and b∘a and their domains. Then let c(x)=x: find c∘b and explain its domain without relying only on a calculator.

Discussion

(a∘b)(x)=1/x−1 with x≠0. (b∘a)(x)=1/(x−1) with x≠1. For (c∘b)(x)=1/x, the reciprocal first excludes zero and the square root requires 1/x≥0. A reciprocal is never zero, so this means x>0.

Activity 4.7 · A calibration with a valid range

An invented instrument produces a numerical voltage v=f(p)=0.4p+0.2, where p is the numerical pressure in kPa and the instrument is specified for 0≤p≤10. A display accepts only 0≤v≤4 (voltage in V) and reports g(v)=25v display units. Find the complete rule and valid pressure domain for the display as a function of pressure. Check the outputs at both endpoints. Explain why a calculation at p=10 is not a valid output of the composed system even though the sensor itself accepts that input.

Hint

First solve 0≤0.4p+0.2≤4, then intersect that result with the sensor's pressure interval. These are numerical-value formulas in the stated units.

Discussion

The combined numerical rule is g(f(p))=25(0.4p+0.2)=10p+5. The display condition gives −0.5≤p≤9.5; combining it with 0≤p≤10 leaves [0,9.5] kPa. The endpoint display values are 5 and 100. At p=10, the intermediate voltage is 4.2 V, outside the display's stated domain. Reporting 105 by extending its formula would ignore that restriction.

The coefficients carry the units needed by the numerical-value formulas: the sensor slope represents 0.4 V per kPa, and the display conversion represents 25 display units per volt. No physical pressure-sensor law is assumed; the rules and valid intervals were supplied.

4.5 One function, several formulas

A rule may depend on which part of the domain contains the input. Such a function is piecewise defined. The conditions are part of the rule, and the equality sign at a boundary tells us which formula supplies its value there. Read the condition first, then substitute.

Example 4.5 · A threshold display

An invented dimensionless display follows

d(x)={x+2,x<1,5−x,x≥1.
Find d(0.99), d(1) and d(1.01) and sketch the branches near 1.

Working. Below 1 use x+2, giving 2.99. At 1 the second condition applies, giving 4; it also applies at 1.01, giving 3.99. Draw an open circle at (1,3) for the excluded endpoint of the first branch and a filled circle at (1,4) for the included endpoint of the second.

The nearby outputs on the two sides are heading towards different heights. This is a feature of the specified display rule; it is not evidence that a measured physical quantity jumps in the same way. In the next lesson we give each approach its own limit notation.

Activity 4.8 · Repair an ambiguous rule

A proposed rule assigns 2x for x≤1 and x+3 for x≥1. Explain why it fails to specify a function at 1. Give two different repairs that keep both formulas away from the boundary, and say what output each repair assigns at 1.

Discussion

Both conditions include 1, but the outputs would be 2 and 4. One repair changes the second condition to x>1, assigning 2 at the boundary. Another changes the first to x<1, assigning 4. Neither changes the two approaching branch values. We have changed the value at one point, not the behaviour on either side.

You now have a way to read a function as more than a formula: input restrictions, output values, order of operations and branch conditions all matter. Keep those distinctions beside you as we turn from evaluating at an input to describing what happens near it.
