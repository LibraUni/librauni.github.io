Examination reference sheet

Compact formulas and conditions for the controlled-reference specimen.

Public specimen v0.1 · 23 October 2026 · Teaching standard v1.12 · Not an assessed sitting

Permitted reference · M101-EXAM-REF-0.1

This unannotated sheet is the only reference permitted for specimen v0.1. It contains results and conditions for consultation. A future assessed paper must identify its permitted version explicitly. All vectors use Cartesian components; angles are in radians. Formulas describe their stated domains.

1. Vectors and linear systems

Magnitude, scalar product and projections

|a|=a12+a22+a32,a·b=∑i=13aibi.
a·b=|a||b|cosθ.

The angle requires two nonzero vectors. For b≠0:

signed scalar projection=a·b|b|,projba=a·b|b|2b.
a×b=(a2b3−a3b2,a3b1−a1b3,a1b2−a2b1).

Right-hand orientation; b×a=−a×b. Parallelogram area |a×b|; triangle area half this.

Matrices · In BAx, A acts first.

A=(abcd),detA=ad−bc,A−1=1ad−bc(d−b−ca)(detA≠0).

Row operations: interchange rows; multiply a row by a nonzero scalar; add a multiple of another row. A reduced row 0=k, k≠0, is inconsistent. A free variable in a consistent system gives a family of solutions.

2. Differentiation and local behaviour

f′(a)=limh→0f(a+h)−f(a)h.

The quotient uses h≠0 and inputs in the domain. Continuity at a requires limx→af(x)=f(a).

(uv)′=u′v+uv′,(uv)′=u′v−uv′v2(v≠0).
ddxF(g(x))=F′(g(x))g′(x).
ddxxn=nxn−1,(ex)′=ex,(lnx)′=1x(x>0).
(sinx)′=cosx,(cosx)′=−sinx,(tanx)′=sec2x.

Power and trigonometric rules apply where the expressions are defined and differentiable. Derivatives are linear under sums and constant factors.

L(x)=f(a)+f′(a)(x−a).

Tangent approximation is local. For a continuous function on [a,b], global extrema occur among endpoints and interior critical points. At a differentiable interior extremum f′=0. A derivative sign change + to − gives a local maximum; − to + gives a local minimum. At a stationary point, f″>0 implies a local minimum, f″<0 a local maximum; f″=0 is inconclusive.

3. Integration and accumulation

ddx∫axf(t)dt=f(x),∫abf(x)dx=F(b)−F(a)(F′=f).

For these FTC forms, f is continuous on the relevant interval. Reversing limits changes the sign; equal limits give zero. Integrals are linear.

∫xndx=xn+1n+1+C(n≠−1),∫1xdx=ln|x|+C.
∫exdx=ex+C,∫cosxdx=sinx+C,∫sinxdx=−cosx+C.

Use intervals on which the integrands are defined; 1/x excludes zero.

∫abF(g(x))g′(x)dx=∫g(a)g(b)F(u)du.

Substitution: u=g(x), du=g′(x)dx, with valid continuous integrands and differentiable substitution.

∫udv=uv−∫vdu.

Definite parts: evaluate the boundary product at both endpoints. Signed rate integral = net change; absolute-rate integral = total amount irrespective of direction.

favg=1b−a∫abf(x)dx(b>a).

Integral units = integrand units × variable units. Check an antiderivative by differentiating; check any initial value separately.

4. Numerical checks and Python notation

Dh+f(a)=f(a+h)−f(a)h,Dh0f(a)=f(a+h)−f(a−h)2h.

Use nonzero h with all sample points in the domain. Step reduction and finite-precision subtraction can have competing effects.

Equal panels: h=(b−a)/n, positive integer n.

Mn=h∑i=0n−1f(a+(i+12)h).
Tn=h[f(a)2+∑i=1n−1f(a+ih)+f(b)2].

Refinement checks numerical behaviour for a fixed model; agreement alone is not proof. Changing model inputs asks a different question.

value = 0.0            # assignment
value += increment     # add to current value
x**2                   # square; ^ is not power
for j in range(2):      # j takes 0, then 1
    value += j         # indented loop body
print(value)           # after the loop

Python multiplication is *, division is /; ** precedes multiplication and addition. Parentheses group calculations. range(n) excludes n. Code here is for reading, not execution during the sitting.
