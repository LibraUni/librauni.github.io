A defensible mathematical judgement

A good validation report lets another person follow the evidence. It identifies the question, explains the checks and reaches a conclusion at the precision those checks support. We will first practise that form of argument, then apply the unit's ideas across a varied set of problems.

Use this lesson's five hours together with the 80 minutes reserved earlier: 60 minutes for reading and worked synthesis, 40 for written transfer, 60 for the final Python task, 130 for unit-exercise attempts, 50 for feedback and corrections, and 40 for the conclusion and reference. Break the exercise work into sessions and return to the relevant lesson when a difficulty appears.

12.13 Construct a short validation report

Begin with a quantity rather than a verdict. “The amount delivered over three minutes” fixes the integral; “the answer is validated” does not explain what has been tested. State the model and inputs next, including the interval over which they apply. Then give the result and the evidence that matters to the requested accuracy.

The evidence should be selective. A list of twenty nearly identical runs may be less informative than one hand calculation, one independent analytical benchmark and one purposeful parameter change. Explain the relationship between each check and the conclusion. If a discrepancy remains, identify its scale and a plausible next investigation.

Example 12.9 · From output to judgement

Question. For the supplied inflow q(t)=3−t2/4 L/min, determine the amount delivered during 0–3 min and judge a numerical tolerance of 0.01 L.

Calculation. The analytical amount is A(3)=6.75 L. A checked 24-panel trapezoidal calculation gives 6.748046875 L. Its absolute error is 0.001953125 L, below the requested tolerance. Differentiating A(T)=3T−T3/12 recovers the rate, and A(0)=0. Independent constant and shifted-linear benchmarks test the code's weights and positions.

Interpretation. The numerical method meets the tolerance for the specified baseline model. The coefficient ranges from Lesson 2 instead permit exact amounts from 6.645 to 6.855 L. A claim about actual delivered water within 0.01 L therefore needs tighter input/model evidence. With 10 L initially stored and no loss, the baseline final volume is 16.75 L, below the 20 L capacity.

The report does not need to reproduce every code line. It does need enough information to repeat the calculation and understand why the tests were chosen. Retain the complete notebook as supporting work. Record changes to the model or algorithm so that a later reader can distinguish an input revision from a numerical repair.

Activity 12.13 · Improve a conclusion

Rewrite this report in a short paragraph: “Two programs gave 6.75 so the answer is exact. Increasing n made no difference. The pump definitely delivers 6.75 L.” Use the supplied model and the evidence developed in this unit. Identify any claim for which the original report gives no evidence.

Discussion of Activity 12.13

One possible revision: “For the supplied rate model on 0–3 min, analytical integration gives 6.75 L. The 24-panel trapezoidal value differs by approximately 0.00195 L, consistent with the quadratic error formula. Constant and shifted-linear benchmarks support the implementation. The stated coefficient ranges allow 6.645–6.855 L, so numerical agreement alone does not establish the actual delivery to two decimal places.” The original gives no independence evidence for the two programs and no model/measurement evidence for its physical claim. Matching rounded displays also hides the size of remaining numerical changes.

12.14 Transfer the checks to a new model

Consider the dimensionless response fc(x)=1/(1+cx) for 0≤x≤2, with parameter c between 0.45 and 0.55. We want its accumulated response J(c)=∫02fc(x)dx. No additional physical law is needed: the formula and interval define the mathematical problem.

Before calculating, inspect the denominator. Over these parameter and input ranges it is at least 1, so the function is finite and positive. Increasing c makes the denominator larger for every x>0, and therefore makes the integrand smaller. Its integral must decrease. This establishes the direction of sensitivity without differentiating an integral with respect to a parameter.

For c>0, substitution or differentiation of a logarithm gives

J(c)=[ln(1+cx)c]02=ln(1+2c)c.

At c=0, evaluate the original function instead: it is identically 1, so J(0)=2. The written quotient has a zero denominator there, but the original integral remains well defined. This is an excellent edge case for checking whether an implementation confuses the domain of a chosen expression with the domain of the original problem.

Example 12.10 · A benchmark and a bound

At c=0.5, the exact value is 2ln2≈1.38629436. One trapezoid over [0,2] gives 2(1+1/2)/2=1.5. The function is decreasing, so the one-panel endpoint rectangle values 1 and 2 bracket the integral.

With n equal panels, the left-minus-right sum is h(f(0)−f(2))=(2/n)(1/2)=1/n. The trapezoid is their average, so its error is at most 1/(2n). To guarantee an absolute error no larger than 0.01 from this bound alone, 50 panels suffice. The bound is conservative: the actual 32-panel trapezoidal value is about 1.38641642, with error about 0.00012206. A direct benchmark establishes that sharper fact for this case.

The function is convex, so the trapezoids overestimate. This sign check is different from the monotonicity bracket; together they give a clearer interpretation of the result.

Activity 12.14 · A reproducible transfer report · 60 minutes Python

Use the unit notebook or Python companion. Predict the effect of changing c, then compare exact and trapezoidal answers for c=0.45,0.5,0.55 at 4, 8, 16 and 32 panels. Include the c=0 benchmark separately, a one-panel hand check and a stated tolerance. Write a short conclusion about the method and input range. Restart and run all cells; record your environment and assistance used.

Hint for Activity 12.14

Evaluate the logarithmic expression only for positive c. For zero, use the constant-function result. Keep parameter changes in separate rows from resolution changes.

Discussion of Activity 12.14

The exact values are approximately 1.42634197, 1.38629436 and 1.34897699, decreasing as predicted. At the baseline, the trapezoidal values for 4, 8, 16 and 32 panels are approximately 1.39404762, 1.38824370, 1.38678240 and 1.38641642. The errors shrink towards zero from above. At c=0, every panel count should give 2. A good report uses the analytical benchmark to establish actual numerical error and reports the parameter-dependent range separately. It does not turn a finite list of passing tests into a claim about every possible function.

In the pump problem the trapezoidal error was negative; here it is positive. The reusable habit is to inspect the function and justify the sign, not memorise the sign from one example. The same is true of tolerance, parameter sensitivity and edge cases: the questions transfer, while their answers depend on the model.

12.15 Unit exercises

These exercises cover all four lessons. Allow about 130 minutes for attempts and 50 for checking and correction, including the time reserved earlier. Write explanations where requested; a number alone does not answer a question about evidence. Hints and worked solutions are separate and initially closed. All questions are core practice; no additional assessment is introduced.

Exercise 12.1 · Identify the quantity

A tank initially contains 4 L. A supplied net inflow is r(t)=2+t L/min for 0≤t≤2 min. Find the net amount added and the final stored volume, assuming sufficient capacity and no losses beyond those included in the net rate. Explain why 6 L and 10 L need not conflict.

Hint for Exercise 12.1

Integrate the net rate, then apply the initial value.

Worked solution to Exercise 12.1

The added amount is ∫02(2+t)dt=[2t+t2/2]02=6 L. The final volume is 4+6=10 L. The answers describe a change and a final value. Both have units of volume, so matching units alone does not make them the same quantity.

Exercise 12.2 · Test an accumulated amount

For the same rate, a candidate is C(T)=2T+T2/2+4. Which of the amount added and stored volume does it represent? State two checks.

Hint for Exercise 12.2

Check both derivative and initial value.

Worked solution to Exercise 12.2

C′(T)=2+T, so its rate matches. C(0)=4, so it represents stored volume in the specified tank. The amount added has initial value zero and is C(T)−4.

Exercise 12.3 · Recover a sum

For f(x)=4−x2 on [0,1], calculate the exact integral and the two-panel trapezoidal estimate. Give signed, absolute and relative errors, and explain the sign geometrically.

Hint for Exercise 12.3

Use heights at 0, 1/2 and 1; compare with 11/3.

Worked solution to Exercise 12.3

The exact integral is [4x−x3/3]01=11/3. The trapezoid is 12(2+15/4+3/2)=29/8. Signed error is 29/8−11/3=−1/24; absolute error is 1/24, relative error 1/88, about 1.14%. Concave-down chords lie below the graph.

Exercise 12.4 · Use a justified tolerance

For the function in Exercise 12.3, the n-panel error is −1/(6n2). Find the smallest integer n giving absolute error less than 0.002. What would a mere agreement of displayed two-decimal answers tell you?

Hint for Exercise 12.4

Solve an inequality before rounding n.

Worked solution to Exercise 12.4

We need n2>1/0.012=83.333…, so n=10. Nine gives about 0.002058 and fails; ten gives 0.0016667. Matching two-decimal displays establishes only that rounding concealed the difference; it cannot certify the stated tolerance.

Exercise 12.5 · Choose an independent test

A function intended to integrate f on [u,v] is checked against a second call to itself. Design two hand-checkable tests that examine different weaknesses. Explain their limits.

Hint for Exercise 12.5

Use a constant and a shifted linear function.

Worked solution to Exercise 12.5

One suitable pair is f=3 on [2,5], exact integral 9, and f(x)=x on [2,5], exact integral 10.5. The constant checks total weights and width; the shifted linear function also checks node placement. Include a panel count greater than one. Passing these supports these implementation properties, but does not test accuracy for every curved function or establish a physical model.

Exercise 12.6 · Input range and domain

A supplied inflow is q(t)=a−bt2 on 0–2 min. All combinations 3.9≤a≤4.1 L/min and 0.45≤b≤0.55 L/min³ are allowed. Find the exact range of delivered amounts and check that every admissible model remains an inflow.

Hint for Exercise 12.6

Use A=2a−8b/3; inspect the smallest rate at t=2.

Worked solution to Exercise 12.6

The amount increases with a and decreases with b. Its minimum is 2(3.9)−8(0.55)/3=19/3 L; its maximum is 2(4.1)−8(0.45)/3=7 L. The smallest rate is 3.9−0.55(22)=1.7 L/min, so all allowed rates stay positive. These are bounds for the allowed inputs, not probability statements.

Exercise 12.7 · A local prediction

Use the original pump model A(T)=3T−T3/12. At T=1 min, estimate the amount change for an additional 0.2 min using a derivative. Calculate the exact change and judge an allowed discrepancy of 0.02 L.

Hint for Exercise 12.7

The rate at T=1 is 2.75 L/min. Use the cubic expansion or direct substitution.

Worked solution to Exercise 12.7

The tangent predicts 2.75(0.2)=0.55 L. Exact change is 0.55−1(0.2)2/4−(0.2)3/12=809/1500≈0.5393333 L. The overestimate is 0.0106667 L, below 0.02 L. The decreasing rate explains the overestimate.

Exercise 12.8 · Cancellation and scale

An inflow is 8.00±0.02 L/min and an outflow is 7.97±0.02 L/min. Treat these as independent allowed ranges. Find the nominal net rate and its possible range. Is its sign certain?

Hint for Exercise 12.8

Pair smallest inflow with largest outflow, then reverse.

Worked solution to Exercise 12.8

The nominal net rate is 0.03 L/min. The smallest is 7.98−7.99=−0.01; the largest is 8.02−7.95=0.07 L/min. The range includes both signs, so net filling is not established by these inputs. More exact subtraction of the nominal values does not settle that issue.

Exercise 12.9 · Residual and solution error

Solve x+y=3, x+1.02y=3.04. Test the candidate (0,3), giving its residuals and coordinate errors. Explain why the two measures differ in significance.

Hint for Exercise 12.9

Subtract the equations, then substitute the candidate into the original system.

Worked solution to Exercise 12.9

Subtraction gives 0.02y=0.04, so y=2,x=1. The candidate residuals, left side minus right side, are 0 and 0.02. Its coordinate errors are −1 and +1. The nearly parallel equations amplify a small change in the second right-hand side; the residuals alone do not imply nearby coordinates.

Exercise 12.10 · Choose a comparison scale

Compare u=0 and v=0.0004 L using relative tolerance 0.001 and absolute tolerance 0.0005 L. Does the combined rule pass? Would the relative rule alone pass? Explain the role of the absolute scale.

Hint for Exercise 12.10

Calculate the larger of the absolute and relative allowances.

Worked solution to Exercise 12.10

The discrepancy is 0.0004 L. The relative allowance is 0.001(0.0004)=0.0000004 L. The combined allowance is 0.0005 L, so the comparison passes; the relative-only rule fails. The absolute allowance gives a meaningful criterion near zero. Passing compares the two numbers; it does not make either an exact physical result.

Exercise 12.11 · Classify and investigate

A numerical model differs from observations by about 0.2 L. Doubling the panel count changes its output by 0.001 L. A known exact benchmark passes. Propose two distinct next investigations and explain why the evidence does not yet identify the cause.

Hint for Exercise 12.11

Think about measured inputs and the assumptions linking rate to stored volume.

Worked solution to Exercise 12.11

Inspect the rate calibration/input ranges and compare the rate formula with measurements. Separately investigate losses, initial volume or overflow if the observed quantity is stored water. Small refinement change and benchmark success support parts of the computation, but do not identify which input or model assumption explains the 0.2 L. A missed feature in the actual integrand must also be considered if only sparse grids were inspected.

Exercise 12.12 · Trace and repair

A trapezoidal routine starts with half-weighted endpoints, then adds f(i*h) for i in range(n). Trace it for f(x)=2 on [1,3] with n=2, before rounding. State both loop repairs and design a test exposing the missing offset after repairing only the range.

Hint for Exercise 12.12

h=1. Interior nodes should be u+i*h with i=1,...,n−1.

Worked solution to Exercise 12.12

The initial total is 2; two loop terms add 4, so the routine returns 6 instead of the exact 4. Use range(1,n) and f(u+i*h). After fixing only the range, test f(x)=x on [1,3], n=2: the wrong interior sample at 1 gives total 3, while the correct sample at 2 gives 4. Keep output unrounded for checks.

Exercise 12.13 · A parameter and an edge case

For J(c)=∫02(1+cx)−1dx, derive its expression for c>0, find J(0) from the original integral and explain the direction of change as c increases through positive values. Why should code not substitute c=0 directly into the logarithmic quotient?

Hint for Exercise 12.13

Use substitution for positive c and inspect the integrand for zero c.

Worked solution to Exercise 12.13

J(c)=ln(1+2c)/c for c>0. At c=0 the integrand is 1, giving J(0)=2. For positive x, increasing c decreases the integrand, hence its integral decreases. The quotient expression divides by zero at c=0 even though the original integral is defined; use the separate constant case.

Exercise 12.14 · Write a defensible judgement

A report says: “Our tank has 19 L initially and capacity 20 L. The original pump model delivers 6.75 L in three minutes. A very fine numerical calculation agrees, so the final stored volume is 25.75 L.” Write a corrected judgement. Separate the reliable mathematical result from the failed physical assumption, and propose a useful next step.

Hint for Exercise 12.14

Compare the proposed stored volume with capacity before doing more integration.

Worked solution to Exercise 12.14

The analytical delivered amount is 6.75 L for the supplied unchanged inflow. Adding it to 19 L gives a combined amount of 25.75 L, which cannot all be stored in a 20 L tank. If the open tank spills immediately while pumping continues, final storage is 20 L and 5.75 L has spilled. If the pump stops at capacity, its rate history changes and delivered amount must be recalculated. Establish which operating rule applies. Numerical agreement validates neither the no-loss assumption nor continued pumping. A good response identifies this distinction and an actionable next investigation.

12.16 Conclusion and reference

The unit began with three competing numbers. We resolved their disagreement by identifying what each number meant and how it had been obtained. That first step led to a wider method: specify the problem, choose checks with different vulnerabilities, interpret discrepancies and decide what further evidence would matter.

Input sensitivity showed why accuracy is not simply a matter of printing more digits. An exact calculation can change substantially when an input changes, and a small equation residual can conceal a substantial solution error. Derivatives and elimination gave us ways to understand those responses. The numerical repair then showed how a plausible check can fail and how a small set of independently understood benchmarks can expose specific defects.

The final response model required the same questions but different calculations. That is the preparation for Unit 13: connecting representations in a new supplied setting and explaining why a method is suitable. Keep one example of a failed check and its repair beside your reference sheet. Being able to explain the failure is part of knowing when to trust the method.

Use the final 40 minutes for this conclusion and active reference work: reconstruct the Recall items, explain one Understand item without looking, and locate the Consult material needed to rerun a check. The printable reference PDF contains the same compact material. The notebook and exercises remain available for targeted correction.

Consult · Python

from math import isclose
# Values expressed in the same units:
isclose(u, v, rel_tol=0.001, abs_tol=0.0005)
# Signed/absolute discrepancy:
difference = estimate - benchmark
error = abs(difference)
# Sensitivity with other inputs fixed:
change = F(p + dp) - F(p)
# Keep precision; format only for display:
print(f"{estimate:.6f}")

F, p and dp denote your model function, baseline input and input change; u, v, estimate and benchmark denote previously calculated values. Full routines and input guards are in Lesson 3.
