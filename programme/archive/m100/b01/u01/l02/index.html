SECTION 1 · ABOUT 72 MINUTES

Equivalent fractions and a common unit

A fraction a/b describes a divided by b, with b ≠ 0. The denominator names the size of each equal part; the numerator counts those parts. Thus 3/4 means three quarter-sized parts. Multiplying numerator and denominator by the same non-zero number leaves the value unchanged: 3/4 = 6/8. We have changed the description, not the quantity. To add fractions, first express them using the same-sized parts. A common denominator need not be the smallest possible, but a smaller one usually makes arithmetic easier. Reduce a fraction by dividing both entries by a common factor. A negative sign may be attached to the numerator or placed before the whole fraction; two negative entries give a positive value.

Worked example

Add 3/4 + 1/6. Twelfths are a common unit: 3/4 = 9/12 and 1/6 = 2/12, so the sum is 11/12. It should lie between 3/4 and 1: 1/6 is positive but smaller than the missing quarter. This estimate checks the result. Adding numerators and denominators would give 4/10, smaller than 3/4, so it fails even this simple check.

SECTION 2 · ABOUT 78 MINUTES

Combine fractions; retain an exact answer

Multiplication of fractions combines the numerators and denominators: (a/b)(c/d) = ac/(bd). For positive fractions, “a fraction of a fraction” gives a useful area interpretation. Division asks which factor would undo multiplication. Dividing by a non-zero fraction c/d is multiplication by its reciprocal d/c. Keep all non-zero restrictions visible. A decimal can be exact: 0.25 = 1/4. A finite displayed decimal can also be a rounded approximation: 1/3 ≈ 0.3333. Use = for equal values and ≈ for approximations. For a reduced fraction, only denominators composed of factors 2 and 5 have terminating decimal expansions. Other rational fractions recur; this is not random numerical noise.

Worked example

Compute (2/3) ÷ (4/5): (2/3)(5/4) = 10/12 = 5/6. Check by multiplying 5/6 by 4/5: the result is 2/3. By contrast (2/3)(4/5) = 8/15. Dividing by a positive number smaller than one increases a positive value. Also, 5/6 ≈ 0.8333; the fraction remains the exact answer.

SECTION 3 · ABOUT 60 MINUTES

Names, assignment and printed values

A Python name is a label attached to a value. In elapsed = 12, Python evaluates the right-hand side and assigns its value to the name on the left. This is an instruction, not an equation to solve. Later elapsed = 15 replaces the value associated with that name. Integers such as 12 have type int; decimal literals such as 12.0 have type float. Ordinary / division produces a float, even when the mathematical quotient is an integer. print(...) explicitly displays a value; a notebook also normally displays the final expression in a cell. Choose names that convey meaning and use an underscore for spaces. A notebook remembers previous execution, so run cells in order when checking your work.

Worked example

With numerator = 5 and denominator = 6, ratio = numerator / denominator stores an approximate float. print(ratio) displays a decimal approximation to 5/6. Changing numerator afterwards does not recalculate ratio automatically: assignment stored the earlier result. Run the ratio assignment again to recompute it.

Type, predict, run

numerator = 5
denominator = 6
ratio = numerator / denominator
print(ratio)
print(8 / 4)

SECTION 4 · ABOUT 30 MINUTES

An elapsed-time ratio

A ratio compares quantities of the same kind. Dividing 45 seconds by 120 seconds cancels the unit and gives a dimensionless ratio. Write the units in your hand calculation even though Python does not carry them automatically. Decide which quantity is the reference: reversing a ratio answers a different question. Keep an exact fraction until the final reporting step when possible. The word “times” is useful only if the direction of comparison is explicit.

Worked example

A model event lasts 45 s and a reference event lasts 120 s. The first duration is 45/120 = 3/8 = 0.375 of the reference. The reference lasts 120/45 = 8/3 ≈ 2.67 times as long. Both descriptions are valid, but they answer opposite comparisons.

  3. The difference is 30 s; 18/48 = 3/8 is dimensionless; 48/18 = 8/3 reverses the reference.
