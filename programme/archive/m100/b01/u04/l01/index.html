Equality and linear equations

Solve linear equations using equivalent steps, including fractions, and check the original relation.

4 hours of planned study, including explanation, handwritten practice, checks and any Python work below. Take breaks within your timetable. Attempt each practice set before revealing feedback; use the remaining practice time to explain corrections and retry without the answer visible.

SECTION 1 · ABOUT 84 MINUTES

Equivalent changes preserve solutions

An equation states that two expressions are equal. Solving it means finding every permitted value that makes the original statement true. Adding or subtracting the same quantity on both sides preserves equality. Multiplying or dividing both sides by a known non-zero number also preserves it. Write the operation explicitly until the reasoning is secure: terms do not magically “move across” an equals sign. Check a candidate by substitution into the original equation.

Worked example

3x − 5 = 10. Add 5 to both sides: 3x = 15. Divide both sides by 3: x = 5. Check: 3 × 5 − 5 = 10. Each transformation was reversible, so no other solution was lost.

Work it through

Show intermediate steps and give units or restrictions where relevant. For code, record a prediction before running.

  1. Solve 4x + 3 = 19, showing both operations.
  2. Solve 7 − 2x = 15 and check the sign.
  3. Solve x/3 − 2 = 4.
  4. Explain why dividing both sides by zero is not an allowable step.
Feedback and worked answers
  1. x = 4; subtract 3 then divide by 4.
  2. −2x = 8, so x = −4; 7 − 2(−4) = 15.
  3. x/3 = 6, so x = 18.
  4. Division by zero is undefined and cannot preserve an equivalent statement.

If an answer differs, locate the first step where your reasoning changes. Correct that step, close this feedback, and solve it again independently.

SECTION 2 · ABOUT 96 MINUTES

Solve and substitute back

When the unknown appears on both sides, collect its terms by applying the same operation to both sides. Expand brackets carefully before collecting. Clear numerical denominators by multiplying every term on both sides by a common non-zero denominator. This removes fractions without altering solutions. Keep the original equation visible for checking, because a mistake in the first line could otherwise survive every later step.

Worked example

(x − 1)/3 + x/2 = 4. Multiply every term by 6: 2(x − 1) + 3x = 24. Expand: 5x − 2 = 24, so x = 26/5. Checking gives 7/5 + 13/5 = 4.

Work it through

Show intermediate steps and give units or restrictions where relevant. For code, record a prediction before running.

  1. Solve 3(2x − 1) = 2x + 9.
  2. Solve (x + 2)/4 = (x − 1)/2.
  3. Solve 5 − (2x − 3) = x + 2.
  4. Solve (2x − 1)/3 − (x + 1)/6 = 2.
  5. A student multiplies x/2 + 3 = 5 by 2 and writes x + 3 = 10. Repair it.
Feedback and worked answers
  1. 4x = 12, x = 3.
  2. x + 2 = 2x − 2, x = 4.
  3. 8 − 2x = x + 2, x = 2.
  4. 4x − 2 − x − 1 = 12, so x = 5.
  5. Every term must be multiplied: x + 6 = 10, hence x = 4.

If an answer differs, locate the first step where your reasoning changes. Correct that step, close this feedback, and solve it again independently.

SECTION 3 · ABOUT 60 MINUTES

Recover a quantity from a supplied relation

A physical equation combines a mathematical relation with meanings and restrictions. For the supplied constant-velocity model s = s₀ + vt, solving for time gives a candidate time; it must also belong to the interval over which the model applies. Use compatible units before solving. A negative solution may describe an extrapolated earlier time rather than a future event.

Worked example

An object starts at s₀ = 5 m and moves with v = 2 m/s. When s = 17 m, 17 = 5 + 2t, giving t = 6 s. Substitution checks the coordinate. This interpretation assumes constant velocity during those six seconds.

Work it through

Show intermediate steps and give units or restrictions where relevant. For code, record a prediction before running.

  1. Find t when s₀ = 3 m, v = 4 m/s and s = 23 m.
  2. With s₀ = 10 m, v = −2 m/s, find the time to s = 4 m.
  3. With s₀ = 5 m, v = 2 m/s, solve for s = 1 m. Is this a future arrival?
  4. State an assumption needed to apply the model to an actual moving object.
Feedback and worked answers
  1. 5 s.
  2. 3 s; negative velocity decreases the coordinate.
  3. t = −2 s; not a future arrival for t ≥ 0.
  4. The velocity remains constant over the relevant interval, with a consistent origin and time reference.

If an answer differs, locate the first step where your reasoning changes. Correct that step, close this feedback, and solve it again independently.
