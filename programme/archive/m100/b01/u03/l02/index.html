SECTION 1 · ABOUT 84 MINUTES

Terms, coefficients and distributivity

Like terms have exactly the same variable part: 3x and −5x combine, whereas 3x and 3x² do not. Distribution says a(b + c) = ab + ac. Every term inside the brackets is multiplied by the outside factor. Subtraction of a bracket means multiplication by −1, so every sign inside changes. Equivalent expressions have the same value for every input where the original expressions are defined. Simplifying changes the form, not the value.

Worked example

3(2x − 1) − 2(x + 4) = 6x − 3 − 2x − 8 = 4x − 11. At x = 2 both forms give −3. That example is a useful error check; the distributive steps justify equivalence generally.

Work it through

Show intermediate steps and give units or restrictions where relevant. For code, record a prediction before running.

  1. Simplify 7x − 2x + 4 − 9.
  2. Expand −3(2x − 5).
  3. Simplify 5 − (2x − 3).
  4. Explain why 2x + 3x² cannot become 5x³. Test x = 2.
Feedback and worked answers
  1. 5x − 5.
  2. −6x + 15: both terms receive the factor −3.
  3. 8 − 2x.
  4. The variable parts differ. At x = 2 the original is 16 and the proposed form is 40.

SECTION 2 · ABOUT 96 MINUTES

Expand and collect without losing signs

For nested brackets work carefully from an inner group outward, or distribute one complete group at a time. Keep intermediate lines rather than doing several sign changes mentally. Products of brackets can be expanded by distributing each term of one bracket across the other. This is an application of the same law, not a new rule to memorise. Check an expansion at zero and at a non-zero input: these tests often expose different mistakes, although they are not a proof.

Worked example

2[3x − (x − 4)] − x = 2(2x + 4) − x = 4x + 8 − x = 3x + 8. Also (x + 2)(x + 3) = x(x + 3) + 2(x + 3) = x² + 5x + 6. The middle terms do not disappear.

Work it through

Show intermediate steps and give units or restrictions where relevant. For code, record a prediction before running.

  1. Simplify 4x − [2x − (3 − x)].
  2. Expand (x + 1)(x − 2), checking x = 0 and 3.
  3. Simplify 2(3a − b) + 3(b − a).
  4. Find and correct the error in −(x − 4) = −x − 4.
  5. Expand (a + b)² and explain the extra term compared with a² + b².
Feedback and worked answers
  1. x + 3: the square bracket is 3x − 3.
  2. x² − x − 2; values −2 and 4 in both forms.
  3. 3a + b.
  4. It should be −x + 4, since −1 × −4 = +4.
  5. a² + 2ab + b². The two cross-products ab and ba add to 2ab.

SECTION 3 · ABOUT 30 MINUTES

Two expressions, one chosen input

Python requires explicit multiplication and ordinary parentheses. Assign an input, evaluate the original expression, then evaluate your simplified form separately. Compare the printed results with your handwritten result. When changing an input, rerun every dependent calculation. Do not silently change both expressions until they agree: preserve the original claim and locate the algebraic mistake.

Worked example

At x = −2, 3(2x − 1) − 2(x + 4) and 4x − 11 both equal −19. Type each calculation independently, rather than copying an already computed result into a second name.

Type, predict, run

x = -2
original = 3 * (2 * x - 1) - 2 * (x + 4)
simplified = 4 * x - 11
print(original)
print(simplified)

SECTION 4 · ABOUT 30 MINUTES

Which calibration order matches the description?

The order of a scale correction and an offset matters. Multiplying a corrected reading by a scale factor is a(x − b); scaling the raw reading and then subtracting an offset is ax − b. Their difference is not merely typography. Expand the first expression to find which offset is actually applied. Use units and the verbal description to select the right model.

Worked example

A reading x = 10 has an offset b = 2 that must be removed before applying a dimensionless scale a = 3. The result is 3(10 − 2) = 24. Applying 3 × 10 − 2 gives 28 and represents a different procedure.

Work it through

Show intermediate steps and give units or restrictions where relevant. For code, record a prediction before running.

  1. Expand a(x − b) and compare it with ax − b.
  2. Use x = 8, b = 1 and a = 2 for both procedures.
  3. Give one parameter choice for which the procedures coincide for every x.
  4. Write an unambiguous instruction for a calibration that uses 2x + 3 rather than 2(x + 3).
Feedback and worked answers
  1. ax − ab versus ax − b; the offset differs by a factor a.
  2. 14 versus 15.
  3. a = 1, or b = 0, makes them coincide.
  4. Double the raw reading, then add 3 in the output units.
