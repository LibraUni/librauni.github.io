U06-L01 · Functions, domains and inverses

A function assigns exactly one output to each permitted input. Its domain is the permitted input set; its range is the set of resulting outputs. f(x) names an output, not multiplication. Composition f(g(x)) applies g first. For f(x)=x², f(x−a)+b shifts the graph right by a and up by b. Absolute value |x| equals x for x≥0 and −x otherwise. An inverse reverses the input/output mapping; it requires a one-to-one domain and is not the reciprocal 1/f(x).

U06-L02 · Writing and checking a function

A def statement defines a function; the indented body runs when it is called. Arguments supply inputs; return sends a result back to the caller. print only displays something. A local name belongs to that call. A docstring is a quoted description at the start. Test ordinary, zero and negative inputs with expected results chosen independently. A test is evidence about those cases, not a proof for every real input.
