Worked example

Read the example one line at a time. Identify the inputs, predict the displayed quantities, then type and run it in your selected notebook kernel. Library calls are explained in this section; preserve your own prediction before execution.

Type, predict, run

import numpy as np
import matplotlib.pyplot as plt
for x in [np.linspace(-2, 0.9, 80), np.linspace(1.1, 4, 80)]:
    plt.plot(x, 1 / (x - 1))
plt.xlabel("x (dimensionless)")
plt.ylabel("1/(x - 1) (dimensionless)")
plt.show()

SECTION 2 · ABOUT 200 MINUTES

Work, explain and check

Verification should target a possible failure. Check an ordinary input, a boundary or excluded input where relevant, and a result you can obtain independently by hand. Do not execute an unknown proposed program merely because it is described as helpful.

Worked example

x²−4x+1=0 gives x=2±√3. For 1/(x−1), x=1 is excluded and the magnitude grows without bound as x approaches 1. The curve approaches zero for large |x|. This is a qualitative asymptote description, not a formal limit proof.

Work it through

Show intermediate steps and give units or restrictions where relevant. For code, record a prediction before running.

  1. Solve x²−7x+12=0 and check both roots.
  2. Classify the real roots of x²+2x+1 and x²+1.
  3. A supplied trajectory h=6+5t−t² is valid for t≥0 until h=0. Find that ending time.
Feedback and worked answers
  1. (x−3)(x−4)=0; roots3,4.
  2. D=0 gives repeated root−1; D=−4 gives no real roots.
  3. t²−5t−6=(t−6)(t+1); choose6 s, rejecting−1 s.
