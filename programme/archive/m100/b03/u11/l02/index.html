Worked example

Read the example one line at a time. Identify the inputs, predict the displayed quantities, then type and run it in your selected notebook kernel. Library calls are explained in this section; preserve your own prediction before execution.

Type, predict, run

import numpy as np
import matplotlib.pyplot as plt
readings_m = np.array([1.01, 0.99, 1.00, 1.02, 0.98])
print(np.mean(readings_m))
print(np.std(readings_m, ddof=1))
plt.plot(np.arange(1, 6), readings_m, "o")
plt.xlabel("Observation number")
plt.ylabel("Reading / m")
plt.show()

Work, explain and check

Worked example

For values1,2,3 the mean and median are2. Squared departures1,0,1 sum to2. Population SD is√(2/3); sample SD is1. For a fair six-sided die, P(even)=3/6=1/2. Complements satisfy P(not A)=1−P(A). Independent event probabilities multiply; independence must be justified, not assumed from different names.
