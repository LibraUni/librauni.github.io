Worked example

Type, predict, run

import numpy as np
t = np.array([0.0, 1.0, 2.0])
observed_m = np.array([2.0, 5.1, 7.9])
predicted_m = 2 + 3 * t
residual_m = observed_m - predicted_m
print(residual_m)
assert np.allclose(predicted_m, [2, 5, 8])

SECTION 2 · ABOUT 160 MINUTES

Work, explain and check

Verification should target a possible failure. Check an ordinary input, a boundary or excluded input where relevant, and a result you can obtain independently by hand. Do not execute an unknown proposed program merely because it is described as helpful.

Worked example

For a supplied constant-speed model s=2+3t and synthetic observations(0,2),(1,5.1),(2,7.9), predictions are2,5,8 m and residuals0,0.1,−0.1 m. These small discrepancies describe fit to three supplied values; they do not prove constant velocity outside the interval or reveal measurement uncertainty.
