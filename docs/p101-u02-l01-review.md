## Reader and subject review

Separate checks identified and addressed these points:

1. A bare “length of a book” needed a question and endpoints before vocabulary. The sleeve/cover/page contrast now develops the need for a measurand before naming it.
2. The ruler diagram could have been mistaken for the later millimetre instrument. Its caption now explicitly says that it shows centimetre divisions only.
3. Fine display increments could be mistaken for whole-procedure accuracy. The timer example and last-digit distinction state what is unknown; no universal half-division uncertainty is asserted. An explicit explanation of accuracy was added before Activity 2.2.
4. Repeated timing may vary the physical motion as well as the measurement. Activity 2.4 feedback states that limitation; invented delays are not presented as typical reaction-time data.
5. The supplied alternative must not masquerade as real measurement. The text, table, notebook and companion consistently identify simulated record A. Route A requires actual readings; Route B evidences method/data reasoning only.
6. A list containing lengths could conceal endpoint subtraction. Example 2.5 explicitly stipulates A at zero; nonzero-start routes must retain both readings.
7. Converting or sorting could lose evidence. The derived list is separate, order is checked, and trial 4's note remains attached. Empty data are distinguished from a zero reading.
8. The notebook's work area intentionally contains prompts rather than filled solutions; all worked code and discussion are in the lesson. No unintroduced placeholder syntax causes a learner run to fail.
9. Visual review found mathematical unit spacing collapsed in MathML. Explicit 0.2em spaces now separate numbers from units. Equation scrollers are keyboard-focusable for narrow views.
