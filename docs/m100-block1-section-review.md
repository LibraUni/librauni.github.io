## Inside-out review

- U01 moves from signed calculation to fractions, named values, percentages and a reproducible calculation record. Exact-versus-approximate reasoning precedes numerical reporting. No installation time is charged again.
- U02 introduces powers before scientific notation and conversions. Squared units precede dimensions and scaling. Rational powers require explicit real-domain restrictions: do not use Python negative-base fractional exponentiation as a real-root algorithm. Principal roots differ from solving a squared equation. State the order-of-magnitude convention before assessing it.
- U03 introduces symbolic roles, distributivity and cancellation before Boolean guards. Identity versus equation consolidates algebraic justification; sampled agreement is not proof. No loops are assumed here.
- U04 progresses through equivalent operations, exceptional parameter cases, simultaneous relations and their information content, then inequalities, explicit lists/loops and assertions. Exact-integer assertions avoid silently teaching float equality as a reliability test.
- Block 2 receives linear relations, intervals and short transparent programs. It must still teach graphs, functions, arrays, quadratic methods and trigonometry; Block 1 does not claim them. M100 remains preparation outside the degree, supporting M101/P101 readiness and the agreed later progression.

The existing MIT/Imperial coverage register remains the wider context; this expansion makes no new institutional-equivalence claim. No curriculum topic, module credits, private timetable or completion standard is changed.

## Workload and assignments

Section allocations reconcile all five existing mutually exclusive categories for every lesson, not only each total. U01/U02/U03/U04 remain 16/18/22/24 hours; total 80 including 14 Python hours. Some workshop sections span multiple sittings. All explanation, practice, feedback, application and review counts inside these budgets; no compulsory extra homework is introduced.

iCMA41 stays within U02-L04: 30-minute review plus 60-minute assessment. Its ten-item, 100-mark specification covers U01/U02. TMA01 remains separate: written groups 45+45+60+75+45=270 minutes, notebook60, file preparation30. Its proposed question-group marks total100. Question-level tolerances, detailed partial-credit rubrics, permitted tools and live question versions require review before release. These specifications do not alter module weightings, pass thresholds or the essential-capability completion policy. No separate Block 1 EMA or final exam is added; those remain at their existing module locations.

Every section has a bounded practice/assignment intent and expected evidence. Ordinary activities are formative and do not demand formal submission. iCMA/TMA use dedicated submission routes when released. Assessment originals and feedback remain private and eligible for the existing evidence archive; do not create placeholder learner evidence now.

## Release checks still required

A blueprint is not self-contained teaching. Each section must receive complete explanations, worked examples, original activity questions, verified answers, useful hints and misconception-specific feedback. Trial realistic timings; trim or rebalance visibly within parent budgets when necessary. Optional backup replaces comparable practice when possible; additional remediation is recorded honestly. Avoid forcing a fixed item count into a short section.

Use original labelled figures with captions and text equivalents. A conversion/scaling slider in U02-L03 and a guard decision tracer in U03-L04 are useful candidates for occasional interactive support; retain an equivalent static route and include interaction time inside practice. A brief historical sidebar on standard units in U02-L03 or symbolic notation in U03-L01 may help, but verify primary sources before authoring; optional context is not assumed assessment knowledge. External references/videos must be free, specific and genuinely useful; no unverified links or whole-book substitutes are added now.

Review each section against its lesson, then integrate each completed lesson and unit. Verify no assessment asks untaught operations. Review mobile figures, keyboard interaction, print and licensing. Structural tests verify budgets, identity coverage and assessment reconciliation; they cannot certify pedagogy or mathematical explanations that have not yet been written.
