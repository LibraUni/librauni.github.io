## Immediate design review

S01 retrieves elementary readiness and makes the task explicit. S02 establishes sign, order and absolute value. S03 distinguishes unary sign from subtraction and supplies reasoning for sign rules. S04 establishes brackets and equal precedence, including the left-to-right conventions within each level. S05 translates prior mathematical work into typed Python and adds a bounded syntax repair. S06 brings evidence together and directs focused feedback.

No variable assignment, print requirement, powers, functions, arrays, fraction arithmetic algorithm or algebraic solving is introduced prematurely. Python output display is taught explicitly; installation remains the earlier guided orientation. Division yielding a decimal display is explained without a premature floating-point course. Any setup troubleshooting beyond the allowance is recorded separately.

Planned practice progresses from worked to partially supported to independent. Feedback must identify the first invalid step and explain why it fails. Numerical predictions precede execution. Correct code output alone does not establish mathematical understanding. S06 reads the saved evidence rather than adding unbudgeted Python execution. The final checkpoint is formative; it is not another TMA or a compensating percentage pass requirement.
